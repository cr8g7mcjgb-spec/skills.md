# 선지 판정표

문항 하나당 한 장. **선지를 끊어 읽는 습관**을 만드는 것이 목적이다.

---

## 사용법

```
1) 발문의 부정어("않는")에 동그라미
2) 선지마다 슬래시(/)로 절을 끊는다
3) 각 조각에 O / X / ? 표시하고 근거 위치를 적는다
4) X가 하나라도 있으면 오답 → T태그 부여
5) 전부 O면 정답 후보
```

---

## 오답 유형 태그

| 태그 | 이름 | 한 줄 설명 |
|---|---|---|
| **T1** | 인과 역전 | 원인과 결과를 바꿈 |
| **T2** | 증감 반전 | 늘어난다/줄어든다를 바꿈 |
| **T3** | 주체 바꿔치기 | A의 것을 B의 것으로 |
| **T4** | 범위 확대 | 일부를 전체로 ("모든", "항상") |
| **T5** | 범위 축소 | 없는 조건을 붙임 |
| **T6** | 조건 혼동 | 필요조건 ↔ 충분조건 |
| **T7** | 시점·순서 교란 | 단계·시기를 뒤섞음 |
| **T8** | 외삽 | 그럴듯하지만 근거 없음 |
| **T9** | 부분 진실 | 앞은 맞고 뒤가 틀림 |
| **T10** | 기법 유무 오류 | 없는 기법을 있다고 함 (문학) |
| **T11** | 효과 오류 | 기법은 맞고 효과가 틀림 (문학) |
| **T12** | `<보기>` 이탈 | `<보기>` 지시를 벗어남 |

## 작성 예시

> **선지**: "㉠은 대상과의 거리를 좁힘으로써 / 화자의 친밀감을 드러낸다"
>
> | 조각 | O/X/? | 근거 |
> |---|---|---|
> | ㉠은 대상과의 거리를 좁힘으로써 | O | 3연 "다가가" |
> | 화자의 친밀감을 드러낸다 | X | 3연 뒤 "돌아섰다" — 오히려 거리 둠 |
>
> **판정**: 오답 → **T11 (효과 오류)**
> 기법은 맞는데 효과 설명이 반대다.
