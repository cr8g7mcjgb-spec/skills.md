# 산출물 검수 체크리스트

수업 자료를 내보내기 전에 반드시 돌린다. 통과하지 못한 항목은 **고치거나, 산출물에 한계로 적는다.**

---

## A. 정직성 (가장 먼저)

- [ ] `[검증]`과 `[분석]`을 구분했는가
- [ ] `[분석]`에 해당하는 내용을 "평가원 규칙"이라고 단정하지 않았는가
- [ ] "항상 / 반드시 / 무조건"을 근거 없이 쓰지 않았는가
- [ ] 기출 원문을 기억으로 복원하지 않았는가
- [ ] 자작 지문·문항에 **자작 표기**를 했는가
- [ ] 원문 코퍼스 미대조 상태면 그 사실을 머리말에 적었는가
- [ ] 적중 예언(특정 작품이 나온다)을 하지 않았는가
- [ ] 등급컷·정답률을 예측하지 않았는가

## B. 기출 취급

- [ ] 지문·작품을 임의로 줄이거나 다듬지 않았는가
- [ ] 생략이 있으면 `(중략)` 표기를 했는가
- [ ] 출처(학년도·시행 회차·문항 번호)를 정확히 적었는가
- [ ] 평가원 기출과 교육청 학력평가를 구분해 표기했는가
- [ ] 2028 대비 자료에서 **매체 문항을 제외**했는가
- [ ] 옛 체제(2027 이전) 자료를 쓸 때 체제 차이를 밝혔는가
- [ ] 배포·판매 계획이 있다면 저작권을 확인했는가

## C. 해설 품질

- [ ] 정답 근거를 **문단 번호 + 문장 인용**으로 특정했는가
- [ ] "지문에서 알 수 있듯"으로 얼버무리지 않았는가
- [ ] **모든 오답에 T1~T12 태그**를 붙였는가
- [ ] 오답 해설 총 분량이 정답 해설보다 긴가
- [ ] 매력적 오답을 표시하고 왜 끌리는지 설명했는가
- [ ] `<보기>` 문항이면 `<보기>`의 어느 문장이 근거인지 밝혔는가

## D. 노베이스 적합성 (해당 시)

- [ ] 설명이 아니라 **절차**로 쓰였는가
- [ ] 한 문장 40자 이내인가
- [ ] 한 문장에 새 개념이 1개인가
- [ ] 전문 용어에 괄호 풀이를 달았는가
- [ ] 어려운 한자어를 우리말로 바꿨는가
- [ ] 초기 자료라면 문제 풀이 비중이 낮은가
- [ ] 지시어("이것", "그러한") 대신 대상을 다시 썼는가
- [ ] 겁주는 표현이 없는가

## E. 구조

- [ ] 7블록(표지/절차/자료/작업/문항/해설/정리)이 다 있는가
- [ ] 목표가 3개 이내이고 행동 동사로 쓰였는가
- [ ] 작업 블록에 실제로 채울 **빈칸**이 있는가
- [ ] 문단 번호가 자료에 붙어 있는가 (근거 인용용)
- [ ] 발문의 부정어가 표시되어 있는가
- [ ] 소요 시간이 명시되어 있는가

## F. 자작 문항 (해당 시)

- [ ] 정답이 하나로 확정되는가
- [ ] 각 오답이 정확히 한 지점에서 틀리는가
- [ ] 오답 태그가 서로 다른가
- [ ] 매력적 오답이 최소 1개 있는가
- [ ] 선지 길이가 고른가 (정답이 튀지 않는가)
- [ ] 발문이 평가원 표준 문형인가
- [ ] 배경지식 없이 풀리는가

## G. 기본값 명시

- [ ] 사용자가 지정하지 않아 기본값으로 간 항목을 밝혔는가
  (대상 수준 / 체제 / 분량 / 용도)

---

## 실패 시 처리

| 실패 항목 | 처리 |
|---|---|
| A (정직성) | **반드시 고친다.** 산출 보류 |
| B (기출 취급) | 출처 확인 후 고친다. 확인 불가면 자작으로 전환 |
| C (해설) | 고친다. 태그 없는 해설은 미완성 |
| D (노베이스) | 고친다 |
| E (구조) | 고치거나, 축약본임을 명시 |
| F (자작) | 정답 확정성이 실패하면 그 문항은 폐기 |
| G (기본값) | 한 줄 추가 |

---

## 최종 확인 한 문장

> 이 자료를 받은 학생이, 교사 없이 혼자서, 틀린 이유를 스스로 알 수 있는가?

아니라면 ⑥ 해설 블록으로 돌아간다.
