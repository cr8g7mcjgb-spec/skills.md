# 17. 독서 제재별 화제 지도와 지문 문법 심화

`03-reading.md`가 골격을 다뤘다면, 이 문서는 **화제 단위**로 내려간다. "무슨 이야기가 나오고, 그 이야기는 어떤 모양으로 서술되며, 어디서 문항이 터지는가."

`[분석]` 전체가 구조 관찰이다. 연도별 출제 여부는 표기하지 않는다.

---

## 1. 인문 — 철학

### 반복되는 화제군

| 화제 | 전형적 대립축 |
|---|---|
| 인식론 | 경험론 ↔ 합리론 / 실재론 ↔ 관념론 |
| 존재·동일성 | 인격 동일성, 심신 문제, 개체 식별 |
| 윤리학 | 의무론(칸트) ↔ 공리주의 / 덕 윤리 |
| 자유의지·결정론 | 양립 가능론의 위치 |
| 언어철학 | 지시·의미·기술 이론 |
| 과학철학 | 반증주의, 패러다임, 이론 미결정성 |
| 동양철학 | 성리학의 이기론, 심성론 / 노장의 무위 / 불교 연기론 |
| 미학 | 재현 ↔ 표현, 예술 정의 문제 |

### 지문 문법

```
개념 도입 → 그 개념의 통상적 이해 → 문제 제기
→ 갑의 견해(근거) → 을의 견해(갑을 어떤 점에서 부정하는지 명시)
→ (때로 병의 절충) → 남은 쟁점
```

**핵심**: 평가원 철학 지문은 **"을이 갑의 무엇을 부정하는가"를 반드시 명시적으로 쓴다.** 정답 시비를 막기 위해서다. 그 문장이 곧 문항이다.

### 터지는 지점

- 각 입장이 **공유하는 전제**와 **갈라지는 지점**의 경계 → T3
- "A는 B를 인정하지만 C는 인정하지 않는다"류 부분 부정 → T9
- `<보기>`에 가상 사례를 주고 "갑이라면 어떻게 판단할까" → 관점 적용

### 노베이스 처리법

인물 이름을 기호로 바꾼다. 칸트→㉮, 스트로슨→㉯. **이름이 어려워서 못 읽는 경우가 실제로 많다.** 표를 그리게 한다.

```
        | 주장 | 근거 | 상대의 무엇을 부정 |
   ㉮    |      |      |                    |
   ㉯    |      |      |                    |
   공통 전제:
```

## 2. 인문 — 역사·언어

| 화제 | 서술 방식 |
|---|---|
| 사학사·역사 서술 | 사료 해석 관점의 변천(통시) |
| 문자·표기의 역사 | 한글 창제 원리, 표기 변화 |
| 번역론 | 등가와 불가능성 |
| 고전 문헌 편찬 | 유서(類書), 편집 원리 |

**골격 C(통시적 발전형)가 압도적.** 각 단계가 **무엇을 해결하고 무엇을 못 했는지**가 문항.

## 3. 사회 — 법

**독서에서 가장 정형화된 제재다.**

### 화제군

| 화제 | 핵심 구조 |
|---|---|
| 계약 일반 | 성립 요건 → 효력 → 무효·취소 사유 |
| 담보·보증 | 주채무와의 관계, 부종성 |
| 물권 | 소유권·점유권·용익물권·담보물권의 구분 |
| 채권 | 채무불이행, 손해배상 범위 |
| 손해배상·불법행위 | 고의·과실, 인과관계, 위법성 조각 |
| 행정법 | 처분, 취소소송, 재량과 기속 |
| 헌법 | 기본권 제한의 요건, 비례 원칙 |
| 형사 | 구성요건·위법성·책임의 3단계 |
| 지식재산·표현의 자유 | 권리 충돌과 조정 |

### 지문 문법 — 법 지문의 4단 상수

```
① 원칙 진술        "~은 ~하여야 한다"
② 요건 열거        "이때 ~하려면 ⓐ, ⓑ, ⓒ를 갖추어야 한다"
③ 예외·단서        "다만 ~인 경우에는 그러하지 아니하다"
④ 효과·구제        "요건을 갖추면 ~할 수 있다"
```

`[분석]` **③이 없는 법 지문은 거의 없다.** 그리고 정답의 상당수가 ③ 근처에 있다.

### 터지는 지점

| 지점 | 오답 유형 |
|---|---|
| 요건 하나를 빼고 판정 | T5 |
| 예외를 무시하고 원칙만 적용 | T4 |
| 필요조건을 충분조건으로 | **T6 — 법 지문 최다** |
| 권리 주체를 바꿈 | T3 |
| 효과의 범위를 넓힘 | T4 |

### 노베이스 처리법

**요건 체크박스**를 손으로 그리게 한다.

```
[원칙] ________________________
[요건] ① ______ ② ______ ③ ______
[예외] ________________________
[효과] ________________________

<보기> 사례 → ①☐ ②☐ ③☐ → 예외 해당? ☐ → 결론 ______
```

이 시트 하나로 법 지문 정답률이 눈에 띄게 오른다.

## 4. 사회 — 경제·경영

| 화제 | 축 |
|---|---|
| 수요·공급, 탄력성 | 변수 간 증감 |
| 시장 실패·외부효과 | 원인 → 교정 수단 |
| 화폐·금리·환율 | 연쇄 인과 |
| 독점·과점·규제 | 시장 구조와 후생 |
| 플랫폼·다면시장 | 네트워크 효과 |
| 게임이론 | 전략과 균형 |
| 보험·금융상품 | 위험 배분 |
| 국제무역 | 비교우위, 관세 효과 |
| 회계·재무 | 자산·부채 인식 |

### 지문 문법

```
현상/제도 소개 → 작동 원리 → 변수 간 관계(증감) → 정책 개입 → 부작용·한계
```

**경제 지문의 정보는 거의 전부 "A가 ↑면 B는 ↓"로 환원된다.**

### 터지는 지점

- **T2(증감 반전)가 최다.** 화살표를 안 그리면 반드시 틀린다
- 연쇄 인과에서 중간 단계 생략 → T7
- 단기/장기, 명목/실질 구분 → T5

### 노베이스 처리법

**화살표 지도**를 강제한다.

```
금리 ↑ → 투자 ↓ → 총수요 ↓ → 물가 ↓
                          ↘ 고용 ↓
단, [조건] ______ 인 경우에는 ______
```

## 5. 과학

| 분야 | 화제군 |
|---|---|
| 생명 | 효소·대사, 유전자 발현, 면역, 호르몬 항상성, 신경 전달, 세포 소기관 |
| 화학 | 반응 속도, 평형, 산-염기, 결합, 전기화학 |
| 물리 | 힘과 운동, 열역학, 파동, 전자기, 광학 |
| 지구·천문 | 대기 순환, 판구조, 별의 진화, 천체 관측, 궤도 변화 |

### 지문 문법 — 과학 지문의 2가지 하위 유형

**유형 ㉠ 과정형** (생명·화학 다수)
```
현상 → 1단계 → 2단계 → … → 결과
      각 단계마다: 무엇이 무엇으로, 어떤 조건에서
```
문항: 단계 순서, 각 단계의 산물, 조건 변화 시 결과

**유형 ㉡ 관계형** (물리·지구 다수)
```
개념 정의 → 정량 관계(비례/반비례) → 실제 사례 → 측정·응용
```
문항: 변수 관계, `<보기>` 그래프 대입

### 터지는 지점

- 물질의 **증가/감소** 방향 → T2
- 단계 **건너뛰기** → T7
- "A는 B에서만 일어난다" 같은 **한정** → T5
- `<보기>` 그래프의 축을 잘못 대응 → T12

### 노베이스 처리법

과학 지문은 **"모르는 단어를 기호로 바꾸기"**가 핵심이다.

```
다황화물 → ㉮
전류 효율 → ㉯
"㉮가 용해되면 ㉯가 낮아진다"
```

용어의 뜻을 몰라도 관계는 읽힌다. 이걸 가르치면 과학 지문 공포가 크게 준다.

## 6. 기술

| 화제군 |
|---|
| 데이터 저장·압축·전송, 오류 검출·정정 |
| 암호화, 인증, 해시 |
| 센서·액추에이터, 제어 |
| 영상·음향 처리 |
| 배터리·에너지 변환 |
| 반도체·디스플레이 |
| 통신 프로토콜 |
| 기계 요소, 재료 |

### 지문 문법

```
목적/문제 → 장치 구성 요소 → 각 요소의 기능
→ 작동 순서 → 성능 좌우 요인 → 개선 방법
```

**그림·도식이 붙는 비율이 가장 높다.** 도식이 있으면 도식 문항이 반드시 있다.

### 터지는 지점

- 구성 요소의 **기능 바꿔치기** → T3
- 작동 **순서** → T7
- "~할수록 성능이 좋아진다"의 방향 → T2

### 노베이스 처리법

**부품표**를 그리게 한다.

```
| 부품 | 하는 일 | 순서 |
|  A   |         |  1   |
|  B   |         |  2   |
성능 ↑ 조건: ______
```

## 7. 예술

| 화제군 | 축 |
|---|---|
| 미술 사조 | 재현 ↔ 추상, 원근법, 매체 특성 |
| 음악 | 조성, 형식, 연주와 해석 |

## 9. 융합·주제통합 (가)(나)

### 결합 방식

| 방식 | 예 |
|---|---|
| 이론 + 적용 | (가) 개념 / (나) 그 개념의 실제 적용 |
| 서양 + 동양 | 같은 주제의 두 전통 |
| 원리 + 비판 | (가) 이론 / (나) 그 이론의 한계 지적 |
| 인문 + 사회 | 철학적 근거 + 제도적 구현 |
| 과학 + 기술 | 원리 + 응용 장치 |
| 관점 대립 | (가) 권리 A 우선 / (나) 권리 B 우선 |

### 문항 구성의 상수

```
① (가)와 (나)의 공통 화제 / 서술 방식 비교
② (가) 내용 이해
③ (나) 내용 이해
④ (가)의 관점으로 (나)를 평가 ← 최고난도
⑤ <보기> 사례에 둘 다 적용
⑥ 어휘
```

`[분석]` **④가 융합 지문의 핵심이자 최다 실수 지점이다.** "(가)의 입장에서 (나)를 비판한다면"류 발문이 나오면, 반드시 **(가)의 어떤 명제가 (나)의 어떤 명제와 충돌하는지**를 짚어야 한다. 감으로 풀면 100% 틀린다.

2028의 **관점 비교형 독서**(표현의 자유 vs 인격권)가 정확히 이 계열이다. → `14-collected-data.md` §3

## 10. 제재별 난도 체감 순위

`[분석]` 절대적 순위가 아니라 **노베이스 기준 진입 난도**다.

```
쉬움  ←                                        → 어려움
예술 < 독서론 < 기술 < 사회(경제) < 사회(법) < 과학 < 인문(철학) < 융합
```

**학습 순서 권고**: 기술 → 예술 → 경제 → 법 → 과학 → 철학 → 융합

이유:
- **기술**은 구조가 눈에 보인다(부품과 순서). 성공 경험을 만들기 좋다
- **법**은 절차(요건 체크박스)가 명확해서 훈련 효과가 즉각적이다
- **철학**은 추상어 부담이 커서 마지막에 온다
- **융합**은 위 전부가 되어야 시작할 수 있다

## 11. 자료 만들 때

- [ ] 제재를 밝히고 그 제재의 **지문 문법**을 먼저 제시했는가
- [ ] 해당 제재의 **전용 처리 도구**(요건 체크박스 / 화살표 지도 / 부품표 / 입장표 / 기호 치환)를 넣었는가
- [ ] 그 제재에서 잘 터지는 **오답 유형**을 미리 알려 줬는가
- [ ] 노베이스 대상이면 **모르는 용어를 기호로 바꾸는 훈련**을 포함했는가
