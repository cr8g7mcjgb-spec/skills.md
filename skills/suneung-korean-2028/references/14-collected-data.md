# 14. 수집된 회차별 실측 데이터

이 문서는 **네이버 검색으로 실제 수집한 회차별 정보**를 담는다. 다른 참조 문서(`01`~`13`)가 "출제 문법의 틀"이라면, 이 문서는 **개별 회차의 사실 기록**이다.

- 수집일: 2026-07-29
- 수집 경로: 네이버 검색 MCP (`13-corpus.md` §1-B)
- **문제지 원문은 확보하지 못했다.** 아래는 전부 2·3차 자료를 교차 검증한 것이다

## 0. 먼저 — 허위 분석 블로그를 실제로 걸러낸 사례

`[검증]` **이것이 이 문서에서 가장 중요한 항목이다.**

수집 과정에서 **회차별 기출 분석을 표방하지만 내용이 사실과 다른 블로그**를 발견했다. 특정 블로그를 비난하려는 것이 아니라, **판별 방법**을 남기기 위해 기록한다.

### 발견된 패턴

한 블로그가 2020~2027학년도 거의 모든 회차의 "기출분석 — 총평·등급컷·오답률"을 시리즈로 올려 두었고, 검색 상위에 다수 노출된다. 그런데 내용을 여러 회차 비교하면 **모든 회차가 동일한 틀**을 따른다.

| 반복되는 틀 | 실제 |
|---|---|
| 항상 "과학/기술 10~13번" + "사회 14~17번" | 회차마다 지문 배열이 다르다 |
| 항상 "오답률 최상위 13번, 상위 16번" | 회차마다 다르다 |
| 항상 문단 4개 + 이모지 + "💡 국어쌤의 한마디" | — |

### 교차 검증 결과 — 2026학년도 수능 사례

| 항목 | 문제의 블로그 | 독립 출처 2곳 (일치) |
|---|---|---|
| 과학기술 지문 | "리튬-황 배터리" | **"열팽창 현상과 액추에이터"** |
| 사회 지문 | "반덤핑 관세" | **"법 해석 방법과 보증 계약"** |
| 인문 지문 | (언급 없음) | **"인격의 동일성"(칸트·스트로슨)** |
| 오답률 최상위 | "13번" | **"12번"** |
| 언매 1등급컷 | 86~88 | **85** |

독립된 두 출처가 서로 일치하고, 문제의 블로그만 다르다. **해당 블로그의 회차별 내용은 사실이 아닌 것으로 판단한다.**

### 판별 규칙 — 앞으로 반드시 적용할 것

블로그 기출 분석을 쓰기 전에 아래를 확인한다.

- [ ] **여러 회차 글을 비교했는가?** 구성이 똑같으면 의심한다. 실제 시험은 회차마다 배열이 다르다
- [ ] **구체적 고유명사가 있는가?** 작품명·작가명·지문 소재가 나오지 않으면 신뢰도가 낮다
- [ ] **수치의 출처를 밝히는가?** "EBSi/메가스터디/이투스/대성마이맥 자료" 식으로 기관을 명시하면 신뢰도가 올라간다
- [ ] **독립된 다른 출처와 일치하는가?** ← **이것 하나만 지켜도 대부분 걸러진다**
- [ ] 문체가 지나치게 정형적이고 감탄사·이모지가 규칙적으로 반복되는가?

**최소 2개 출처가 일치하지 않으면 수업 자료에 쓰지 마라.**

## 1. 2026학년도 수능 (2025.11.13 시행)

`[검증: 독립 출처 2곳 교차 일치]` — 입시 분석 블로그 2곳이 세부까지 일치. 각 출처는 EBSi·메가스터디·이투스·종로학원·진학사 자료를 인용한다.

### 총평
- **독서가 매우 어렵고 문학·선택과목은 평이한 "난이도 양극화"**
- 킬러문항 배제 기조는 유지되었으나 **정보 밀도와 추론 복잡도로 변별**
- EBSi 당일 체감난이도 조사에서 '어려웠다' 응답 **86.7%** (매우 47.7% + 약간 39.0%, 응답 5,714명)
- 국어 지원자 548,376명, 1교시 결시율 9.4%

### 독서 지문 배열

| 문항 | 영역 | 소재 |
|---|---|---|
| 1~3 | 독서 이론 | 독해 능력에 대한 관점 |
| 4~8 | 사회(법) | 법 해석 방법과 보증 계약 |
| 10~13 | 과학기술 | 열팽창 현상과 액추에이터 |
| 14~17 | 인문(철학) | 인격의 동일성 (칸트·스트로슨·롱게네스) |

`[확인필요]` 위 배열은 3+5+4+4=16문항으로, 독서 17문항과 1문항 어긋난다(9번 미기재). 출처의 표기 누락으로 보이나 원문 대조가 필요하다.

### 문학 출제 작품

| 갈래 | 작품 | 작가 | EBS 연계 |
|---|---|---|---|
| 고전소설 | 수궁가 | 작자 미상 | ○ |
| 현대소설 | 독가촌 풍경 | 박태순 | ✕ |
| 고전시가 | 북새곡 | 구강 | ○ |

**8개 작품 중 3개 연계.** 연계 작품에서 시간을 벌고 비연계에서 변별하는 구조.

### 고난도 문항

| 문항 | 지문 | 지목한 기관 |
|---|---|---|
| **12번** | 과학기술(열팽창) — 개념 관계 종합 + `<보기>` 적용 | EBS 현장교사단, 메가스터디 |

### 성적 지표

| 항목 | 값 |
|---|---|
| 1등급 표준점수 | 132~133 (2025: 131) |

## 3. 2028학년도 예시문항 (2025.4.15 공개)

`[검증: 단일 출처 / 평가원 안내자료 인용]` — 학원 블로그가 평가원 「예시문항 안내」 9~39쪽을 근거로 서술. **교차 검증되지 않았으나 원자료 쪽수를 특정하고 있어 신뢰도가 높은 편.**

### 확인된 세트 구성

| 영역 | 자료 | 묻는 것 |
|---|---|---|
| **화법과 언어** | 발표 상황 | 화자가 **어떤 어휘·문법 요소로 태도를 드러내는가** — 확신의 정도를 낮추는/높이는 표현 |
| **화법** | 학생회 **토의** — 후문 계단 안전사고 (계단 재시공 / 미끄럼 방지 패드 / 난간 보수 / 조명 설치) | 사고 시각·학생 의견·조명 설치 부작용 등 **여러 자료를 종합해 가장 타당한 대안 구성** |
| **독서와 작문** | **디지털 영화와 리얼리즘** — 필름 영화의 현실 기록성 vs 디지털 영화의 이미지 변형 가능성, CG가 오히려 더 사실적으로 느껴지는 역설 | 지문 개념 이해 → **영화감독 인터뷰 자료와 연결해 비평문 작성** 시 적절한 내용 판단 |
| **독서 (관점 비교)** | **표현의 자유 vs 인격권** — 두 글 병치 | 공적 인물 기사·익명 게시글·방영금지가처분 등 사례에 **두 관점 중 어느 쪽 논리가 맞는지** 판단 |
| **작문** | **하수 처리 시설 유치 논증문** — 합리적 선택, 기회비용, 매몰비용, 정책 딜레마, 절차적 합리성 | 주장-이유-근거-예상 반론-반박 구조 파악, **추가 자료로 반박 보강** |
| **문학 (소설)** | 환경오염 고발 소설 — 공장 오염물질 vs 경제개발·근대화·안보 논리 | **사회 생태주의 관점**과 연결 |
| **문학 (시)** | **김기림 「길」 + 천양희 「한계」** | **시간과 공간이 시적 장치로 어떻게 작동하는가** — 과거 상실 경험과 현재 기다림, 눈보라·한계령 이미지 |

### 이 구성에서 읽어야 할 것

`[분석]`

1. **문법이 담화 안으로 들어갔다.** "이 문법 요소의 이름은?"이 아니라 "이 표현이 어떤 태도를 드러내고 이 상황에 적절한가"를 묻는다. → `06-grammar.md`의 학습 순서를 담화 관찰 가능한 개념(높임·지시·시제·피동·종결) 우선으로 조정해야 한다
2. **화법이 자료 종합 문제가 되었다.** 토의 절차 암기로는 안 되고, 자료 여러 개를 겹쳐 **부작용까지 고려한 대안**을 골라야 한다
3. **독서가 작문의 재료가 된다.** 읽고 끝이 아니라 "읽은 것으로 무엇을 쓸 수 있나"까지 간다
4. **관점 비교형 독서가 핵심 난도 지점이 될 가능성이 높다.** 두 글 이해 + 관점 차이 파악 + 사례 적용의 3단 구조
5. **문학도 외부 관점을 작품에 적용시킨다.** 사회 생태주의처럼 지금까지 잘 안 쓰던 비평 틀이 `<보기>`로 들어온다
