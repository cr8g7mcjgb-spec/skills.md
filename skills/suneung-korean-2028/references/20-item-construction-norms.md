# 20. 문항 제작·검토 규범 — 출제자가 실제로 따르는 규칙

이 문서가 이 스킬에서 **가장 깊은 층**이다. 앞의 문서들이 "평가원 문항은 이렇게 생겼다"를 관찰한 것이라면, 여기는 **"출제자가 어떤 규칙을 지키기 때문에 그렇게 생겼는가"** 를 다룬다.

## 0. 출처와 지위

`[검증]` 아래 내용은 **교사 대상 평가문항 제작 실무 자료**와 **교육평가 문항분석 이론**에서 확인한 것이다. 임용시험(중등 교사 임용) 준비생과 현직 교사가 공부하는 표준 내용이다.

**중요한 단서 두 가지.**

1. 이것은 **평가원 내부 출제 지침 원문이 아니다.** 학교·교육청 단위 문항 제작 규범이다.
2. 그러나 **같은 계보다.** 이 규범을 배운 사람들이 수능 출제·검토위원이 되고(현직 교사 비율 45→50%, `01-exam-system.md`), 자료 자체가 "대학수학능력시험의 좋은 문항 유형을 살펴보고 제작하라"고 명시한다. 수능이 이 규범의 정점이자 모범 사례로 취급된다.

`[분석]` **그래서 이 규범과 실제 수능 문항의 대응이 놀랍도록 정확하다.** 아래에서 규범 ↔ 관찰된 평가원 관행을 하나씩 대응시킨다. 지금까지 `[분석]`이던 것 상당수가 여기서 **근거를 얻는다.**

## 1. 측정학의 세 지표 — 문항의 운명을 결정하는 숫자

`[검증]`

### 1-1. 문항난이도 (P) = 정답률

```
P = R/N × 100
R = 정답자 수,  N = 전체 응시자 수
```

- **정답률이 곧 난이도 지수다.** 값이 크면 쉬운 문항
- 규준지향평가(상대평가)에서 바람직한 범위: **20% ~ 80%**
- **평균 난이도 50%가 이상적**

### 1-2. 문항변별도 (DI)

```
DI = 2(RU − RL) / N
RU = 상위집단 정답자, RL = 하위집단 정답자
```

- 범위 −1.00 ~ +1.00
- 최저 **.20** 이상, **.30 이상이면 만족**
- **.70을 넘으면 오히려 나쁘다** — 상위자는 다 맞고 하위자는 다 틀려서 그 안에서 변별이 안 되기 때문
- **바람직한 구간: .30 ~ .70**
- **변별도는 난이도 50%일 때 최대가 된다**

### 1-3. 문항반응분포 = 답지별 선택 비율

각 답지에 학생이 어떻게 반응했는지 분석한다. 목적은 **"각 오답지가 오답으로서 얼마나 매력이 있었는가"** 를 보는 것.

| 상태 | 판정 |
|---|---|
| 정답에 50% 이상 + 나머지가 오답지에 **고르게 분산** | **이상적** |
| 특정 오답지에 정답보다 많이 몰림 | 정답이 정답 구실 못함 → **수정 대상** |
| 오답지에 아무도 반응 안 함 | **오답 매력 부족 → 수정 대상** |

---

## 2. 이것이 뜻하는 것 — 매력적 오답은 부작용이 아니라 요건이다

`[분석]` **이 스킬 전체에서 가장 중요한 통찰이다.**

지금까지 나는 매력적 오답을 "정답률을 떨어뜨리려는 장치"로 설명했다. 규범을 보면 그보다 근본적이다.

> **아무도 고르지 않는 오답지는 결함이다.** 문항 검토 관점에 "오답지의 매력도가 너무 부족하지 않은가"가 명시적 점검 항목으로 들어 있다.

즉 출제자는 학생을 괴롭히려고 매력적 오답을 만드는 게 아니다. **오답지가 골고루 선택되어야 그 문항이 품질 기준을 통과한다.** 5지선다에서 오답 4개가 전부 죽어 있으면, 그 문항은 사실상 2지선다이고 변별도가 무너진다.

### 여기서 따라 나오는 학습 원리

| 규범 | 학습 원리 |
|---|---|
| 오답지는 매력이 있어야 한다 | **"끌리는 선지"는 정답의 신호가 아니라 위험 신호다** |
| 정답률 50% 부근이 이상적 | 절반이 틀리도록 설계된 문항이 정상이다. 틀렸다고 좌절할 일이 아니다 |
| 변별도 .70 초과는 나쁨 | 최상위권만 맞는 문항은 오히려 배제된다 → **"킬러 문항"이 측정학적으로도 나쁜 문항인 이유** |
| 난이도 50%에서 변별도 최대 | 평가원이 중간 난도 문항을 많이 배치하는 이유 |

`[분석]` **킬러문항 배제 정책은 정치적 결정이기 이전에 측정학적으로 정당하다.** 변별도가 .70을 넘는 초고난도 문항은 원래 좋은 문항이 아니다. 이 사실을 알면 2024학년도 이후의 기조 변화가 일시적 유행이 아님을 알 수 있다.

## 3. 좋은 문항의 8조건

`[검증]` 규범이 명시한 조건. 각각을 관찰된 평가원 관행과 대응시킨다.

| 조건 | 규범의 내용 | 평가원에서 나타나는 모습 `[분석]` |
|---|---|---|
| **타당성** | 측정하려는 능력과 실제 요구 능력이 일치 | 배경지식이 아니라 지문 처리력을 재도록 설계 |
| **복합성(Complexity)** | 단순 기억·재생이 아니라 분석·종합·평가 등 고등 정신 능력 | **선지에 판단 지점이 2~3개**인 이유 |
| **참신성(Novelty)** | 진부함을 벗어나 새로운 경험. 단, 지나친 생소함은 금물 | 매년 **낯선 유형이 일부** 섞이는 이유. 2028 예시문항의 융합 세트 |
| **구조화** | 답해야 할 방향이 명확. 모호하면 안 됨 | **발문이 정형화**되어 있는 이유 |
| **학습 동기** | 충실히 학습한 학생이면 무난히 풀 수 있게 | 공교육 정상화 기조 |
| **적절한 난이도** | 너무 쉽거나 어려우면 배제 | P 20~80% 구간 |
| **높은 변별력** | 잘하는 학생과 아닌 학생을 구별 | DI .30~.70 |
| **제작 원리 준수** | 윤리적·교육적으로 바람직, 특정 집단에 유·불리 없음 | 정치·종교 소재 회피 |

## 4. 문항 제작 절차 — 문항은 지문보다 먼저 설계된다

`[검증]`

```
① 제재 선정 및 교육과정 분석
      ↓
② 평가 목표 설정          ← 교육과정 성취기준에서 도출
      ↓
③ 출제 계획표 작성        ← 영역별 문항 수·비율 배분
      ↓
④ 이원분류표 작성          ← 내용 × 행동의 매트릭스
      ↓
⑤ 문항 카드 작성          ← 문항별 출제 의도·예상 정답률
      ↓
⑥ 출제
      ↓
⑦ 검토 (여러 관점 체크리스트)
```

### 4-1. 이원분류표란

**측정하려는 행동(세로) × 교과 내용(가로)의 매트릭스**다. 이 표로 문항이 특정 영역에 쏠리지 않게 배분한다.

국어과 출제 계획표의 실제 형태 (규범 자료에 제시된 예시):

```
        행동 →  개념적 지식        언어 이해              언어 표현
 내용 ↓        언어지식 문학지식  사실적 추론적 비판적   내용 선정 조직 표현
 말하기
 듣기
 읽기          ← 소단위 독해 / 대단위 독해 / 심층적 독해
 쓰기
```

`[분석]` **이 매트릭스가 수능 국어의 뼈대와 정확히 겹친다.**

| 이원분류의 행동 요소 | 수능 국어의 문항 유형 |
|---|---|
| 사실적 이해 | 내용 일치, 세부 정보 |
| 추론적 이해 | 추론 문항 |
| 비판적 이해 | `<보기>` 적용, 관점 비교, 비판적 평가 |
| 언어 지식 | 문법 |
| 문학 지식 | 문학 개념·기법 |
| 내용 선정·조직·표현 | 작문 |

**즉 "사실적 이해 → 추론적 이해 → 비판적 이해"는 강사가 만든 분류가 아니라 교육과정 평가 체계 그 자체다.** 수능 독서 세트가 왜 항상 일치 → 추론 → 적용 순으로 구성되는지가 여기서 설명된다.

### 4-2. 문항 카드

문항마다 다음을 기록한다.
- 출제 의도
- 평가 내용
- 행동 영역 (지식 / 이해 / 적용 …)
- **예상 정답률** — 출제자가 미리 구간을 표시한다 (81~100 / 61~80 / 41~60 / 21~40 / 0~20)
- 출제 근거
- 배점, 출제위원

`[분석]` **모든 문항은 만들어질 때 이미 예상 정답률이 붙어 있다.** 시험 후 실제 정답률과 대조해 문항 품질을 사후 검증한다. 이것이 6·9월 모의평가의 실질적 기능이다 — **본수능 문항의 난이도를 교정하기 위한 사전 측정.**

## 5. 검토 체크리스트 — 평가원 관행의 직접적 원천

`[검증]` 규범이 제시한 검토 관점. **왼쪽이 규칙, 오른쪽이 그 규칙 때문에 나타나는 평가원 문항의 특징이다.**

### 5-1. 출제 전반

| 검토 항목 | 대응하는 평가원 현상 `[분석]` |
|---|---|
| 교육과정 정상 운영을 기할 수 있게 출제되었는가 | 교육과정 밖 배경지식 배제 |
| 출제 계획표에 부합하는가 | 영역별 문항 수 안정성 |
| 교과서 범위를 벗어나지 않았는가 | — |
| **시중 참고서·사설 모의고사·학원 교재에 나온 문항이 아닌가** | **출제점검위원회의 사교육 유사성 검증과 동일** |
| 지나치게 세부적·특수한 지식을 묻지 않는가 | 지엽적 암기 배제 |
| 지나치게 어렵거나 쉽지 않은가 | 난이도 관리 |
| 난이도와 변별도는 적절한가 | P·DI 관리 |

### 5-2. 발문

| 검토 항목 | 대응하는 평가원 현상 |
|---|---|
| **정답 시비가 없도록 필요한 조건이 모두 포함되어 있는가** | **발문·선지가 길어지는 근본 원인** |
| 교과서 문장을 그대로 옮기지 않았는가 | 지문 재구성 |
| **정답에 대한 단서가 제시되어 있지 않은가** | 발문이 답을 흘리지 않음 |
| 부정문을 긍정문으로 바꾸는 게 낫지 않은가 | 부정형 남용 경계 |

### 5-3. 답지 (선지)

| 검토 항목 | 대응하는 평가원 현상 |
|---|---|
| **답지 길이가 너무 다른 것은 없는가** | **정답 선지가 길이로 튀지 않는 이유** |
| 표현이 불필요하게 장황하지 않은가 | — |
| **답지끼리 중복되는 것은 없는가** | 선지 간 배타성 |
| 두 답지에 공통 요소가 있어 단서가 되지 않는가 | — |
| **답지는 논리적 순서에 따라 배열되어 있는가** | 선지가 지문 순서·수치 순서를 따르는 이유 |
| **정답 위치가 특정 답지에 편중되지 않았는가** | **정답 번호 분포 균등화** |

### 5-4. 정답지

| 검토 항목 | 대응하는 평가원 현상 |
|---|---|
| **정답의 근거가 분명하게 제시되어 있는가** | **정답 근거를 지문 문장으로 특정할 수 있는 이유** |
| **관점에 따라 오답이 될 가능성은 없는가** | 해석 여지가 큰 소재 회피 |
| 모르는 학생도 금방 찾을 만큼 평이하지 않은가 | — |
| 답이 없거나 2개 이상이거나 시비 소지는 없는가 | 복수정답 사태 방지 |

### 5-5. 오답지

| 검토 항목 | 대응하는 평가원 현상 |
|---|---|
| 교과서에 없는 너무 생소한 답지는 없는가 | 오답도 지문 어휘 안에서 구성 |
| **관점에 따라 정답이 될 가능성은 없는가** | **오답은 명확히 한 지점에서만 틀린다** |
| **오답지가 모두 발문 내용과 직접 관련이 있는가** | 엉뚱한 오답 없음 |
| **오답지의 매력도가 너무 부족하지 않은가** | **매력적 오답이 필수 요건인 이유** |

## 6. 발문 작성 원리 — 평가원 발문이 그 모양인 이유

`[검증]` 규범의 발문 작성 지침. **관찰된 평가원 발문과 하나하나 일치한다.**

| 규범 | 평가원 발문 |
|---|---|
| 선다형 발문은 **불완전형 의문문**으로 끝맺는다 | "~적절한 것은?" |
| **평가 요소를 발문 끝부분에 배치**해 명확히 인지시킨다 | "윗글에 대한 이해로 **적절하지 않은 것은?**" |
| 발문은 **하나의 문장**으로 단순 명료하게 | 발문이 짧고 정형적 |
| **한 문항에서 묻는 평가 요소는 반드시 하나** | 발문에 요구가 하나뿐 |
| 답지에 반복되는 말은 발문에 넣는다 | "윗글을 바탕으로" 등이 발문에 옴 |
| 제시문 뒤 발문은 **"위 글~"로 통일** | **"윗글의…"** |
| 부정문을 쓸 때는 **부정 단어에 밑줄** | **"적절하지 <u>않은</u> 것은?"** |
| `~하지 못한 것은?`(✕) / `~에 대한 설명으로 적절하지 않은 것은?`(○) | **평가원 표준 발문 그대로** |
| 모든 답지가 부분적으로 맞으면 **'가장'을 붙여 최선답임을 명시** | **"가장 적절한 것은?"** |
| **결과 자체보다 원인·과정을 묻는다** | 인과·메커니즘 문항 |
| '누가·언제·어디서·무엇'보다 **'왜·어떻게'** | 단순 확인 문항 배제 |
| 배점 표시는 발문 마지막 줄 끝에 | **"[3점]"** |
| 발문에 정답 단서가 있으면 안 된다 | — |

`[분석]` **"한 문항에서 묻는 평가 요소는 반드시 하나"**가 특히 중요하다. 이 때문에 발문은 단순해지고, **복잡성은 전부 선지로 밀려난다.** 앞서 여러 차례 관찰한 "지문은 순해지고 선지는 정교해진다"의 제도적 근거가 이것이다.

## 9. 수업에 쓰는 법

### 학생에게 전할 3문장

> 1. **오답은 아무도 안 고르면 실패작이다.** 그래서 오답은 반드시 끌리게 만들어진다. "끌린다"는 건 답이라는 신호가 아니라 조심하라는 신호다.
> 2. **문항 하나가 묻는 건 딱 하나다.** 발문은 단순하다. 복잡한 건 전부 선지에 있다.
> 3. **정답은 지문 어딘가의 문장을 바꿔 쓴 것이다.** 근거를 못 찾으면 그건 정답이 아니다.

### 자작 문항 검수에 그대로 쓴다

`12-item-writing.md`의 체크리스트에 **§5의 검토 관점 전체**를 얹는다. 특히:
- 답지 길이 균등
- 정답 위치 편중 방지
- 오답지 매력도 확보
- 오답지가 발문과 직접 관련
- 관점에 따라 오답이 정답이 될 여지 없음
