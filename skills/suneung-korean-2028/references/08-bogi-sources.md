# 08. `<보기>` — 카테고리와 발췌 출처

`<보기>`는 수능 국어에서 **가장 강력한 출제 장치**다. 지문 밖의 정보를 합법적으로 들여오고, 해석의 자유를 제한해 정답을 하나로 만들고, 3점 배점을 정당화한다. `<보기>`를 이해하면 문항 설계 전체가 보인다.

## 1. `<보기>`가 하는 일 — 4가지 기능

`[분석]`

| 기능 | 설명 | 효과 |
|---|---|---|
| **① 정보 추가** | 지문에 없는 사례·자료·관점을 들여온다 | 지문을 무겁게 하지 않고 난도를 올린다 |
| **② 해석 고정** | "이 작품은 ~을 다룬다"고 못 박는다 | 정답 시비 차단 |
| **③ 적용 요구** | 지문의 원리를 새 사례에 적용시킨다 | 단순 대조를 넘어선 사고 측정 |
| **④ 관점 부여** | 특정 이론·비평 틀을 준다 | 교육과정 성취기준 연결 |

`[분석]` **②가 가장 중요하다.** 문학 작품은 원래 여러 해석이 가능한데, `<보기>`가 "이 방향으로 읽어라"라고 지정하는 순간 정답이 하나로 확정된다. 그래서 문학 `<보기>` 문항의 정답은 **작품이 아니라 `<보기>`가 결정한다.**

> **학생에게**: "`<보기>`는 힌트가 아니라 **명령문**이다. `<보기>`가 시키는 대로 읽어라. 네 감상은 틀린 게 아니라 이 문제에서 물어보는 게 아니다."

## 2. `<보기>` 카테고리 분류

`[분석]` 실제 기출에서 관찰되는 `<보기>`의 유형을 영역별로 정리한다.

### 2-1. 독서(비문학)의 `<보기>`

| 카테고리 | 형태 | 대응 문항 |
|---|---|---|
| **사례형** | 구체적 상황·인물·사건 | 지문 원리를 사례에 적용 |
| **수치·그래프형** | 표, 그래프, 실험 결과 | 변수 관계 판정 |
| **도식형** | 장치 구조도, 과정 흐름도 | 각 부분의 기능 |
| **가상 실험형** | "조건 X를 바꾸면" | 인과 추론 |
| **대조 자료형** | 지문과 다른 입장의 짧은 글 | 비교·비판 |
| **법조문·규정형** | 실제 유사 규정 | 요건 충족 판정 |

`[분석]` 독서 `<보기>` 문항의 정답 판정은 **지문 ↔ `<보기>` 대응표**로 환원된다. 대응표를 그리면 거의 기계적으로 풀린다.

```
지문의 개념 A ─── 보기의 요소 a
지문의 개념 B ─── 보기의 요소 b
지문의 관계 "A↑ → B↓" ─── 보기에서 a가 커졌다면 b는? 
```

### 2-2. 문학의 `<보기>`

`04-literature.md` §4의 5유형을 다시 쓴다:

| 카테고리 | 전형적 첫 문장 | 정답 근거 |
|---|---|---|
| **주제·해석형** | "이 작품은 ~을 형상화하고 있다" | 작품 요소 ↔ 주제 |
| **시대·배경형** | "이 작품이 발표된 1930년대는…" | 작품 요소 ↔ 시대 |
| **이론·개념형** | "문학에서 ~란 …을 말한다" | 개념의 실현 양상 |
| **작가론형** | "이 작가는 ~을 지속적으로…" | 작가 세계 ↔ 작품 |
| **비교형** | "(가)와 (나)는 모두 ~을 다루지만" | 공통점·차이점 |

### 2-3. 화법·작문의 `<보기>`/`<자료>`

| 카테고리 | 형태 |
|---|---|
| **작문 상황·계획** | 목적·독자·주제 메모 |
| **수집 자료** | 통계, 신문 기사, 인터뷰, 전문가 견해, 사례 |
| **초고** | 고쳐쓰기 대상 |
| **청중 반응·질문** | 발표 후 질의 |

### 2-4. 문법의 `<보기>`

| 카테고리 | 형태 |
|---|---|
| **예문 나열형** | ㉠~㉤ 문장, 조건에 맞는 것 고르기 |
| **자료 + 탐구 활동형** | 학생의 탐구 과정, 빈칸 채우기 |
| **중세국어 대조형** | 중세 자료 + 현대어 풀이 |
| **사전 자료형** | 국어사전 표제어·뜻풀이·용례 |

## 3. `<보기>`는 어디서 오는가

`[분석]` + `[확인필요]` — 평가원은 `<보기>`의 출처를 공개하지 않는다. 아래는 텍스트 성격에서 추정한 것이며 단정해서는 안 된다.

### 문학 `<보기>`의 원천으로 보이는 것들

| 원천 | 근거가 되는 특징 | 주로 쓰이는 카테고리 |
|---|---|---|
| **문학사 개설서** | 시대 구분·사조 서술이 정형적 | 시대·배경형 |
| **작품론·작가론 학술 논문** | 해석 진술이 학계 통설과 일치 | 주제·해석형, 작가론형 |
| **문학 이론서** | 개념 정의가 교과서적 | 이론·개념형 |
| **고교 문학 교과서 학습활동·단원 도입** | 성취기준 문구와 어휘가 유사 | 전 카테고리 |
| **평론집** | 비평 언어 | 주제·해석형 |

`[분석]` 다만 결정적인 점은 이것이다: **`<보기>`는 어디서 가져오든 출제진이 다시 쓴다.** 원전을 그대로 붙이면 길이·난도·정답 확정성이 통제되지 않는다. `<보기>`는 대개 3~6문장의 압축된 서술이며, 그 압축 자체가 출제 행위다.

**따라서 "`<보기>` 출처 찾기"는 학생 학습 과제가 될 수 없다.** 교사가 이해를 위해 추적하는 것은 유용하지만, 그것으로 적중을 노릴 수는 없다.

### 독서 `<보기>`의 원천

`[분석]` 대체로 **출제진 자작**이다. 지문 원리에 정확히 대응하도록 설계되어야 하므로 외부 자료를 그대로 쓸 수 없다. 수치·그래프는 지문 원리에 맞춰 만들어진 가상 자료인 경우가 많다.

## 4. `<보기>` 문항 공략 프로토콜

`[분석]` 노베이스에게 그대로 시킬 절차. 예외 없이 적용한다.

### 독서 `<보기>` 문항

```
1) 발문 확인 — "적절하지 않은 것"인가? 부정어에 동그라미
2) <보기>를 먼저 읽는다. 요소마다 기호를 붙인다 (a, b, c…)
3) 지문으로 돌아가 각 요소가 지문의 어느 개념에 대응하는지 표시
4) 대응표를 여백에 그린다
5) 선지를 절 단위로 끊어 대응표와 대조
6) 어긋나면 T 태그를 붙이고 다음 선지로
```

### 문학 `<보기>` 문항

```
1) <보기>를 문장 단위로 쪼개고 번호를 매긴다 (①②③…)
2) 각 문장이 "무엇을 무엇으로 읽으라"는 지시인지 한 줄로 정리
3) 작품에서 그 지시에 해당하는 부분을 찾아 표시
4) 각 선지가 <보기>의 몇 번을 근거로 삼는지 확인
5) <보기> 근거 + 작품 근거가 둘 다 있어야 정답 후보
```

**가장 흔한 실패**: `<보기>`를 읽고 "아 그렇구나" 하고 넘어간 뒤 선지를 작품만 보고 판단한다. `<보기>`를 계속 손가락으로 짚고 있어야 한다.

## 5. `<보기>` 오답 제조 방식

`[분석]`

| 방식 | 설명 | 태그 |
|---|---|---|
| **`<보기>` 이탈** | `<보기>`가 안 준 관점으로 해석 | T12 |
| **대응 어긋남** | `<보기>` 요소를 지문의 다른 개념에 붙임 | T3 |
| **방향 반전** | 대응은 맞는데 증감·인과 방향이 반대 | T2, T1 |
| **`<보기>` 과잉 적용** | `<보기>` 진술을 작품 전체로 확대 | T4 |
| **작품 근거 부재** | `<보기>` 말은 맞는데 작품에 그 장면이 없음 | T8 |
| **양쪽 뒤섞기** | (가)의 요소를 (나)의 `<보기>` 진술과 결합 | T3 |

## 6. 미출제 정전을 다루는 법 (적중 아닌 준비)

`[분석]` "어떤 작품이 나오나"라는 질문에 대한 정직하고 유용한 답:

### 하지 말 것
- 특정 작품 목록을 주며 "이게 나온다"고 말하기
- 적중률을 주장하기

### 할 것
1. **갈래별 정전 목록**을 제공하되 "출제 가능 조건을 만족하는 작품군"으로 설명
2. **이미 출제된 작품**을 정리해 주기 — 재출제 빈도가 높은 갈래(고전시가·고전소설)에서는 이것이 실질적으로 유용하다
3. **처음 보는 작품 대처법**을 훈련시키기 — 이것이 진짜 대비다

### "처음 보는 작품" 대처 절차 (노베이스용)

```
현대시:  화자 찾기 → 대상 찾기 → 태도 한 단어로 → 반복되는 말 표시
고전시가: 화자의 위치(자연/조정) → 지향 대상 → 관습 코드 확인
현대소설: 서술자 확인 → 인물 관계도 → 갈등의 축 → 장면 전환 지점
고전소설: 인물 선악 구분 → 사건 순서 → 서술자 개입 표시
```

이 절차를 몸에 붙이면 작품을 몰라도 세트가 열린다. **적중보다 이쪽이 훨씬 안전한 투자다.**
