# 11. 수업 자료 생성 프로토콜

이 문서는 **산출물의 규격**을 정한다. 어떤 요청이 오든 아래 형식으로 만든다.

## 1. 요청 접수 — 확정할 5가지

작업 시작 전에 다음을 확정한다. 사용자가 안 알려줬고 결과를 크게 바꾸는 항목만 물어본다. 나머지는 기본값으로 가고 **산출물에 기본값을 명시**한다.

| 항목 | 기본값 |
|---|---|
| **대상 수준** | 노베이스(진단 D1~D2 실패 수준) |
| **체제** | 2028 (2022 개정) |
| **영역** | 요청에서 추출 |
| **분량** | A4 4쪽 상당 |
| **용도** | 자습 가능(해설 포함) |

기본값 명시 문구 예:
> 대상: 고1 노베이스 / 체제: 2028 / 분량: A4 4쪽 / 용도: 자습용
> (별도 지정이 없어 기본값으로 작성했습니다.)

## 2. 산출물 표준 구조

모든 학습지는 아래 7블록을 갖는다. 순서를 바꾸지 않는다.

```
① 표지 블록      — 제목, 대상, 영역, 소요 시간, 학습 목표(3개 이내)
② 절차 블록      — 오늘 쓸 절차를 단계로 제시 (설명 아님)
③ 자료 블록      — 지문/작품/담화 (원문, 훼손 금지)
④ 작업 블록      — 표시·요약·대응표 등 손으로 하는 작업
⑤ 문항 블록      — 문항 (있는 경우)
⑥ 해설 블록      — 정답 근거 인용 + 오답별 T태그 해설
⑦ 정리 블록      — 오늘의 한 문장 + 다음에 할 것
```

### 각 블록 규격

#### ① 표지 블록
```
━━━━━━━━━━━━━━━━━━━━━━━━━━
[독서 · 사회] 원칙과 예외 구조 읽기
대상: 노베이스 | 소요: 40분 | 2028 대비

오늘의 목표
1. 법·제도 지문의 골격(E)을 알아본다
2. '다만/단서'에 표시하는 습관을 만든다
3. 조건 문항의 선지를 슬래시로 끊는다
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

목표는 **3개 이내**, 각각 **행동 동사**로. "이해한다" 금지, "표시한다/찾는다/끊는다" 사용.

#### ② 절차 블록
반드시 번호 매긴 단계로. 각 단계는 한 줄.

```
[오늘의 절차]
1) 문단 첫 문장에 밑줄
2) '다만, 단, 그러나, ~인 경우'에 세모
3) 문단 옆에 역할 한 단어 적기 (원칙/요건/예외/사례)
4) 선지는 슬래시로 끊고 각 조각에 O/X/? 표시
```

#### ③ 자료 블록
- 기출이면: **출처를 반드시 명기** — `2025학년도 수능 국어 [10~13]` 형식
- 자작이면: **자작임을 명기** — `※ 이 지문은 학습용 자작 지문입니다`
- 원문 훼손 금지. 생략 시 `(중략)` 표기
- 문단 번호를 왼쪽에 붙인다 (①②③…) — 근거 인용을 위해 필수
- 노베이스용이면 어려운 어휘에 각주

#### ④ 작업 블록
학생이 손으로 채우는 칸. 빈칸을 실제로 만든다.

```
[문단 역할 표]
①문단: ____________
②문단: ____________
③문단: ____________

[골격 판정] A B C D E F G H  ← 하나에 동그라미
근거: ____________________
```

#### ⑤ 문항 블록
- 기출이면 원 발문 그대로
- **발문의 부정어에 굵게 표시**하거나 밑줄
- 배점 표기

#### ⑥ 해설 블록 — 가장 중요

형식을 고정한다. **아래 내용은 형식을 보이기 위한 가상 예시이며 실제 기출이 아니다.**

```
─────────────────────────
[11번] 정답 ③   ※ 아래는 형식 예시(가상 지문·문항)

▷ 정답 근거
  ③문단 "다만 사용자가 명시적으로 동의한 경우에는 이 제한이 적용되지 않는다"
  → 선지 ③의 "동의가 있으면 제한을 벗어난다"와 같은 말

▷ 오답 해설
  ① [T4 범위 확대] ③문단은 "명시적 동의"에 한정. 선지는 "어떤 형태의 
     동의든"으로 넓힘. 지문에 근거 없음
  ② [T6 조건 혼동] 지문은 "제한을 벗어나려면 동의가 필요"(필요조건).
     선지는 "동의하면 항상 벗어난다"(충분조건)로 바꿈
  ④ [T1 인과 역전] ②문단의 원인-결과를 뒤집음
  ⑤ [T8 외삽] 그럴듯하지만 지문에 이 내용 없음

▷ 매력적 오답: ②
  지문 단어를 가장 많이 포함해서 "본 것 같은" 느낌을 준다.
  조건 문제는 항상 '필요/충분'을 확인할 것
─────────────────────────
```

**강제 규칙**:
- 정답 근거는 **문단 번호 + 문장 인용**
- 오답마다 **T태그** (`07-choice-logic.md`)
- **오답 해설 총 분량 > 정답 해설 분량**
- 매력적 오답이 있으면 별도 항목

#### ⑦ 정리 블록
```
[오늘의 한 문장]
법·제도 지문은 '다만'에 답이 있다.

[다음에 할 것]
같은 절차로 2024학년도 9월 [12~16] 세트 풀기
```

## 3. 자료 유형별 변형

### 강의안(교사용)일 때
- ⑥ 해설 블록을 앞으로 당긴다
- **예상 질문과 답변** 블록 추가
- **시간 배분** 명시 (블록별 분 단위)
- `[검증]/[분석]/[확인필요]` 표시를 **지우지 않는다**

### 개념 정리 자료일 때
- ③ 자료 블록 대신 **개념 카드** 블록
- 카드 규격: `개념명 / 한 줄 정의 / 예문 3 / 반례 1 / 판별 절차`

### 오답 클리닉 자료일 때
- 학생의 오답 태그 집계표로 시작
- 상위 2개 태그만 다룬다
- 같은 태그 문항 8~10개를 몰아서 배치

### 모의고사 해설지일 때
- 문항별 해설을 위 ⑥ 형식으로
- 앞에 **총평**: 난도, 시간 배분 진단, 영역별 정답률
- 뒤에 **재풀이 지시**: 어느 문항을 언제 다시 풀지

## 4. 언어 규칙 (노베이스 대상 시)

`10-curriculum-novice.md` §2 원칙 5의 구체화.

### 반드시
- 한 문장 40자 이내
- 한 문장에 새 개념 1개
- 전문 용어 첫 등장 시 괄호 풀이
- 능동태, 현재형
- 지시어 대신 대상 반복

### 금지
- "~라고 할 수 있다" (단정하거나 말거나)
- "여러분도 아시다시피"
- 3중 이상 수식
- 근거 없는 "반드시/항상"
- 겁주기 ("이것도 모르면…")

### 용어 변환 표

| 쓰지 말 것 | 쓸 것 |
|---|---|
| 환언 | 바꿔 쓰기 |
| 대응시키다 | 짝을 짓다 |
| 유기적 | 서로 연결된 |
| 함의 | 담긴 뜻 |
| 개연성 | 그럴듯함 |
| 통사적 | 문장 구조상의 |
| 층위 | 단계 / 수준 |
| 정합적 | 앞뒤가 맞는 |

## 5. 작성 순서 (실무)

효율적인 순서는 이렇다:

```
1) 자료(지문/작품) 확정 → 없으면 자작 (12-item-writing.md)
2) 지문 분석 (골격, 형광펜 지점) → 교사가 먼저 완전히 이해
3) 문항 선정 또는 제작
4) 해설 작성 (오답 태그 먼저!)
5) 절차 블록 작성 (해설에서 역산 — 오늘 필요한 절차가 뭔지 알게 됨)
6) 작업 블록 작성 (절차가 실행되도록 칸 설계)
7) 표지·정리 블록
8) 자체 검수 (assets/self-check.md)
```

**4번을 먼저 하는 이유**: 오답 태그를 뽑아 보면 이 자료가 실제로 무엇을 가르치는지가 드러난다. 그때 절차 블록이 정확해진다. 절차부터 쓰면 해설과 어긋난다.

## 6. 하지 말아야 할 것

| 하지 말 것 | 왜 |
|---|---|
| 기출 지문 요약해서 싣기 | 원문 규격 적응이 목표 |
| 기억으로 기출 복원 | 왜곡 위험. 자작하고 자작이라 밝혀라 |
| "무조건 이렇게 나온다" | `[분석]`을 `[검증]`으로 포장하는 것 |
| 해설에 "지문에서 알 수 있듯" | 근거 특정 회피 |
| 오답 해설 생략 | 노베이스에게 가장 중요한 부분 |
| 정답률·등급컷 예측 | 근거 없음 |
| 특정 작품 적중 주장 | 하지 않는다 |
| 학생용에 `[분석]` 표시 없이 단정 | 사실과 해석의 혼동 |

## 7. 산출물 머리말 규약

원문 코퍼스를 대조하지 않은 상태에서 만든 자료에는 다음을 넣는다:

> ※ 이 자료의 기출 분석은 패턴 분석이며, 문항 단위 원문 대조는 별도로 필요합니다.

자작 지문/문항이 포함되면:

> ※ 이 자료의 지문(문항)은 학습용 자작이며 실제 기출이 아닙니다.

이 두 줄을 생략하지 마라.
