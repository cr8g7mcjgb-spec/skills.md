# 18. 문법 출제 개념 전수 목록과 문항화 방식

`06-grammar.md`가 학습 순서를 다뤘다면, 이 문서는 **개념을 하나도 빠뜨리지 않고 나열하고**, 각 개념이 **어떤 모양의 문항이 되는지**를 붙인다.

`[분석]` 구조 관찰이다. 특정 연도 출제 여부는 표기하지 않는다.

## 1. 음운

### 1-1. 개념 목록

| 개념 | 세부 |
|---|---|
| 음운의 체계 | 자음 19, 모음 21(단모음 10 + 이중모음 11), 조음 위치·방법, 혀 위치·입술 모양 |
| 음절 | 구조(초성·중성·종성), 음절 수 세기 |
| **교체** | 음절의 끝소리 규칙(7종성), 비음화, 유음화, 구개음화, 된소리되기, 반모음화 |
| **탈락** | 자음군 단순화, 'ㅎ' 탈락, 'ㅡ' 탈락, 'ㄹ' 탈락, 동일 모음 탈락 |
| **첨가** | 'ㄴ' 첨가, 반모음 첨가, 사잇소리 현상 |
| **축약** | 거센소리되기(자음 축약), 모음 축약 |
| 변동의 순서 | 두 개 이상 적용 시 순서 |
| 음운 개수 변화 | 변동 전후 증감 |
| 표준 발음 | 표기 ↔ 발음 대응 |

### 1-2. 문항화 방식

```
[유형1] "<보기>의 ㉠~㉤ 중 [교체/탈락/첨가/축약]이 일어난 것은?"
[유형2] "㉠에서 일어난 음운 변동의 횟수는?"
[유형3] "음운 변동 전후 음운의 개수가 달라진 것은?"
[유형4] "㉠과 ㉡에 공통으로 적용된 음운 변동은?"
[유형5] 지문형 — 특정 변동의 조건을 설명한 뒤 사례 판정
```

### 1-3. 함정 지점

| 함정 | 설명 |
|---|---|
| 한 단어에 변동 **2회 이상** | '값어치', '맞히다' 등 |
| 축약은 음운 개수 **감소**, 탈락도 감소 — 구분 | 축약은 두 음운이 하나로, 탈락은 하나가 사라짐 |
| 된소리되기의 **조건 구분** | 어간말 자음 뒤 / 관형사형 '-(으)ㄹ' 뒤 / 한자어 'ㄹ' 뒤 |
| 사잇소리는 **필수가 아님** | 예측 불가 |
| 구개음화는 **형식형태소** 앞에서만 | '밭이'(○) vs '밭이랑'(경우에 따라) |

## 2. 형태 — 단어 형성

### 2-1. 개념 목록

| 개념 | 세부 |
|---|---|
| 형태소 | 자립/의존, 실질/형식 |
| 어근·접사 | 접두사, 접미사 |
| 단일어·복합어 | 파생어, 합성어 |
| 파생 | 접두 파생, 접미 파생, 품사 유지/변경, 통사 구조 변경(사동·피동) |
| 합성 | 통사적/비통사적, 대등/종속/융합 |
| 직접 구성 요소 | 2분지 분석 |
| 어간·어미 | 활용, 규칙/불규칙 |
| 불규칙 | ㅅ, ㄷ, ㅂ, 르, 우 불규칙 / 여, 러, 오 불규칙 / ㅎ 불규칙 |

### 2-2. 문항화 방식

```
[유형1] "㉠~㉤ 중 파생어인 것은?"
[유형2] "㉠의 직접 구성 요소를 바르게 분석한 것은?"
[유형3] "합성어의 유형이 나머지와 다른 것은?"
[유형4] "㉠과 ㉡에 쓰인 접사의 기능이 같은 것은?"
[유형5] 사전 자료를 주고 표제어·파생 관계 판정
```

### 2-3. 함정 지점

- **직접 구성 요소 순서**: '헛웃음'은 [헛+웃음]인가 [헛웃+음]인가
- **접두사 vs 관형사**: '새-'(접두) vs '새'(관형사) — 띄어쓰기와 분리 가능성
- **접미사의 품사 바꿈**: '-이/-음'(명사 파생) vs 명사형 어미 '-(으)ㅁ'
- **비통사적 합성어**: '높푸르다', '검붉다', '여닫다' — 연결어미 없이 결합
- **어근 + 어근인데 의미가 제3의 것**: 융합 합성어 '밤낮(늘)'

## 3. 품사

### 3-1. 9품사와 판별 기준

| 품사 | 판별 |
|---|---|
| 명사 | 조사 결합, 관형어 수식 |
| 대명사 | 지시·인칭 |
| 수사 | 수량·순서, 조사 결합 |
| 동사 | 현재형 '-는-' 결합 가능 |
| 형용사 | '-는-' 불가, 명령·청유 불가 |
| 관형사 | **활용 안 함**, 체언만 수식, 조사 결합 불가 |
| 부사 | 용언·문장 수식, 일부 조사 결합 가능 |
| 조사 | 격조사·보조사·접속조사 |
| 감탄사 | 독립 |

### 3-2. 최다 함정 5가지

1. **관형사 vs 형용사**: '다른 사람'(관형사) vs '나와 다른 생각'(형용사 활용형)
2. **동사 vs 형용사**: '늙다'(동사), '젊다'(형용사) / '있다'는 둘 다
3. **의존명사 vs 조사·어미**: '아는 것', '할 수', '먹을 만큼' ↔ '너만큼'
4. **부사 vs 부사어**: 품사와 문장 성분의 층위 구분
5. **조사 vs 접사**: '학생답다'의 '-답-'(접사) vs '까지'(조사)

## 4. 문장 — 성분과 구조

### 4-1. 개념 목록

| 개념 | 세부 |
|---|---|
| 주성분 | 주어, 서술어, 목적어, 보어 |
| 부속성분 | 관형어, 부사어 |
| 독립성분 | 독립어 |
| 서술어 자릿수 | 1~3자리 |
| 홑문장·겹문장 | |
| **안은문장** | 명사절, 관형절, 부사절, 서술절, 인용절 |
| 관형절 | 관계 관형절 / 동격(내용) 관형절 |
| **이어진문장** | 대등적(나열·대조·선택), 종속적(원인·조건·양보·목적) |
| 성분의 생략·중복 | |
| 문장의 중의성 | 수식 범위, 비교 대상, 부정 범위 |

### 4-2. 문항화 방식

```
[유형1] "㉠의 안긴문장의 종류는?"
[유형2] "㉠~㉤ 중 서술어의 자릿수가 다른 것은?"
[유형3] "㉠과 같은 방식으로 이어진 문장은?"
[유형4] "㉠에서 생략된 성분을 바르게 복원한 것은?"
[유형5] "㉠의 관형절이 수식하는 말과 관형절의 관계는?"
```

### 4-3. 함정 지점

| 함정 | 설명 |
|---|---|
| **서술절** | '코끼리는 코가 길다' — 안긴문장이 서술어 역할. 가장 많이 놓친다 |
| 부사절과 종속적으로 이어진 문장의 경계 | '-게, -도록, -이' |
| 관형절의 **관계/동격** | 성분이 생략되었으면 관계 관형절 |
| 인용절의 **간접 인용 전환** | 인칭·시제·종결어미·조사 '고/라고' 변화 |
| 서술어 자릿수의 **의미별 차이** | '보다'가 1·2·3자리 모두 가능 |
| 필수적 부사어 | '되다, 삼다, 여기다' 앞 |

### 4-4. 노베이스 훈련 절차 (재수록)

```
1) 서술어에 전부 동그라미     → 개수 = 절 개수
2) 2개 이상이면 겹문장
3) 각 서술어의 주어를 찾아 선 연결
4) 어느 절이 어느 절 안에 있는지 [ ]로 표시
5) 안겼으면 종류 판정 / 이어졌으면 대등·종속 판정
```

## 5. 문법 요소

### 5-1. 높임

| 종류 | 실현 |
|---|---|
| 주체 높임 | 선어말어미 '-시-', 조사 '께서', 접미사 '-님', 특수 어휘(계시다·잡수시다·주무시다) |
| 간접 높임 | 주체의 신체·소유물 등 '말씀이 있으시다' |
| 객체 높임 | 특수 어휘(뵙다·드리다·모시다·여쭈다), 조사 '께' |
| 상대 높임 | 종결어미 — 하십시오체/하오체/하게체/해라체 / 해요체/해체 |
| 압존법 | |

**함정**: 간접 높임에 '계시다'를 쓰면 잘못('말씀이 계시다' ✕ → '있으시다' ○). 이 지점이 반복 출제된다.

### 5-2. 시간 표현

| 종류 | 실현 |
|---|---|
| 과거 | '-았/었-', '-더-', 관형사형 '-(으)ㄴ' |
| 현재 | '-는-/-ㄴ-', 관형사형 '-는' |
| 미래·추측 | '-겠-', '-(으)ㄹ 것이-', 관형사형 '-(으)ㄹ' |
| 동작상 | 진행('-고 있다', '-는 중이다'), 완료('-아/어 있다', '-아/어 버리다') |

**함정**: '-았-'이 과거가 아닌 **완료·상태 지속**('닮았다', '앉았다')을 나타내는 경우. '-겠-'이 미래가 아닌 **의지·추측·완곡**을 나타내는 경우.

### 5-3. 피동·사동

| 종류 | 실현 |
|---|---|
| 파생적 피동 | '-이-, -히-, -리-, -기-' |
| 통사적 피동 | '-아/어지다', '-게 되다' |
| 파생적 사동 | '-이-, -히-, -리-, -기-, -우-, -구-, -추-' |
| 통사적 사동 | '-게 하다' |

**함정 3가지**
1. **이중 피동**: '보여지다', '쓰여지다' — 잘못된 표현
2. **형태는 같고 기능이 다름**: '보이다'가 피동/사동 둘 다
3. **사동 접미사가 붙었지만 사동이 아닌 경우**: '먹이(명사)'

### 5-4. 부정

| 종류 | 실현 |
|---|---|
| '안' 부정 | 의지·단순 부정 / 짧은 부정 '안', 긴 부정 '-지 아니하다' |
| '못' 부정 | 능력·외부 원인 / '못', '-지 못하다' |
| '말다' 부정 | 명령·청유 |

**함정**: 부정의 **범위 중의성** — '학생들이 다 오지 않았다'

### 5-5. 인용

- 직접 인용 '라고' / 간접 인용 '고'
- 전환 시 변하는 것: **인칭 대명사, 시간 표현, 종결어미, 지시어, 높임**

## 8. 국어사 (중세국어)

### 8-1. 표기·음운

| 항목 | 내용 |
|---|---|
| 소실 문자 | ㆍ(아래아), ㅸ(순경음 비읍), ㅿ(반치음), ㆆ(여린히읗) |
| 방점 | 평성·거성·상성 표시 |
| 이어적기(연철) | '사ᄅᆞ미' |
| 끊어적기(분철) | '사람이' |
| 거듭적기(중철) | '사ᄅᆞᆷ미' |
| 어두 자음군 | 'ᄡ, ᄠ' 등 |
| 모음조화 | 양성·음성 |
| 8종성법 | |

### 8-2. 문법

| 항목 | 내용 |
|---|---|
| 주격조사 | '이 / ㅣ / Ø' (선행 음운 조건) |
| 목적격조사 | 'ᄋᆞᆯ/을/ᄅᆞᆯ/를' |
| 관형격조사 | 'ᄋᆡ/의' (유정·평칭), 'ㅅ'(무정·존칭) |
| 객체 높임 | '-ᄉᆞᆸ-/-ᄌᆞᆸ-/-ᅀᆞᆸ-' |
| 주체 높임 | '-시-' |
| 상대 높임 | 'ᄒᆞ쇼셔체' 등 |
| 명사형 어미 | '-옴/움' |
| 의문법 | 판정 의문 '-가', 설명 의문 '-고' / 2인칭 '-ㄴ다' |

### 8-3. 문항화

```
중세 자료 + 현대어 풀이 병기 → 표기·음운·문법 요소의 차이 판정
때로 근대국어 자료를 끼워 3단 비교(중세 → 근대 → 현대)
```

**함정**: 현대어 풀이가 주어지므로 **해석은 문제가 아니다.** 묻는 것은 항상 **형태의 차이**다. 겁먹고 해석하려 들면 시간을 잃는다.

## 10. 지문형 문법 세트 — 별도 대응이 필요하다

`[분석]` 문법 지식보다 **독해력**을 요구하는 유형. 2028에서 비중이 커질 가능성이 높다.

### 지문의 전형

```
① 학교문법의 통상적 설명 제시
② 그 설명으로 처리되지 않는 사례 제시
③ 대안적 기준·분류 제시
④ 그 기준으로 사례 재분류
```

### 문항

```
[문항1] 지문 내용 이해 — 개념 정의, 기준의 차이
[문항2] 지문의 기준을 <보기> 사례에 적용
```

### 공략

**지문에 나온 기준만 쓴다.** 학교문법 지식으로 판단하면 틀린다 — 지문이 학교문법과 **다른 기준**을 제시했을 수 있기 때문이다. 이것이 지문형 최대 함정이다.

> **학생에게**: "문법 지문은 문법 문제가 아니다. 지문이 새 규칙을 알려주고, 그 규칙대로 하라는 것이다. 네가 아는 문법은 잠깐 접어라."

## 11. 2028 대비 우선순위 재조정

`[분석]` 문법이 필수화되고 담화 결합형이 등장한 것을 반영한 순위.

| 순위 | 단원 | 이유 |
|---|---|---|
| 1 | **문장 구조(겹문장·안긴문장)** | 모든 문장 관련 문항의 토대 |
| 2 | **문법 요소 5종** | 담화 결합형의 재료. 2028에서 중요도 상승 |
| 3 | **담화** | '화법과 언어' 융합의 핵심 |
| 4 | 음운 변동 | 출제 안정적 |
| 5 | 품사 | 토대 |
| 6 | 단어 형성 | |
| 7 | 지문형 대응 훈련 | 독해로 접근 |
| 8 | 중세국어 | 비중 대비 학습량 과다 주의 |
| 9 | 어문 규정 | 얹혀 나옴 |

**2027 이전 대비와 달라진 점**: 담화가 3위로 올라왔다. 옛 언매 대비에서는 거의 다루지 않던 단원이다.
