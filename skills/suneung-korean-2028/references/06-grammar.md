# 06. 언어(문법) — 좁고 깊고 반복되는 영역

## 1. 이 영역의 성격

`[검증]` 2028학년도부터 문법은 **'화법과 언어'의 일부로 전원 필수**다. 2022~2027 체제에서 '화법과 작문'을 선택해 문법을 피했던 학생층이 사라진다.

`[분석]` 문법은 **출제 범위가 가장 좁고 반복이 가장 심한 영역**이다. 그래서 노베이스에게 **투자 대비 회수율이 가장 높다.** 동시에, 개념을 모르면 손도 못 대기 때문에 **가장 먼저 붕괴하는 영역**이기도 하다. 문법은 "이해"가 아니라 "장착"이다.

## 2. 출제 단원 지도

`[분석]` 33년 기출에서 반복되는 단원과 빈도 체감:

| 단원 | 빈도 | 세부 |
|---|---|---|
| **음운** | 매우 높음 | 음운 변동(교체·탈락·첨가·축약), 음절, 된소리되기, 구개음화, 비음화, 유음화, 사잇소리 |
| **단어 형성** | 높음 | 어근·접사, 파생어·합성어, 직접 구성 요소 |
| **품사** | 높음 | 9품사 구분, 특히 관형사vs형용사, 조사vs어미, 의존명사 |
| **문장 성분·구조** | 매우 높음 | 주성분·부속성분, 겹문장(안은문장/이어진문장), 안긴문장의 종류 |
| **문법 요소** | 매우 높음 | 높임(주체·객체·상대), 시제·상, 피동·사동, 부정, 인용 |
| **단어 의미** | 중간 | 다의어·동음이의어, 의미 관계 |
| **국어사(중세국어)** | 높음 | 표기·음운·문법 요소의 통시적 비교 |
| **한글 맞춤법·표준어** | 중간 | 규정 적용 |
| **담화** | 낮음~중간 | 지시·대용, 발화 맥락 |

`[분석]` **문법 문항 중 절반 이상이 '문장 구조 + 문법 요소 + 음운 변동' 세 곳에서 나온다.** 노베이스는 여기부터 시작한다.

## 3. 문항 유형 3종

### 유형 A — 단독 개념 문항
- 발문: "다음 중 ~에 해당하는 것은?"
- `<보기>`에 예문 여러 개, 조건에 맞는 것 고르기
- 개념을 알면 즉시 풀림. **가장 확실한 득점처**

### 유형 B — 지문형 문법 세트 (독서형 문법)
`[분석]` 2015 개정 체제에서 정착한 형태. 문법 설명 지문(1~2문단)을 주고 **2문항**을 붙인다.

- 지문: 특정 문법 현상에 대한 설명 (때로 학교문법과 다른 관점 소개)
- 문항 1: 지문 내용 이해
- 문항 2: 지문 원리를 `<보기>`의 사례에 적용

**핵심**: 이 유형은 **문법 지식보다 독해력**을 요구한다. 지문에 개념이 다 설명되어 있으므로, 배경지식이 없어도 지문만 정확히 읽으면 풀린다.

> **노베이스에게 중요**: "문법 몰라도 지문형은 풀 수 있다"는 사실을 알려줘야 한다. 문법 포기 학생이 지문형까지 버리는 것이 최대 손실이다.

### 유형 C — 중세국어 대조
- 중세국어 자료 + 현대국어 대응
- 묻는 것: 표기·음운·문법 요소의 차이
- 필수 지식: 아래아(·), 순경음 비읍(ㅸ), 방점, 이어적기/끊어적기/거듭적기, 주격조사 '이/ㅣ/Ø', 객체높임 '-습-/-잡-/-옵-'
- **`<보기>`에 현대어 풀이가 함께 주어지는 것이 표준**이므로, 겁먹지 말고 대조하면 된다

## 4. 오답 제조 방식

`[분석]` 문법 오답은 다른 영역과 다르다. **개념 경계를 건드린다.**

| 유형 | 방식 | 예 |
|---|---|---|
| **경계 침범** | 인접 개념으로 오분류 | 파생어를 합성어로, 부사어를 관형어로 |
| **조건 누락** | 성립 조건 중 하나를 빼고 판정 | 사동 접미사가 붙었지만 사동이 아닌 경우 |
| **예외 무시** | 규칙의 예외를 규칙으로 처리 | |
| **분석 단위 오류** | 직접 구성 요소를 잘못 자름 | '헛웃음' → [헛+웃음] vs [헛웃+음] |
| **T4 전칭화** | "모든 ~는" | |
| **적용 오류(유형 B)** | 지문 원리를 사례에 잘못 대응 | T12 |

## 6. 노베이스용 문법 학습 설계

`[분석]` 문법은 **선형 학습이 통하는 유일한 영역**이다. 순서를 지켜라.

| 단계 | 내용 | 기간 |
|---|---|---|
| 1 | 품사 9개 구분 | 1주 |
| 2 | 문장 성분 + 서술어 자릿수 | 1주 |
| 3 | 겹문장(안은/이어진) — **최중요** | 2주 |
| 4 | 문법 요소 5종(높임·시제·피동·사동·부정) | 2주 |
| 5 | 단어 형성 | 1주 |
| 6 | 음운 변동 | 2주 |
| 7 | 중세국어 기초 | 1주 |
| 8 | 지문형 세트 훈련 | 2주 |
| 9 | 기출 유형별 반복 | 지속 |

**3단계(겹문장)에서 대부분 이탈한다.** 여기에 시간을 아끼지 마라. 안긴문장을 못 찾으면 문장 관련 문항 전체가 죽는다.

### 노베이스용 겹문장 훈련법

```
1) 문장에서 서술어를 모두 찾아 동그라미 (서술어 개수 = 절 개수)
2) 서술어가 2개 이상이면 겹문장
3) 각 서술어의 주어를 찾아 연결
4) 어느 절이 어느 절 안에 들어가 있는지 괄호로 표시
```

이 4단계를 100문장 반복시킨다. 강의보다 반복이 낫다.

## 7. 문법 학습의 함정

`[분석]`

- **함정 1**: 개념을 "이해"하려다 시간을 다 쓴다. 문법은 **판별 기준을 외우고 적용**하는 것이다. 왜 그런지는 나중에 이해해도 된다.
- **함정 2**: 예외를 먼저 배운다. 규칙 → 반복 → 예외 순서를 지킨다.
- **함정 3**: 지문형 세트를 문법 지식으로 풀려 한다. 지문형은 독해다.
- **함정 4**: 중세국어를 과대평가한다. 출제 비중 대비 학습량이 과하게 배정되는 대표 영역이다.
