# 16. 문학 정전 지도 — 무엇이 나오는 풀인가

`[분석]` 이 문서는 **평가원이 다뤄온 작품군**을 갈래별로 정리한 것이다. 특정 연도 출제 여부는 표기하지 않는다(원문 대조 없이 연도를 매칭하면 왜곡이 생긴다). **"이 범위 안에서 나온다"는 지도**로 쓴다.

적중 목적이 아니다. 목적은 둘이다.
1. 학습 자원을 **어디에 몰아야 하는지** 정한다
2. **처음 보는 작품**이 나와도 갈래 관습으로 뚫는다

---

## 1. 고전시가 — 가장 좁고 가장 반복되는 풀

**여기가 투자 대비 회수율 1위다.** 실질 출제 가능 작품이 수십 편 수준이고, 재출제가 잦다.

### 1-1. 가사

| 계열 | 대표 작품군 | 출제 포인트 |
|---|---|---|
| 강호가사 | 상춘곡(정극인), 면앙정가(송순), 성산별곡(정철) | 자연 완상 + 임금 은혜, 계절 이동 |
| 연군가사 | 사미인곡·속미인곡(정철), 만분가(조위) | 여성 화자 = 신하, 임 = 임금 |
| 기행가사 | 관동별곡(정철), 일동장유가(김인겸), 연행가(홍순학), 북새곡(구강) | 여정에 따른 서술, 견문과 감상 |
| 유배가사 | 만언사(안조환), 북천가(김진형) | 자책 + 임금 그리움 |
| 규방가사 | 규원가(허난설헌), 봉선화가 | 여성의 한, 규방 소재 |
| 농부가사 | 농가월령가(정학유) | 월령체, 농사 절기 |
| 현실비판 | 용부가, 우부가, 갑민가 | 풍자, 세태 비판 |

### 1-2. 시조

| 계열 | 대표 | 포인트 |
|---|---|---|
| 강호한정 | 어부사시사(윤선도), 오우가(윤선도), 도산십이곡(이황), 고산구곡가(이이) | 연시조 구성, 각 수의 관계 |
| 절의·충절 | 단심가, 하여가, 사육신 시조 | 상징 해독 |
| 회고 | 오백년 도읍지(길재), 흥망이 유수하니(원천석) | 맥수지탄 |
| 사설시조 | 작자 미상 다수 | 해학·풍자, 열거·과장, 서민 정서 |
| 훈민·교훈 | 훈민가(정철), 오륜가 | 계몽적 어조 |

`[분석]` **연시조는 "각 수가 무엇을 맡는가"가 문항이 된다.** 어부사시사의 계절 배열, 도산십이곡의 언지/언학 구분 같은 것.

### 1-3. 향가·고려가요·한시

| 갈래 | 작품 | 포인트 |
|---|---|---|
| 향가 | 제망매가, 찬기파랑가, 서동요, 처용가 | 10구체 낙구 감탄사 |
| 고려가요 | 청산별곡, 가시리, 서경별곡, 정석가, 동동, 사모곡 | 후렴구 기능, 3음보 |
| 경기체가 | 한림별곡 | 열거, "위 ~ 景 긔 엇더ᄒ니잇고" |
| 한시 | 정지상 송인, 최치원 추야우중, 이규보·정약용 작품 | 기승전결, 선경후정 |

### 1-4. 반드시 장착할 고전시가 어휘

```
어즈버(아아)  아ᄒᆡ(아이)  괴다(사랑하다)  녀다(가다)  하다(많다/크다)
슬ᄏᆞ장(실컷)  ᄒᆞ노라(하노라)  이시라(있으라)  삼기다(생기다)
백구(갈매기)  어옹(어부)  초려(초가)  강호(자연)  홍진(속세)
님(임금)  구름(간신)  ᄃᆞᆯ(임금/충신)  옥황(임금)
매화·국화·송죽(지조)  두견·접동새(한)  기러기(소식/외로움)
```

## 2. 고전소설 — 유형이 곧 해독 키

### 2-1. 유형별 작품군

| 유형 | 작품 | 구조 상수 |
|---|---|---|
| 영웅·군담 | 유충렬전, 조웅전, 소대성전, 김원전, 홍계월전, 박씨전 | 고귀한 혈통 → 시련 → 조력자 → 승리 |
| 가정·쟁총 | 사씨남정기, 창선감의록, 장화홍련전 | 처첩 갈등, 계모 모해, 진실 규명 |
| 애정 | 운영전, 춘향전, 숙영낭자전, 이생규장전 | 신분 장벽, 재회 |
| 판소리계 | 춘향전, 흥부전, 심청전, 토끼전(수궁가), 적벽가 | 율문체, 장면 확장, 해학 |
| 몽자류·환몽 | 구운몽, 옥루몽, 조신몽 | 입몽-각몽, 깨달음 |
| 우화·풍자 | 장끼전, 두껍전, 서동지전 | 동물 의인, 세태 비판 |
| 한문 단편 | 박지원(허생전·양반전·호질), 이옥, 김려 | 풍자, 서술자 논평 |
| 전기(傳奇) | 금오신화 계열 | 비현실적 사건의 자연스러운 서술 |

### 2-2. 반드시 가르칠 고전소설 상투 표현

```
차설 / 각설 / 화설            — 장면 전환 신호
이때 / 이윽고 / 문득           — 시간 전환
어찌 아니 ~하리오              — 편집자적 논평(설의)
슬프다, ~여                    — 서술자 개입
차마 ~지 못하더라              — 인물 심리 요약 제시
과연 ~이러라                   — 서술자 판단
~하니 이는 ~ 때문이라           — 서술자 해설
```

`[분석]` **"서술자의 개입이 나타난다"는 선지는 위 표현의 유무로 판정된다.** 이것만 가르쳐도 고전소설 표현 문항이 열린다.

## 3. 현대시 — 정전 편중이 뚜렷하다

### 3-1. 시대·계열별

| 계열 | 시인 |
|---|---|
| 1920~30년대 서정 | 김소월, 한용운, 정지용, 백석, 이용악 |
| 모더니즘 | 김기림, 김광균, 이상, 오장환 |
| 생명파·청록파 | 서정주, 유치환, 박목월, 박두진, 조지훈 |
| 저항·현실 | 이육사, 윤동주, 신동엽, 김수영 |
| 전후 | 박인환, 구상, 김종삼 |
| 1960~80년대 | 신경림, 정희성, 고은, 황동규, 김지하 |
| 생태·일상 | 정현종, 김광규, 최승호, 고재종, 이시영 |
| 여성 시 | 김남조, 나희덕, 천양희, 문정희, 정끝별 |

`[분석]` **작고 시인 비중이 높다** — 저작권 처리가 수월하기 때문. 다만 생존 시인 작품도 꾸준히 나온다.

### 3-2. 현대시 세트의 짝 짓기 규칙

평가원은 두 편을 묶을 때 **공통 화제 + 다른 태도**로 고른다.

| 짝 유형 | 예시 축 |
|---|---|
| 같은 소재, 다른 태도 | 자연을 대하는 관조 vs 합일 |
| 같은 정서, 다른 방식 | 상실감을 직설 vs 절제 |
| 시 + 수필 | 같은 대상에 대한 산문적 성찰 |
| 시 + 평론 | 작품과 그 해석 |
| 현대시 + 고전시가 | 자연·이별·시간이라는 공통 화제 |

**따라서 (가)(나) 문항은 "무엇이 같고 무엇이 다른가"로 환원된다.**

## 4. 현대소설 — 가장 넓은 풀, 그래서 대처법이 답

### 4-1. 계열별

| 계열 | 작가 |
|---|---|
| 근대 초기 | 이광수, 김동인, 현진건, 염상섭, 나도향 |
| 1930년대 | 이상, 박태원, 채만식, 김유정, 이태준, 이효석 |
| 해방·전후 | 황순원, 손창섭, 오상원, 하근찬, 선우휘 |
| 1960~70년대 | 김승옥, 이청준, 최인훈, 박태순, 황석영, 조세희, 윤흥길 |
| 1980~90년대 | 임철우, 양귀자, 박완서, 오정희, 이문열 |
| 근래 | 성석제, 김애란, 김소진, 은희경 |

`[분석]` **현대소설은 "처음 보는 작품"이 나오는 것이 정상이다.** 작품 암기로 대비하는 영역이 아니다. → `08-bogi-sources.md` §6의 대처 절차를 훈련시킨다.

### 4-2. 반복되는 주제 축

```
산업화와 공동체 해체 / 도시 빈민 / 이농
분단과 이념 대립 / 전쟁의 상흔
가족 내 갈등 / 세대 간 단절
소시민의 위선과 자기 합리화
지식인의 무력감 / 부끄러움
근대화와 전통의 충돌
```

`<보기>`가 이 축 중 하나를 지정해 주는 것이 표준이다.

## 5. 극·시나리오 — 좁지만 용어를 모르면 못 푼다

| 갈래 | 작품군 |
|---|---|
| 희곡 | 이강백(파수꾼·결혼), 오영진(맹진사댁 경사), 차범석, 유치진, 함세덕 |
| 시나리오 | 각색 시나리오(오발탄 등), 창작 시나리오 |
| 전통극 | 봉산탈춤, 꼭두각시놀음 |

**필수 용어** — 1회 정리로 충분하다.
```
S#(장면 번호)  F.I.(페이드인)  F.O.(페이드아웃)  O.L.(오버랩)
E.(효과음)  N.A.(내레이션)  C.U.(클로즈업)  INS.(인서트)
몽타주  플래시백  지시문(지문)  방백  독백
```

**전통극 상수**: 재담, 언어유희, 관객에게 말 걸기, 양반 풍자, 비판 대상의 희화화

## 6. 수필·교술 — 짝으로 나온다

| 유형 | 작품군 |
|---|---|
| 고전수필 | 이규보(경설·이옥설·슬견설), 이곡(차마설), 박지원(일야구도하기), 유한준, 이이, 정약용 서간 |
| 현대수필 | 이양하, 피천득, 법정, 이상, 김소운, 나희덕 |
| 기행·일기 | 의유당관북유람일기, 산성일기, 계축일기 |

`[분석]` **고전수필의 구조는 거의 고정이다**: 체험/사물 관찰 → 유추 → 깨달음 → 일반화. "설(說)" 계열은 전부 이 틀이다. 이 구조 하나로 처음 보는 작품도 읽힌다.

## 7. 학습 자원 배분 권고

`[분석]` 갈래별로 **투자 방식이 달라야 한다.**

| 갈래 | 전략 | 이유 |
|---|---|---|
| 고전시가 | **작품 암기 + 어휘 암기** | 풀이 좁고 재출제 잦다 |
| 고전소설 | **유형 + 상투 표현 암기** | 개별 작품보다 유형이 반복 |
| 현대시 | **정전 시인 중심 + 기법 사전** | 풀이 넓지만 편중 있음 |
| 현대소설 | **대처 절차 훈련** | 암기 불가능한 넓이 |
| 극 | **용어 1회 정리** | 빈도 낮음 |
| 수필 | **구조 1개 암기** | 설(說) 구조가 전부 |

**가장 흔한 실수**: 현대소설을 암기로 대비하려다 시간을 다 쓴다. 반대로 고전시가를 "어차피 모르는 게 나온다"며 포기한다. **정확히 거꾸로 해야 한다.**

## 8. 자료 만들 때

- [ ] 작품을 소개할 때 **갈래 유형**을 먼저 말했는가
- [ ] 고전이면 어휘 풀이를 달았는가
- [ ] 유형 상수(영웅소설의 구조, 설의 구조 등)를 함께 제시했는가
- [ ] "이게 나온다"는 적중 주장을 하지 않았는가
- [ ] 현대소설이면 **처음 보는 작품 대처 절차**를 붙였는가
- [ ] 저작권 — 현대 작품 전문 게재를 피했는가
