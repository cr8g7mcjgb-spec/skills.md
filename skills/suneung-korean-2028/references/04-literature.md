# 04. 문학 — 작품 선정과 세트 설계

문학은 **가장 예측 가능한** 영역이다. 작품 풀(pool)이 유한하고, 문항 유형이 고정되어 있고, `<보기>`의 문법이 명시적이기 때문이다. 노베이스가 가장 빨리 점수를 올릴 수 있는 곳도 여기다.

## 1. 문학 세트의 구성 규칙

`[분석]` 현행(2022~2026) 기준 문학은 15문항 안팎이며, 대체로 4개 세트로 나뉜다.

### 전형적 세트 편성

| 세트 | 구성 | 문항 수 |
|---|---|---|
| 고전시가 (+ 수필/한시 복합) | 고전시가 1~2편, 때로 고전수필 결합 | 3~4 |
| 현대시 (때로 현대시 2편, 또는 시+수필) | | 3 |
| 고전소설 | 단독 | 3 |
| 현대소설 | 단독 | 3~4 |
| (일부 연도) 극·시나리오 | 소설 세트를 대체하거나 복합 | 3 |

`[분석]` **갈래 복합**이 표준화되었다. "고전시가 + 고전수필", "현대시 + 현대수필", "시 + 평론" 조합이 자주 나온다. 이유는 하나의 `<보기>`로 두 작품을 묶어 비교 문항을 만들 수 있기 때문이다.

### 세트 안 문항 배열의 전형

```
① 표현상 특징 / 서술상 특징 (형식)
② 작품 내용 이해 — 화자·인물·상황
③ 특정 구절(㉠~㉤) 이해
④ <보기> 감상 (3점) ← 세트의 중심
```

**`<보기>` 문항이 세트의 설계 출발점이다.** 출제진은 `<보기>`를 먼저 정하고 거기서 역산해 작품을 고르는 경우가 많다. `[분석]`

## 2. 작품 선정의 원리

`[분석]` "무엇이 나오는가"보다 **"왜 그것이 나올 수 있는가"**를 가르쳐야 한다.

### 선정 필터 (모두 통과해야 출제 가능)

1. **정전성(canonicity)** — 문학사적으로 위상이 확립되어 있을 것. 교과서·문학사·연구 축적이 있어야 `<보기>`를 쓸 수 있다
2. **해석 안정성** — 연구자 간 해석이 크게 갈리지 않을 것. 갈리면 정답 시비가 난다
3. **분량 적합성** — 지문으로 잘라낼 수 있는 완결된 단락이 있을 것
4. **문항 산출 가능성** — 표현 기법, 인물 관계, 시상 전개 등 물을 거리가 3개 이상
5. **정치적 안전성** — 현대사·이념 논쟁을 직접 자극하지 않을 것
6. **저작권 처리 가능성** — 현대 작품일수록 제약. 그래서 **작고한 작가 작품 비중이 높다**

### 갈래별 풀의 크기 `[분석]`

| 갈래 | 실질 출제 가능 풀 | 성격 |
|---|---|---|
| 고전시가 | 좁음 (수십 편 수준) | **반복 출제 필연.** 학습 효율 최고 |
| 고전소설 | 중간 | 영웅소설·가정소설·판소리계 등 유형이 반복 |
| 현대시 | 넓지만 정전 편중 | 정전 시인 중심 |
| 현대소설 | 넓음 | 신인 작품도 등장 가능 |
| 극·시나리오 | 매우 좁음 | 출제 빈도 자체가 낮음 |
| 수필·교술 | 넓음 | 복합 세트의 짝으로 주로 등장 |

**노베이스 지도 전략**: 고전시가·고전소설에 학습 자원을 몰아준다. 풀이 좁아서 투자 대비 회수율이 가장 높다. 현대소설은 "처음 보는 작품"을 전제로 **읽는 법**을 훈련한다.

### 미출제 정전을 다루는 법

"앞으로 나올 작품"을 예언하지 마라. 대신 이렇게 말한다:

> "평가원은 문학사에서 위상이 확립되고 해석이 안정된 작품을 쓴다. 그 조건을 만족하는데 아직 안 나온 작품이 있다면 후보군이다. 하지만 적중은 목표가 아니다 — 처음 보는 작품도 풀 수 있게 만드는 것이 목표다."

## 3. 갈래별 출제 문법

### 3-1. 현대시

**묻는 것 3가지**: ① 화자의 태도/정서 ② 표현 기법 ③ 시상 전개

| 항목 | 자주 나오는 선지 서술 |
|---|---|
| 화자 | "화자는 대상과 거리를 두고 관찰하고 있다" |
| 정서 | "상실감", "체념", "의지", "성찰" |
| 기법 | 반복, 대구, 대조, 감각의 전이, 의인, 반어, 역설, 도치, 수미상관, 색채 대비, 시각의 청각화 |
| 시상 전개 | 선경후정, 시간 흐름, 공간 이동, 시선 이동, 점층 |

`[분석]` **표현 기법 문항의 오답 제조 방식**: 기법 이름은 맞는데 **작품에 그 기법이 없거나**, 있는데 **효과 설명이 틀리다**. 두 부분을 나눠 판정하게 훈련한다.

> 선지: "색채 대비를 통해 대상의 생명력을 부각하고 있다"
> → ㉠ 색채 대비가 있나? ㉡ 있다면 그게 '생명력 부각'인가?
> **둘 중 하나만 틀려도 오답.**

### 3-2. 고전시가

**추가로 요구되는 것**: 어휘 해독.

- 필수 어휘: 어즈버, 하노라, 이시라, 괴다(사랑하다), 녀다(가다), 슬프다/슲다, 백구, 강호, 임금 지향어(님)
- 갈래별 관습:
  - **강호가도**: 자연 은거 = 정치적 물러남 + 임금 은혜 감사가 짝을 이룸
  - **연군지정**: 임 = 임금. 사랑 노래처럼 보이면 대개 충신연주지사
  - **가사**: 서사-본사-결사, 여정에 따른 서술
  - **시조**: 초·중·종장, 종장 첫 음보 3음절 고정
  - **민요·잡가**: 노동·해학, 반복과 열거

`[분석]` **고전시가는 배경지식 투자가 정당화되는 유일한 영역이다.** 독서에서는 배경지식이 함정이지만, 여기서는 갈래 관습이 곧 해독 키다.

### 3-3. 고전소설

**구조 상수**:
- 전기적(傳奇的) 요소 — 비현실적 사건이 당연하게 서술됨
- 편집자적 논평 — 서술자가 개입해 인물을 평가함 ("어찌 아니 가련하리오")
- 우연의 남발 — 개연성보다 서사 진행 우선
- 인물의 평면성 — 선인/악인 고정
- 행복한 결말

**문항이 걸리는 곳**: 인물 간 관계, 서술자 개입 여부, 장면 전환, 대화 속 의도

`[분석]` **"서술자의 개입"은 고전소설 문항의 단골이다.** 있는데 없다고 하거나, 없는데 있다고 하는 선지가 반복된다.

### 3-4. 현대소설

**묻는 것**: ① 서술 시점과 그 효과 ② 인물의 심리·태도 ③ 장면 구성 ④ 배경의 기능

| 시점 | 판별 키 | 흔한 오답 |
|---|---|---|
| 1인칭 주인공 | '나'가 자기 이야기 | 관찰자로 오독 |
| 1인칭 관찰자 | '나'가 남 이야기 | 주인공으로 오독 |
| 3인칭 관찰자 | 내면 서술 없음 | 전지적으로 오독 |
| 전지적 | 여러 인물 내면 서술 | 특정 인물에 제한된 것으로 오독 |
| **초점화(제한적 전지)** | 한 인물 내면만 | 전지적으로 오독 |

`[분석]` 최근 기출에서 **"특정 인물의 시각에서 서술함으로써"** 류의 선지가 늘었다. 초점화 개념을 반드시 가르쳐야 한다.

### 3-5. 극·시나리오

- 지시문(무대 지시)의 기능
- 대사의 이중성 (관객은 아는데 인물은 모름)
- 시나리오 용어: S#, F.I./F.O., O.L., 인서트, 몽타주
- 빈도는 낮지만 나오면 용어를 모르면 손도 못 댄다 → **1회분 정리로 충분**

### 3-6. 수필·교술

- 글쓴이의 체험 → 깨달음 구조
- 다른 갈래와 묶여 나오므로, **묶인 짝과의 공통점**이 문항이 된다

## 4. 문학 `<보기>`의 문법

`08-bogi-sources.md`에서 전면적으로 다루지만, 문학 특유의 것만 여기 적는다.

`[분석]` 문학 `<보기>`는 **감상의 방향을 지정하는 지시문**이다. 작품 해석의 자유를 제한해 정답을 하나로 만드는 장치다.

### 문학 `<보기>` 5유형

| 유형 | 형태 | 문항 |
|---|---|---|
| ① 주제·해석 제시형 | "이 작품은 ~을 형상화한다" | 작품 요소 ↔ 주제 대응 |
| ② 창작 배경·시대 상황형 | "1930년대 식민지 현실에서…" | 작품 요소 ↔ 시대 대응 |
| ③ 문학 이론·개념형 | "낯설게 하기란…" | 개념의 작품 내 실현 |
| ④ 작가론형 | "작가는 ~을 일관되게 다뤄왔다" | 작가 세계관 ↔ 작품 |
| ⑤ 비교 관점형 | "두 작품은 모두 ~을 다루되…" | 공통점·차이점 |

### `<보기>` 문항 푸는 법 (노베이스용 3단계)

```
1) <보기>를 문장 단위로 쪼개고 번호를 매긴다
2) 각 선지가 <보기>의 몇 번 문장에 대응하는지 찾는다
3) 대응이 안 되면 → 작품에서 근거를 찾는다 → 없으면 오답
```

**핵심 규칙**: `<보기>` 문항의 정답 근거는 **작품 + `<보기>` 둘 다**에 있어야 한다. 한쪽만 맞으면 오답이다. 오답 제조도 정확히 이 지점에서 이뤄진다 — `<보기>`의 말은 맞는데 작품에 그 근거가 없거나, 작품 근거는 있는데 `<보기>`가 지정한 방향과 어긋난다.

## 5. 문학 오답 제조 방식

`[분석]` `07-choice-logic.md`의 일반 유형에 더해, 문학 고유의 오답 패턴:

| 패턴 | 설명 | 예 |
|---|---|---|
| **기법 오인** | 없는 기법을 있다고 함 | "설의적 표현으로" (설의문이 없음) |
| **효과 오인** | 기법은 맞고 효과가 틀림 | "반복을 통해 화자의 기쁨을 강조" (실제는 슬픔) |
| **주체 혼동** | 화자/인물의 행위를 다른 쪽에 귀속 | 인물 A의 심리를 B의 것으로 |
| **정서 과장/축소** | 미묘한 정서를 극단화 | "체념" → "분노" |
| **시간·공간 오독** | 회상을 현재로, 이동을 정지로 | |
| **`<보기>` 이탈** | `<보기>`가 안 준 관점으로 해석 | |
| **서술자 개입 오판** | 고전소설 단골 | |
| **결말 왜곡** | 지문에 없는 결말을 전제 | |

## 6. 노베이스용 문학 학습 설계

`[분석]`

### 1단계 — 갈래 감각 (3주)
"이게 시냐 소설이냐"가 아니라 **"어떤 시냐"**. 현대시/고전시가/고전소설/현대소설 각각 무엇을 묻는지를 먼저 알려준다. 문제는 안 푼다.

### 2단계 — 고전 어휘·관습 (4주)
고전시가 어휘 200개, 고전소설 상투 표현 50개. **암기가 정당화되는 유일한 구간.**

### 3단계 — 기법 사전 (3주)
표현 기법 40개를 예문과 함께. 각 기법마다 "이게 있으면 뭐가 보이는가"를 붙인다.

### 4단계 — `<보기>` 대응 훈련 (4주)
`<보기>` 문항만 30개 몰아 풀기. 대응표 그리기 강제.

### 5단계 — 세트 통풀이
갈래별 → 혼합.

**시간 목표**: 문학 세트 1개 7~8분. 문학에서 시간을 벌어 독서에 쓰는 것이 표준 전략이다.

## 7. 수업 자료 제작 시 체크

- [ ] 작품 원문을 임의로 줄이지 않았는가 (생략 시 `(중략)` 표기)
- [ ] 갈래와 출제 연도·시행 회차를 명시했는가
- [ ] 어려운 고어에 풀이를 달았는가
- [ ] `<보기>`가 있다면 문장 번호를 매겨 대응 가능하게 했는가
- [ ] 기법 관련 선지는 "기법 유무 / 효과 적절성"을 나눠 해설했는가
- [ ] 작품 저작권 상태를 확인했는가 (현대 작품 전문 게재 주의)
