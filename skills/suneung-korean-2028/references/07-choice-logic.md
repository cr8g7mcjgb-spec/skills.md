# 07. 선지 논리와 오답 설계 — 이 스킬의 심장

평가원 문항의 난도는 지문이 아니라 **선지**에서 나온다. 킬러문항 배제 이후로는 더욱 그렇다(`01-exam-system.md` §2). 이 문서는 선지가 어떻게 쓰이고 오답이 어떻게 제조되는지를 다룬다. **수업 자료 제작 시 반드시 참조한다.**

## 1. 대전제 — 정답과 오답은 만드는 방식이 다르다

`[분석]` 이것이 전부다.

- **정답 선지**는 지문/작품 문장의 **환언(paraphrase)**이다. 새 정보를 추가하지 않는다. 표현만 바꾼다.
- **오답 선지**는 지문 정보를 **한 군데 비틀어** 만든다. 비틀린 지점이 정확히 하나 있고, 그것이 지목 가능해야 한다(정답 시비 방지).

여기서 **오답 지우기가 정답 찾기보다 대체로 쉽다**는 결론이 나온다. 정답은 "왜 맞는지" 설명하기 어려울 수 있지만(환언이라 자명해 보임), 오답은 "여기가 틀렸다"고 손가락으로 짚을 수 있는 경우가 많다.

> **학생에게 주는 한 문장**: "정답을 고르지 말고, 틀린 곳을 찾아라. 틀린 곳이 안 보이면 그게 답이다."

## 2. 정답 선지의 4가지 환언 방식

`[분석]` 정답 선지가 지문을 바꿔 쓰는 방식은 대체로 넷이다. 이것을 알면 "지문에 그 말이 없는데?"라는 착각이 사라진다.

| 방식 | 지문 | 정답 선지 |
|---|---|---|
| **어휘 대체** | "감소한다" | "줄어든다" |
| **관계 유지 재구성** | "A가 커지면 B가 작아진다" | "A와 B는 반비례한다" |
| **상위어 추상화** | "혈액 속 포도당 농도" | "체내 물질의 농도" |
| **부정의 부정** | "X는 Y의 조건이 아니다" | "Y는 X 없이도 성립한다" |

**노베이스 훈련**: 지문 문장 하나를 주고 4가지 방식으로 각각 바꿔 쓰게 한다. 이 훈련을 20회 하면 정답 선지가 눈에 익는다.

## 3. 오답 제조법 12종 — 오답 유형 태그 체계

`[분석]` 수업 자료에서 **모든 오답에 아래 태그를 붙인다.** 학생은 오답노트에 태그별 빈도를 기록하고, 자기가 어느 유형에 반복해서 걸리는지 확인한다.

### T1. 인과 역전
원인과 결과를 바꿔 놓는다.
- 지문: "A 때문에 B가 일어난다" → 선지: "B 때문에 A가 일어난다"
- **탐지**: 선지에서 '때문에', '따라서', '~로 인해'가 보이면 방향을 확인

### T2. 증감 반전
정도·방향을 뒤집는다.
- 지문: "커질수록 감소" → 선지: "커질수록 증가"
- **탐지**: 비교급·증감 어휘. 과학·경제 지문 최다

### T3. 주체 바꿔치기
A의 속성/주장을 B에 붙인다.
- 대립 구도형(골격 B), 문학의 화자·인물 문항에서 최다
- **탐지**: 선지의 주어를 지문에서 다시 확인

### T4. 범위 확대 (전칭화)
일부에만 해당하는 것을 전체로 넓힌다.
- 지문: "일부 경우에는" → 선지: "모든 경우에"
- **탐지**: 모든, 항상, 반드시, 어떤 ~도, 언제나, 전혀. **다만 이 표현이 있다고 자동 오답은 아니다** — 지문이 실제로 전칭이면 정답일 수 있다

### T5. 범위 축소 (한정 추가)
없는 조건을 붙인다.
- 지문: "X는 Y이다" → 선지: "X는 Z인 경우에만 Y이다"

### T6. 조건-결과 혼동
필요조건과 충분조건을 바꾼다.
- 지문: "Y이려면 X여야 한다"(필요) → 선지: "X이면 Y이다"(충분)
- **탐지**: '~해야', '~하면'. 법·논리 지문 최다. **최고난도 오답 유형**

### T7. 시점·순서 교란
단계 순서나 시기를 뒤섞는다.
- 통시적 발전형(골격 C), 과정 서술형(골격 D)에서 최다
- **탐지**: 먼저/나중, 이후/이전, 단계 번호

### T8. 지문에 없는 정보 (외삽)
그럴듯하지만 지문에 근거가 없다.
- **상식 유도형**이 여기 포함된다. 배경지식이 많은 학생이 오히려 걸린다
- **탐지**: "이 말의 근거 문장을 지문에서 짚을 수 있나?" 못 짚으면 오답

### T9. 부분 진실 + 결정적 오류
선지의 앞부분은 완전히 맞고 뒷부분이 틀리다.
- **가장 흔한 매력적 오답 구조.** 앞부분에서 안심하고 넘어가게 만든다
- **탐지**: 선지를 절 단위로 끊어서 각각 판정. **선지 하나에 판단 지점이 2~3개**인 최근 경향의 정체가 이것

### T10. 기법 유무 오류 (문학)
없는 기법을 있다고 하거나, 있는 기법을 없다고 함.

### T11. 효과·의도 오류 (문학)
기법·요소는 맞는데 그 효과 설명이 틀림.

### T12. `<보기>` 이탈
`<보기>`가 지정하지 않은 관점으로 해석하거나, `<보기>` 진술을 작품에 잘못 대응시킴.

### 유형별 출현 지형 `[분석]`

| 영역 | 최다 오답 유형 |
|---|---|
| 독서 인문·사회 | T3, T6, T9 |
| 독서 과학·기술 | T2, T7, T9 |
| 독서 `<보기>` 적용 | T2, T8, T12 |
| 문학 표현 문항 | T10, T11 |
| 문학 `<보기>` 문항 | T12, T3 |
| 화법·작문 | T3, T8 |
| 문법 | T4, T5 |

## 4. 매력적 오답의 설계 원리

`[분석]` 정답률을 30~50%대로 떨어뜨리는 오답은 우연이 아니라 설계된 것이다. 설계 원리 4가지:

### 원리 1 — 정답보다 지문 표현을 더 많이 포함시킨다
오답에 지문 단어를 더 많이 박아 넣으면, 지문을 대충 읽은 학생은 "본 것 같은" 오답을 고른다. 정답은 환언되어 있어 오히려 낯설다.

> **대응 훈련**: "지문 단어가 많이 보인다"는 정답의 근거가 **아니다**. 오히려 경계 신호다.

### 원리 2 — 상식적으로 옳은 진술을 넣는다
세상 상식으로는 맞는 말인데 지문 근거가 없는 선지(T8). 배경지식이 있는 학생일수록 걸린다.

> **대응 훈련**: "이건 사실이니까 맞다"는 판단 금지. 판단 기준은 **지문 근거의 유무**뿐.

### 원리 3 — 판단 지점을 뒤로 배치한다
선지 앞 60%는 완벽히 맞고, 마지막 어절에서 틀린다(T9). 읽다가 앞부분에서 확신하고 넘어가게 만든다.

> **대응 훈련**: 선지는 **끝까지, 절 단위로 끊어서** 읽는다. 슬래시를 그어가며 읽게 한다.

### 원리 4 — 두 정보를 결합해야만 판정되게 한다
1문단 정보 + 4문단 정보를 합쳐야 참·거짓이 결정된다. 문단 하나만 보면 맞아 보인다.

> **대응 훈련**: `<보기>` 문항과 추론 문항에서 "근거 문장 2개 이상 표시하기"를 강제한다.

## 5. 선지 분해 프로토콜 — 노베이스 핵심 훈련

`[분석]` 이 스킬이 제공하는 가장 실용적인 도구다. 모든 학습지에 이 절차를 넣는다.

### 4단계 분해

```
1) 선지를 절 단위로 슬래시(/)로 끊는다
   "㉠은 대상과의 거리를 좁힘으로써 / 화자의 친밀감을 드러낸다"

2) 각 절에 판정 기호를 붙인다
   O = 지문/작품에 근거 있음 (근거 위치 적기)
   X = 근거와 어긋남
   ? = 근거를 못 찾음

3) X가 하나라도 있으면 → 오답. 오답 유형 태그(T1~T12)를 붙인다

4) 전부 O면 → 정답 후보
```

### 실물 예시 (자작 예시 — 실제 기출 아님)

> 지문(자작): "습도가 높아지면 이 센서의 저항값은 낮아진다. 다만 온도가 40℃를 넘으면 이 관계는 성립하지 않는다."
>
> 선지: "습도가 높아지면 / 온도와 무관하게 / 저항값이 낮아진다."
>
> - 절1 "습도가 높아지면" → **O** (1문장)
> - 절2 "온도와 무관하게" → **X** (2문장의 단서와 충돌) → **T5 범위 축소 위반 / T4 전칭화**
> - 절3 "저항값이 낮아진다" → O
> - **판정: 오답. 태그 T4**

이 형식을 그대로 학습지에 쓴다. → `assets/choice-verdict-table.md`

## 6. 발문(질문)의 문법

`[분석]` 발문 형식이 풀이 방식을 결정한다. 노베이스는 발문을 대충 읽어 **긍정/부정을 뒤집는 실수**를 반복한다.

| 발문 형태 | 요구 | 주의 |
|---|---|---|
| "적절한 것은?" | 정답 1개 찾기 | 오답 4개가 틀린 이유가 명확 |
| **"적절하지 않은 것은?"** | 틀린 것 1개 | **최다 실수 지점.** 발문에 반드시 표시하게 훈련 |
| "~을 바탕으로" | 그 자료 범위 안에서만 | 범위 이탈이 오답 |
| "~을 고려할 때" | 주어진 관점 적용 | |
| "추론한 내용" | 직접 진술 아님, 도출 가능 | 상상 금지 |
| "㉠~㉤ 중" | 국소 판단 | 지문 전체 뒤지지 말 것 |
| "가장 적절한 것은?" | 상대 비교 | 완벽하지 않아도 최선이면 정답 |

**"가장 적절한"의 함정**: 정답이 100% 완벽하지 않을 수 있다. 다른 4개보다 나으면 정답이다. 완벽주의 학생이 여기서 시간을 잃는다.

**절차 강제**: 발문의 부정어에 **동그라미**를 치고 시작한다. 예외 없이.

## 7. 배점의 의미

`[분석]`

- 2점 / 3점 두 종류
- 3점은 대체로 `<보기>` 적용 문항, 복합 판단 문항
- **배점은 난도 예고다.** 3점 문항은 시간을 더 쓸 각오로 진입한다
- 노베이스 전략: **2점 문항 전량 확보 → 3점 선별 공략**. 45문항 중 3점을 절반 버려도 등급은 올라간다

## 8. 오답노트 설계

`[분석]` 유형 태그가 있어야 오답노트가 의미를 갖는다. 없으면 "또 틀렸네"로 끝난다.

### 필수 기록 항목

| 항목 | 내용 |
|---|---|
| 출처 | 학년도·시행(수능/6평/9평)·문항 번호 |
| 영역 | 독서(제재)/문학(갈래)/화법/작문/문법 |
| 내가 고른 선지 | |
| **오답 유형 태그** | T1~T12 |
| 왜 걸렸는가 | 한 문장 |
| 정답 근거 위치 | 문단·문장 |

### 활용

2주에 한 번 태그 빈도를 집계한다. 상위 2개 태그가 그 학생의 약점이고, 다음 2주 훈련은 그 유형에만 집중한다. → `assets/error-log.md`

## 9. 수업 자료 제작 시 강제 사항

- [ ] **모든 오답에 T1~T12 태그**를 붙였는가
- [ ] 오답 해설이 정답 해설보다 긴가 (SKILL.md 원칙 3)
- [ ] 정답 근거를 문장 단위로 인용했는가
- [ ] 매력적 오답(선택률 높은 것)을 별도 표시하고 왜 매력적인지 설명했는가
- [ ] 선지 분해(슬래시 + O/X/?) 예시를 최소 1개 넣었는가
- [ ] 발문의 부정어 표시를 훈련시키는 장치가 있는가
