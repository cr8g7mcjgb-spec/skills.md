# 21. 평가원의 렌즈 — 국어교육학이라는 관점 체계

`20-item-construction-norms.md`가 "출제자가 지키는 규칙"이라면, 이 문서는 **"출제자가 세상을 보는 방식"**이다. 평가원 문항의 개념·용어·분류는 출제진의 취향이 아니라 **국어교육학의 학문 체계**에서 그대로 나온다. 그 체계를 알면 문항이 왜 그렇게 생겼는지가 아니라 **다음에 무엇이 나올 수 있는지**가 보인다.

---

## 1. 결정적 사실 — 수능과 임용은 같은 우물에서 나온다

`[검증]` 중등교사 임용시험(전공 국어)을 분석하는 수험 자료는 **임용 문항과 수능·모의평가 문항을 하나의 계보로 놓고 상호 참조한다.** 실제 분석 자료에서 확인된 참조 형태:

```
독서 태도 관련  : 20B04, 17A02, 15A02 / ★24-6모(1,2번 독서이론지문 제재가 독서동기)
표음/표의주의   : 13-16, 10-13, 09-16 / 15B-6모, 15B-9모, 16B-수능, 14B-수능
불규칙 활용     : 20A08, 11-23, 10-21, 97-05 / 21수능, ★22-6모, ★24 수능
필수부사어      : 18수능, 13-6모, ★22수능, 23-9모 지문
구개음화        : 16A09, 15A04, 09모-15, 04-04, 01-05 / ★24 수능 35~36번 지문
대화 원리와 예절 : 21A05, 19B01, 15A01 … / 22예비수능, 23-9모
설득 담화 구조   : 21A08, 18A09 … / 문제-원인-해결 구조(22수능)
```

앞의 코드(`20B04`, `16A09`)는 임용 문항이고 뒤(`24 수능`, `23-9모`)는 수능·모평이다. **한 줄 안에 섞여 있다.**

`[분석]` 여기서 나오는 결론은 강력하다.

> **평가원은 임용과 수능에서 같은 개념 풀(pool)을 쓴다.** 임용에서 다뤄진 개념이 수능 지문·문항으로 내려오고, 수능에서 다뤄진 현상이 임용 문항으로 올라간다.

그래서 **국어교육학 개론서의 목차가 곧 출제 가능 범위의 지도**가 된다. 이것이 이 문서의 존재 이유다.

**단, 방향을 오해하지 마라.** 임용 수준의 이론을 학생에게 가르치라는 말이 아니다. **교사가 그 지도를 갖고 있으면 무엇이 나올 수 있는지 예측하고, 처음 보는 소재 앞에서도 당황하지 않는다**는 뜻이다.

## 2. 읽기 교육론 — 수능 '독서론 지문'의 정체

`[검증]` 국어교육론 읽기 영역의 표준 내용.

### 2-1. 독해 과정 모형 3종

| 모형 | 핵심 | 지향 |
|---|---|---|
| **상향식(bottom-up)** | 낱자 → 단어 → 문장 → 의미. 해독 중심 | 텍스트 지향 |
| **하향식(top-down)** | 독자의 배경지식·예측이 의미를 만든다 | 독자 지향 |
| **상호작용식** | 글의 정보 처리와 독자 지식이 함께 작동 | 절충 |

### 2-2. 스키마 이론

- **개념**: 기억 속에 저장된 지식 구조
- **기능 4가지**: ① 글 정보와 독자 지식의 통합 ② **낱말의 의미 선택**(다의어의 맥락 의미 결정) ③ 정보의 선별적 기억 ④ 다음 내용 예측
- **유형**: **내용 스키마**(주제 배경지식) / **구조(형식) 스키마**(글 구조에 관한 지식)

`[분석]` **구조 스키마가 이 스킬의 골격 A~H(`03-reading.md` §3)와 같은 것이다.** 지문 구조를 유형화해 가르치는 일은 곧 구조 스키마를 형성시키는 일이고, 이것은 국어교육학이 이미 정당화해 둔 교수 방법이다.

### 2-3. 과정 중심 읽기 — 읽기 전 / 중 / 후

| 단계 | 목적 | 전략 |
|---|---|---|
| **읽기 전** | 목적 설정, 배경지식 활성화, 동기 유발 | 브레인스토밍, 미리보기, 예측하기, **KWL 표**, 어휘 소개 |
| **읽기 중** | 이해 촉진, 과정 점검 | 질문하기, 심상 만들기, 추론하기, 메모, 점검, **구조 생각하며 읽기(도해조직자)** |
| **읽기 후** | 이해도 평가, 반응, 종합 | 요약하기, 다시 말하기, 예측 확인, 비판적·창의적 읽기, **의미 지도** |

### 2-4. 읽기 평가 방법 10종

```
① 선다형 검사        ② 자유 회상법        ③ 빈칸 메우기(cloze test)
④ 프로토콜 분석(사고구술)                 ⑤ 중요도 평정
⑥ 오류 감지(오류 발견법)                  ⑦ 관찰법(체크리스트)
⑧ 일화 기록법        ⑨ 포트폴리오법       ⑩ 오독 분석법
```

### 2-5. 이것이 왜 중요한가

`[분석]` **2022~2027 수능의 '독서 이론 지문(독서론)'은 정확히 이 목록에서 나온다.**

확인된 대응:
- **독서 동기 / 독서 몰입** → 24학년도 6월 모평 독서론 지문 제재 `[검증: 임용 분석 자료 기준]`
- 사고구술(프로토콜), 도해조직자, 중요도 평정, 학습 독서 → 임용에서 반복 출제된 개념이자 독서론 지문의 단골 소재
- 상향식·하향식·상호작용 모형, 스키마 → 독해 이론 지문의 표준 제재

**따라서 독서론 지문은 "무엇이 나올지 모르는 영역"이 아니다.** 위 목록이 사실상 출제 범위다.

> `[검증]` 다만 **2028 예시문항에서는 독서 이론 지문이 제외된 것으로 보고되었다**(`14-collected-data.md` §3). 2028 대비에서는 우선순위를 낮춘다. 그래도 개념 자체는 '화법과 언어'·'독서와 작문'의 학습 활동 소재로 재등장할 수 있다.

## 3. 작문 교육론 — 작문 문항의 이론 계보

`[검증]` 쓰기 이론의 역사적 전개. 임용에서 반복 출제되는 핵심 축이다.

### 3-1. 계보 6단계

| 이론 | 의미는 어디에 있는가 | 교육 방법 |
|---|---|---|
| **수사학(결과 중심)** | 대가의 글에 | 모방, 수사적 상황 분석 |
| **형식주의** | **글(텍스트) 자체에** — 맥락에서 자유로운 단일한 의미 | 모범문 제시, 5단락 쓰기, 문장 확장 |
| **인지주의(과정 중심)** | **필자의 사고 과정에** | 쓰기 전략, **사고구술**, 회귀적 과정, 상위인지 점검 |
| **사회구성주의** | **담화 공동체의 상호작용에** | 쓰기 워크숍, 협동 작문, 동료 평가 |
| **대화주의** | **필자와 독자 사이의 협상에** | 동료 비평, 독자를 **공저자**로 |
| **장르 중심** | 반복되는 상황의 유형화된 수사적 행위에 | 장르별 형식·내용 학습 |
| **후기 과정** | 사회·문화 맥락과 이데올로기에 | 비판적 글쓰기, 대안 담론 생산 |

### 3-2. 수사적 상황과 독자 개념

- **수사적 상황**: 필자, 독자, 목적, 상황, 글의 종류
- **독자 3층위**
  - **특정 독자**: 실제로 질문·논쟁·아이디어를 주는 독자
  - **보편 독자**: 합리적으로 사고하는 성인으로 가정된 허구적 독자
  - **독자로서의 자아**: 필자가 보편 독자를 내면화해 스스로 자기 글의 독자가 됨

### 3-3. 수능 작문 문항과의 대응

`[분석]`

| 수능 작문 문항 | 이론적 근거 |
|---|---|
| 작문 계획 확인 (목적·주제·예상 독자 메모) | **수사적 상황** 분석 |
| 자료 활용 방안 | **인지주의** 내용 생성 |
| 고쳐쓰기 (통일성·응집성·완결성) | **형식주의** + 인지주의 점검 |
| "예상 독자를 고려하여" 류 선지 | **독자 개념**, 대화주의 |
| 초고에 반영되지 않은 계획 찾기 | 과정 중심 쓰기의 회귀성 |
| 비평문·논증문 쓰기 | **장르 중심** |

**"독자를 고려하여"라는 문구가 수능 작문 선지에 반복되는 이유가 여기 있다.** 그것이 작문 교육론의 중심 개념이기 때문이다.

`[검증]` 임용에서 반복 출제되는 의사소통 이론.

| 개념군 | 세부 |

## 5. 문법 — 학교문법과 학문문법의 이중 구조

`[검증]` 임용 문법 문항은 **학문문법(국어학) 수준**을 요구한다. 기저형, 적용 환경, 형태소 분석의 대안적 처리 등.

`[분석]` **여기서 수능 '지문형 문법 세트'의 정체가 드러난다.**

수능 지문형 문법은 학교문법으로 처리되지 않는 사례를 제시하고, **지문 안에서 대안적 기준을 준 뒤 그 기준으로 판정하게 한다.** 이것은 임용에서 다루는 학문문법의 논점을 **지문으로 풀어 고등학생도 접근 가능하게 만든 형태**다.

| 임용에서 다루는 논점 | 수능 지문형으로 내려오는 방식 |
|---|---|
| 기저형 설정 | "다음 글은 ~를 설명한 것이다" + 사례 판정 |
| 음운 변동의 적용 환경 | 조건을 지문이 명시하고 사례 적용 |
| 형태소 분석의 대안 | 두 가지 분석을 제시하고 비교 |
| 표음주의 ↔ 표의주의 | 표기 원리 지문 |
| 품사 통용 | 사전 자료 제시형 |

`[검증: 임용 분석 자료 기준]` 24학년도 수능 35~36번 지문이 **구개음화**를 설명하는 지문형 세트였다는 대응이 명시되어 있다.

> **`06-grammar.md` §10의 "네가 아는 문법을 접어라"가 옳은 이유가 이것이다.** 지문이 학교문법과 다른 기준을 줄 수 있는 것은, 그 기준이 학문문법에서 실제로 논쟁 중인 사안이기 때문이다.

## 6. 문학 교육론 — `<보기>`가 지정하는 관점의 목록

`[분석]` 문학 `<보기>`가 주는 "감상의 방향"은 임의적이지 않다. **문학교육론의 관점 분류를 따른다.**

| 관점 | `<보기>`에서의 표현 |
|---|---|
| **내재적(절대주의)** | "이 작품의 구조는…", "화자와 대상의 관계는…" |
| **외재적 — 표현론** | "작가는 ~을 지속적으로 다루어 왔다" |
| **외재적 — 반영론** | "이 작품이 발표된 1930년대는…" |
| **외재적 — 효용론** | "독자는 ~을 경험하게 된다" |
| **수용·반응 중심** | "~로 볼 수 있겠군" (학생 감상 형식) |
| **사회·문화적 관점** | "사회 생태주의 관점에서" (2028 예시문항) |

`[분석]` `08-bogi-sources.md` §2-2의 문학 `<보기>` 5유형은 이 관점 분류와 대응한다. **`<보기>`를 읽을 때 "이건 어느 관점이지?"를 먼저 판정하면 선지 판단이 빨라진다.**

2028 예시문항에서 **사회 생태주의**가 등장한 것은, 문학교육론의 관점 목록이 계속 확장되고 있다는 신호다. 낯선 비평 용어가 `<보기>`에 등장해도 원리는 같다 — **`<보기>`가 준 관점 안에서만 판단한다.**

## 7. 임용 분석에서 드러난 평가원의 출제 로직

`[검증]` 임용 문항 분석 자료가 명시적으로 서술한 출제 경향. **이 진술들이 이 문서에서 가장 값지다.**

### 7-1. "근거를 뚜렷하게 세팅한다"

> "최근 임용에서는 **최대한 근거를 뚜렷하게 세팅하고 문제를 출제하려는 경향이 강하다.** 따라서 작품을 정확히 이해하긴 어렵더라도 나름의 근거를 찾으면서 신속히 답을 찾아야 한다."

`[분석]` 배경지식이 없어도 **자료 안에 근거가 심겨 있다**는 뜻이다. 수능에서 "배경지식 없이 지문만으로 풀린다"는 원칙과 동일하다. 작품을 몰라도 텍스트 표면의 단서로 접근하라는 지침이 임용과 수능에 공통으로 적용된다.

### 7-2. "문제 안에 힌트를 숨겨 둔다"

> "출제자가 이런 조건과 관련하여 특정 답안을 쓸 수 있도록 **문제 안에 힌트를 숨겨 두는 경우가 많다.** … 평소 기출 풀이를 할 때, **지문 안에 답안 작성의 길잡이가 되는 힌트를 찾아서 작성하는 연습**을 하고, 기출 분석을 할 때 **역대 기출에서 이런 힌트들이 어떤 방식으로 등장했는지 분석**해 봐야 한다."

`[분석]` **이것이 평가원 출제 로직의 핵심 진술이다.** 문항은 정답이 하나로 확정되어야 하므로, 출제자는 반드시 자료 안에 **정답으로 수렴시키는 장치**를 심는다. 학생이 할 일은 그 장치를 찾는 것이다.

수능으로 번역하면:
- `<보기>`가 지정한 개념어 → 그것이 힌트다
- 지문의 단서 조항("다만", "~인 경우에만") → 그것이 힌트다
- 발화 뒤에 붙은 상대의 반응 → 그것이 앞 발화의 성격을 알려주는 힌트다
- 선지에 반복되는 용어 → 지문의 어느 지점을 보라는 힌트다

### 7-3. "기출 분석은 힌트의 패턴을 찾는 것"

`[분석]` 임용 준비생의 기출 분석법이 곧 수능 기출 분석법의 상위 버전이다.

```
1) 문항이 요구한 조건을 분해한다
2) 그 조건의 답을 자료 어디서 끌어왔는지 역추적한다
3) 같은 조건이 과거 어느 문항에서 어떤 형태로 나왔는지 연결한다
4) 다음에 나올 수 있는 변형을 예상한다
```

이 절차의 3·4단계가 이 스킬의 `13-corpus.md` 태깅과 `12-item-writing.md` 자작으로 이어진다.

## 8. 개론서 목차 = 출제 범위 지도

`[분석]` 국어교육학 개론서의 영역 구분을 그대로 옮기면, 그것이 **평가원이 문항을 만들 때 참조하는 내용 체계**가 된다.

```
국어교육론
├── 읽기(독서) 교육론  ── 독해 모형, 스키마, 전략, 평가 방법, 독서 태도·동기
├── 쓰기(작문) 교육론  ── 이론 계보, 과정, 수사적 상황, 장르, 평가
├── 화법 교육론        ── 협력·공손성 원리, 체면, 담화 유형, 순서 교대
├── 문법(문법 교육론)  ── 음운·형태·통사·의미·담화·국어사 + 탐구 학습
└── 문학 교육론        ── 관점(내재/외재), 반응 중심, 갈래론, 정전
```

**이 5분할이 2028 수능의 3과목(화법과 언어 / 독서와 작문 / 문학)으로 재편성된 것이다.** 과목 이름이 바뀌었을 뿐 내용 체계는 그대로다. → `09-2028-shift.md`

## 9. 이 문서를 쓰는 법

### 교사용
- 낯선 소재가 `<보기>`나 지문에 나와도 **어느 이론 영역인지 즉시 분류**할 수 있게 된다
- 자작 문항의 **평가 목표를 이론 용어로 적을 수 있다** → `12-item-writing.md`의 성취기준 매핑이 쉬워진다
- "이 개념이 나올 수 있나?"에 대해 **개론서 목차로 답할 수 있다**

### 학생용 — 번역해서 전달한다
이론 용어를 그대로 가르치지 마라. 아래 3가지만 번역해 전달한다.

> 1. **문제 안에는 답으로 데려가는 힌트가 반드시 심겨 있다.** 못 찾은 것이지 없는 게 아니다.
> 2. **작품이나 소재를 몰라도 된다.** 근거는 자료 표면에 있다.
> 3. **`<보기>`는 "이 관점으로 읽어라"는 지시다.** 네 감상이 틀린 게 아니라, 지금은 그걸 묻는 게 아니다.

### 하지 말 것
- 학생에게 "인지주의 작문 이론" 같은 용어를 외우게 하는 것 — **수능은 그 용어를 묻지 않는다.** 그 이론이 만들어 낸 문항을 풀게 할 뿐이다
- 임용 개론서를 학생 교재로 쓰는 것
