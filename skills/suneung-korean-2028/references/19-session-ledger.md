# 19. 전 회차 원장(元帳) — 무엇이 분석되었고 무엇이 비어 있는가

이 문서는 **1994학년도부터 2028 예시문항까지 모든 시행 회차를 한 행씩 빠짐없이 세운 장부**다.

목적은 두 가지다.
1. **누락을 눈에 보이게 한다.** 빈 칸은 빈 칸으로 남긴다. 채운 척하지 않는다
2. 원문을 확보할 때마다 이 표를 채워 나간다. **진척률이 숫자로 나온다**

## 4. 왜 C등급에서 멈춰 있는가

`[검증]` 실측 결과다. 추측이 아니다.

| 경로 | 결과 |
|---|---|
| 평가원·EBSi·교육부·오르비·티스토리 직접 접속 | **전부 차단** (curl 응답 없음) |
| WebFetch | 시도한 호스트 전부 403 |
| 네이버 커넥터로 PDF URL 읽기 | 바이너리 깨짐 (PDF 파서 없음) |
| 네이버 검색으로 지문 전문 찾기 | 검색어 4회 변경 — **그런 페이지가 없음** (저작권상 PDF 첨부로만 유통) |
| 로컬 PDF 텍스트 추출 | **✅ 가능** (검증 완료, `13-corpus.md` §1-B) |

즉 **파일만 손에 들어오면 A등급 전환은 즉시 가능하다.** 막힌 것은 분석 능력이 아니라 파일 취득 경로 하나다.

### 기억으로 채우지 않는 이유

이 표의 "지문·작품" 칸을 기억으로 채울 수는 있다. 하지만 하지 않는다.

`14-collected-data.md` §0에서 **실제로 그렇게 만들어진 허위 분석 블로그를 잡아냈다.** 그 블로그는 모든 회차를 그럴듯한 틀로 채워 놓았고, 교차 검증에서 지문 소재·오답률·등급컷이 전부 틀린 것으로 드러났다. 검색 상위를 점유하고 있어 많은 학생이 그것을 믿는다.

**빈 칸이 틀린 칸보다 낫다.** 이 원장의 존재 이유가 그것이다.

## 5. A등급 전환 절차

한 회차를 A등급으로 올리는 데 필요한 작업이다.

```
1) 문제지 PDF 확보                          ← 유일한 병목
2) python3 scripts/pdf_extract.py <pdf> --items items.csv
   → 45문항 자동 분리, 배점·<보기>·선지 수·부정 발문 자동 판정  (검증 완료)
3) 세트 단위 골격 판정        (03-reading.md §3, 골격 A~H)
4) 문항 유형 태깅             (03-reading.md §5)
5) 선지별 오답 유형 태깅       (07-choice-logic.md, T1~T12)   ← 문항당 5~10분
6) 정답률 병합                (EBSi 등 확보 시)
7) corpus_index.py --validate 로 검증
```

**1회차 소요: 4~6시간.** 2~7단계는 전부 도구화되어 있다.

## 6. 이 원장을 갱신하는 법

원문을 확보해 분석할 때마다:

1. 해당 행의 **등급을 올린다** (C → B → A)
2. 지문·작품·오답률 칸을 채운다
3. §0의 진척률 표를 다시 계산한다
4. 상세 내용은 `14-collected-data.md`에 회차별로 추가한다

**등급을 올릴 때는 근거 출처를 반드시 적는다.** 2차 자료면 B까지만 올라간다. A는 원문 대조가 있어야 한다.
