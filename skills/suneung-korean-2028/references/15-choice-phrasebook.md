# 15. 평가원 선지 문형 사전

평가원 선지는 자유 작문이 아니다. **정해진 문형 목록**이 있고, 출제진은 그 안에서 조합한다. 이 문서는 그 문형을 영역별로 전부 적는다. 문형을 알면 선지를 읽는 속도가 달라지고, 자작 문항의 품질이 달라진다.

`[분석]` 이 문서 전체는 구조 관찰이다. 특정 연도·문항의 선지를 그대로 옮긴 것이 아니다.

---

## 0. 선지의 뼈대 — 모든 선지는 이 셋 중 하나다

```
[A형] 근거 + 서술어          "㉠은 ~을 통해 ~하고 있다"
[B형] 조건 + 판단            "~라면 ~일 것이다"
[C형] 대상 + 속성 귀속        "㉠은 ~에 해당한다"
```

**A형이 압도적으로 많다.** 그리고 A형은 반드시 **두 부분**으로 쪼개진다.

```
"㉠은  /  대상과의 거리를 좁힘으로써  /  화자의 친밀감을 드러내고 있다"
       └─── 수단·근거 (작품/지문 사실) ───┘ └─── 효과·의도 (해석) ───┘
```

**앞은 사실, 뒤는 해석.** 오답은 이 둘 중 한쪽만 비튼다. 그래서 슬래시로 끊어 각각 판정하면 거의 다 잡힌다. → `07-choice-logic.md` §5

## 1. 독서 선지 문형

### 1-1. 내용 일치 유형

| 문형 | 예 |
|---|---|
| `A는 B이다` | 관성은 물체가 운동 상태를 유지하려는 성질이다 |
| `A는 B를 C한다` | 중앙은행은 기준금리를 조정하여 통화량을 관리한다 |
| `A가 ~하면 B가 ~한다` | 이심률이 커지면 근일점 거리는 짧아진다 |
| `A는 B와 달리 C한다` | 관습법은 제정법과 달리 성문화되지 않는다 |
| `A에는 B가 포함되지 않는다` | 담보물권에는 유치권이 포함되지 않는다 |
| `A는 B를 전제로 한다` | 보증 채무는 주채무의 존재를 전제로 한다 |
| `A의 경우에만 B가 성립한다` | 명시적 동의가 있는 경우에만 효력이 발생한다 |

**오답 변형 규칙** — 위 문형 각각에 대응하는 비틀기가 정해져 있다.

| 원 문형 | 비트는 방법 | 태그 |
|---|---|---|
| `A는 B를 C한다` | 주어를 다른 개념으로 | T3 |
| `A가 ~하면 B가 ~한다` | 증감 방향 반전 | T2 |
| `A는 B와 달리` | 공통점을 차이점으로 | T3 |
| `A에는 B가 포함되지 않는다` | 부정을 긍정으로 | T2 |
| `A는 B를 전제로 한다` | 전제 관계를 뒤집기 | T1 |
| `A의 경우에만` | "에만" 삭제 → 전칭화 | T4 |

### 1-2. 추론 유형

| 문형 | 신호 |
|---|---|
| `A라면 B일 것이다` | 조건 추론 |
| `A가 없다면 B는 ~할 것이다` | 반사실 추론 |
| `A와 B가 모두 ~한 경우, C는 ~할 것이다` | 복합 조건 |
| `A는 B를 설명할 수 있지만 C는 설명하지 못한다` | 이론 적용 범위 |
| `A의 관점에서 B는 ~로 평가될 것이다` | 관점 적용 |

**여기서 T6(조건 혼동)이 집중 발생한다.** "~여야 한다"(필요)와 "~하면 ~이다"(충분)를 바꾸는 것이 최고난도 오답의 표준 제조법이다.

### 1-3. 전개 방식 유형 — 서술어 목록

평가원이 쓰는 서술어는 사실상 아래 목록 안에 있다.

```
제시하고 있다 / 소개하고 있다 / 설명하고 있다 / 서술하고 있다
분류하고 있다 / 열거하고 있다 / 대조하고 있다 / 비교하고 있다
분석하고 있다 / 규명하고 있다 / 밝히고 있다
반박하고 있다 / 비판하고 있다 / 논박하고 있다
전제하고 있다 / 가정하고 있다
예시를 들어 / 사례를 통해 / 비유를 활용하여
통시적으로 / 단계적으로 / 병렬적으로
한계를 지적하고 있다 / 전망을 제시하고 있다 / 대안을 모색하고 있다
```

**자주 쓰이는 결합 형태:**
- `~을 소개한 후 ~의 한계를 지적하고 있다`
- `~을 유형별로 분류하여 각각의 특징을 설명하고 있다`
- `~에 대한 상반된 견해를 제시하고 절충안을 모색하고 있다`
- `통념을 반박하며 새로운 관점을 제시하고 있다`
- `구체적 사례를 들어 원리를 설명한 후 적용 범위를 밝히고 있다`

**오답 제조**: 위 결합의 **한쪽만** 사실로 만든다. "통념을 반박하며"는 맞는데 "새로운 관점 제시"가 없거나, 순서가 반대이거나.

### 1-4. `<보기>` 적용 유형

| 문형 | 판정 지점 |
|---|---|
| `<보기>의 A는 윗글의 B에 해당한다` | 대응 정확성 |
| `<보기>에서 A가 증가한 것은 윗글의 B 때문이다` | 인과 + 대응 |
| `<보기>의 상황에서 A는 ~할 것이다` | 원리 적용 |
| `윗글에 따르면 <보기>의 A는 B로 설명된다` | 이론 포섭 |
| `<보기>의 A와 B는 윗글의 C라는 점에서 같다` | 공통 속성 |

## 2. 문학 선지 문형

### 2-1. 표현·서술상 특징

**시 — 기법 어휘 목록**
```
반복 / 변주 / 대구 / 대조 / 열거 / 점층 / 도치 / 생략
설의 / 영탄 / 반어 / 역설 / 의인 / 활유 / 직유 / 은유 / 상징 / 대유
감각적 심상 / 공감각 / 색채 대비 / 시각의 청각화
수미상관 / 선경후정 / 시상의 전환 / 어조의 변화
말줄임 / 명사형 종결 / 현재형 진술 / 청자에게 말 건네는 방식
```

**소설 — 서술 어휘 목록**
```
서술자의 개입 / 편집자적 논평 / 요약적 제시 / 장면 제시
내적 독백 / 의식의 흐름 / 회상 / 삽화적 구성 / 액자식 구성
시점의 전환 / 초점 인물의 이동
대화를 통해 / 행동 묘사를 통해 / 배경 묘사를 통해
과거와 현재의 교차 / 동시적 사건의 병치
```

**표준 결합 문형:**
```
[기법]을 통해 [대상]의 [속성]을 [효과]하고 있다
    반복을 통해     화자의    정서를    강조하고
    대조를 통해     인물 간 갈등을      부각하고
    감각적 심상을 활용하여 대상의 생동감을 드러내고

[서술 방식]으로 [내용]을 [효과]하고 있다
    요약적 제시로   인물의 내력을    압축적으로 전달하고
    장면 제시로     사건의 긴장감을  높이고
```

**효과 어휘 목록** (뒷부분에 오는 것)
```
강조하고 있다 / 부각하고 있다 / 드러내고 있다 / 환기하고 있다
심화하고 있다 / 고조시키고 있다 / 완화하고 있다
암시하고 있다 / 예고하고 있다 / 함축하고 있다
구체화하고 있다 / 형상화하고 있다 / 선명하게 하고 있다
```

`[분석]` **오답의 대부분이 이 뒷부분에서 만들어진다.** 기법은 실제로 있는데 효과 설명이 틀린 것(T11)이 문학 오답의 최다 유형이다. 기법 유무만 확인하고 넘어가는 학생이 여기서 전멸한다.

### 2-2. 인물·화자 이해

| 문형 | 판정 |
|---|---|
| `A는 B에 대해 ~한 태도를 보이고 있다` | 태도의 방향 |
| `A는 ~을 계기로 ~하게 되었다` | 인과·계기 |
| `A의 말에는 ~하려는 의도가 담겨 있다` | 발화 의도 |
| `A는 ~을 통해 자신의 ~을 감추고 있다` | 이면 의도 |
| `화자는 ~와 거리를 두고 ~을 관조하고 있다` | 화자의 위치 |
| `A와 B는 ~에 대해 상반된 인식을 보인다` | 인물 대비 |

### 2-3. `<보기>` 감상 문형

`<보기>`가 준 개념어를 선지가 그대로 받는다. 이 **되받기 구조**가 핵심이다.

```
<보기>: "이 작품은 산업화 과정에서 훼손된 공동체를 형상화한다"
                                   ↓ 개념어를 선지가 받는다
선지:  "㉠에서 마을 사람들이 흩어지는 장면은 훼손된 공동체를
        보여 주는 것으로 볼 수 있겠군"
```

**문말 어미가 고정되어 있다:**
```
~로 볼 수 있겠군 / ~라고 할 수 있겠군 / ~로 이해할 수 있겠군
~을 보여 주는군 / ~을 드러내는군 / ~에 해당하겠군
```

`[분석]` "-군"체는 **학생의 감상**이라는 형식을 취해 해석의 책임을 분산시키는 장치다. 정답 시비를 줄인다.

**오답 제조 3가지**
1. `<보기>` 개념어는 맞게 받았는데 **작품의 그 장면이 없다** (T8)
2. 작품 장면은 맞는데 **`<보기>`가 안 준 개념**으로 해석 (T12)
3. `<보기>` 개념어를 **반대 방향**으로 적용 (T11)

## 3. 화법·작문 선지 문형

### 3-1. 화법 — 말하기 전략

```
[주체]는 [방법]을 통해 [목적]하고 있다

발표자는  구체적 사례를 들어    청중의 이해를 돕고 있다
발표자는  질문을 던져          청중의 주의를 환기하고 있다
발표자는  시각 자료를 활용하여  ~을 효과적으로 전달하고 있다
발표자는  청중의 반응을 확인하며 발화 내용을 조정하고 있다
발표자는  앞서 언급한 내용을 요약하며 화제를 전환하고 있다
```

**토론 전용 문형**
```
찬성 측은 ~을 근거로 ~을 주장하고 있다
반대 측은 상대 발언의 ~을 문제 삼아 반박하고 있다
반대 신문에서 ~의 타당성을 검증하고 있다
상대의 주장을 일부 수용하면서 ~을 지적하고 있다
```

**대화·협상 문형**
```
A는 B의 제안을 조건부로 수용하고 있다
A는 대안을 제시하여 B의 우려를 해소하고 있다
A는 자신의 입장을 유보하며 추가 정보를 요구하고 있다
```

### 3-2. 작문

**계획 확인 문형**
```
[계획 항목]을 고려하여, ~을 ~하였다
독자의 이해를 돕기 위해 ~을 추가하였다
글의 목적을 고려하여 ~을 강조하였다
예상 독자의 관심을 반영하여 ~을 제시하였다
```

**자료 활용 문형**
```
(가)를 활용하여 ~을 뒷받침하는 근거로 제시한다
(나)와 (다)를 함께 활용하여 ~의 심각성을 부각한다
(가)의 통계를 인용하여 ~의 실태를 구체적으로 보여 준다
(다)의 전문가 견해를 인용하여 주장의 신뢰성을 높인다
```

**고쳐쓰기 문형**
```
글의 통일성을 고려하여 ~을 삭제한다
문맥의 흐름을 고려하여 ~을 ~ 뒤로 옮긴다
앞 문장과의 연결을 고려하여 접속어를 ~로 바꾼다
의미를 분명히 하기 위해 ~을 ~로 수정한다
주장을 뒷받침하기 위해 ~을 추가한다
```

`[분석]` 화작 오답은 문형을 벗어나지 않는다. **자료에 없는 것을 있다고 하거나(T8), 주체를 바꾼다(T3).** 그래서 대조만 정확히 하면 100% 판정된다.

## 4. 문법(언어) 선지 문형

```
㉠은 [분류]에 해당한다
㉠과 ㉡은 [기준]에서 차이가 있다
㉠에는 [요소]가 사용되었다
㉠은 [규칙]이 적용된 결과이다
㉠은 ~와 달리 [속성]을 지닌다
㉠에서 [변동]이 일어나 음운의 개수가 [증감]하였다
```

**탐구 활동형 문형** (학생 활동을 흉내 내는 형식)
```
[탐구 과제] → [자료] → [탐구 결과] 의 3단
"㉠을 보니 ~는 ~임을 알 수 있군"
"㉠과 ㉡을 비교해 보니 ~라는 차이가 있군"
```

**오답 제조**: 인접 개념으로 오분류(파생↔합성, 관형어↔부사어), 조건 하나 누락, 예외를 규칙으로 처리.

## 5. 발문 문형 전수

| 영역 | 발문 |
|---|---|
| 공통 | 윗글의 내용과 일치하지 **않는** 것은? |
| 공통 | 윗글에 대한 이해로 적절하지 **않은** 것은? |
| 공통 | 윗글을 바탕으로 추론한 내용으로 가장 적절한 것은? |
| 공통 | 윗글을 바탕으로 `<보기>`를 이해한 내용으로 적절하지 **않은** 것은? |
| 독서 | 윗글의 서술상 특징으로 가장 적절한 것은? |
| 독서 | ㉠~㉤에 대한 설명으로 적절하지 **않은** 것은? |
| 독서 | ⓐ~ⓔ의 문맥적 의미로 적절하지 **않은** 것은? |
| 독서 | (가)와 (나)에 대한 설명으로 가장 적절한 것은? |
| 문학 | (가)와 (나)의 공통점으로 가장 적절한 것은? |
| 문학 | `<보기>`를 참고하여 윗글을 감상한 내용으로 적절하지 **않은** 것은? |
| 문학 | [A]에 대한 이해로 가장 적절한 것은? |
| 문학 | ㉠~㉤에 대한 설명으로 적절하지 **않은** 것은? |
| 화법 | 위 발표에 대한 설명으로 가장 적절한 것은? |
| 화법 | 학생의 말하기 방식으로 적절하지 **않은** 것은? |
| 작문 | 다음은 초고를 쓰기 위한 작문 계획이다. 초고에 반영되지 **않은** 것은? |
| 작문 | `<자료>`를 활용하여 초고를 보완하는 방안으로 적절하지 **않은** 것은? |
| 작문 | ㉠을 고쳐 쓴 내용으로 가장 적절한 것은? |
| 문법 | `<보기>`의 ㉠~㉤에 대한 설명으로 적절하지 **않은** 것은? |
| 문법 | `<보기>`를 바탕으로 탐구한 내용으로 적절하지 **않은** 것은? |

`[분석]` **부정형("않는/않은")이 절반을 넘는다.** 이유는 명확하다 — 정답 1개를 "틀린 것"으로 두면, 나머지 4개가 지문의 정확한 환언이 되어 **정답 시비가 거의 발생하지 않는다.** 긍정형은 오답 4개를 각각 확실히 틀리게 만들어야 해서 위험 부담이 크다.

**따라서**: 부정형 발문이 보이면 "정답은 하나만 틀렸고 나머지 넷은 다 맞다"는 뜻이다. 넷을 확인하는 편이 빠를 때가 많다.

## 6. 이 문서 활용법

### 학생 훈련
1. 선지를 읽고 **어느 문형인지** 먼저 말하게 한다
2. 문형을 알면 **어디를 확인해야 하는지**가 자동으로 정해진다
3. `A형`이면 슬래시로 끊는다 — 이것이 기본기

### 자작 문항
`12-item-writing.md`의 규격과 함께 쓴다. **여기 없는 문형은 쓰지 마라.** 자의적 문형은 즉시 비평가원적으로 읽힌다.

### 사설 문항 판정
선지 문형이 이 목록을 벗어나면 감점 요인이다. 특히 "~라고 볼 수 있다", "~일 가능성이 크다" 같은 **애매한 종결**은 평가원이 쓰지 않는다 — 정답 확정성이 무너지기 때문이다.
