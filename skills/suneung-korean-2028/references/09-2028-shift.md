# 09. 2028 체제 — 무엇이 바뀌고 무엇이 그대로인가

## 1. 확정된 사실

`[검증]`

| 항목 | 2022~2027 체제 | 2028 체제 |
|---|---|---|
| 교육과정 | 2015 개정 | **2022 개정** |
| 선택과목 | 공통 + 택1(화법과 작문 / 언어와 매체) | **폐지 — 전원 동일 응시** |
| 출제 과목 | 독서·문학(공통) + 화작 or 언매 | **화법과 언어 + 독서와 작문 + 문학** |
| 매체 | '언어와 매체' 선택 시 출제 | **출제 범위에서 제외** |
| 문항 수 | 45 | **45 (유지)** |
| 시간 | 80분 | **80분 (유지)** |
| EBS 연계 | 50%, 간접연계 중심 | 유지 기조 |

**예시문항 공개**: 2025년 4월 15일, 교육부·평가원이 국어·수학·사회·과학 예시문항 문제지와 안내자료를 공개. 국어는 킬러문항 없이 기존 수능과 유사한 범위·난이도로 출제되었다는 것이 공식·언론 평가. `[검증]`

## 2. 과목 재편의 의미

`[검증]` 2022 개정 교육과정에서 국어과 과목 체계가 바뀌었다.

```
[2015 개정]            →   [2022 개정]
국어(공통)              →   공통국어1, 공통국어2
화법과 작문             →   화법과 언어
독서                    →   독서와 작문
언어와 매체             →   (매체는 별도 과목으로 분리)
문학                    →   문학
```

수능 출제 범위는 **화법과 언어 / 독서와 작문 / 문학** 세 과목이다.

### 재편이 만든 3가지 구조 변화 `[분석]`

**① 화법과 문법이 한 과목 안으로 들어왔다**
'화법과 작문'/'언어와 매체'라는 옛 조합이 해체되고 **'화법 + 언어(문법)'**가 한 과목이 되었다. 이는 두 영역을 묶은 **융합 문항의 제도적 근거**가 된다.

**② 독서와 작문이 한 과목 안으로 들어왔다**
읽기와 쓰기를 연속된 활동으로 보는 교육과정 관점이 반영됐다. 마찬가지로 **독서 지문 + 작문 활동을 결합한 세트**의 근거가 된다.

**③ 매체가 빠졌다**
2022~2027 언매 선택자가 대비하던 매체 영역(뉴 미디어 텍스트, 매체 언어의 특성 등)이 수능에서 사라졌다. 매체 대비 자료를 2028 학습에 쓰지 않는다.

## 3. 예시문항이 보여준 것

`[검증 + 확인필요]` — 예시문항의 존재와 공개 사실, 그리고 "융합 세트 등장"은 공개 분석에서 일관되게 확인된다. **문항별 세부 구성 수치는 원문 대조가 필요하다.**

### 확인되는 것 `[검증]`
- 국어 45문항 80분 유지
- 화법과 언어 / 독서와 작문 / 문학 세 영역 모두 출제
- **'화법과 언어' 융합 세트, '독서와 작문' 융합 세트가 신설 유형으로 등장**
- 초고난도 문항(킬러문항) 배제 기조 유지
- 지나친 추론이나 배경지식을 요구하는 지문·작품은 배제하되, 변별을 위해 **낯선 유형**이 일부 포함

### `[확인필요]`
영역별 문항 배분(예: 화법과 언어 10 / 독서와 작문 20 / 문학 15 형태)에 대한 사설 분석이 유통되고 있으나, **이는 예시문항 1회의 구성이지 2028 수능의 확정 배분이 아니다.** 수업 자료에 쓸 때는 반드시 "예시문항 기준"이라고 못 박고, 실제 수능 배분은 시행 기본계획으로 확정된다는 점을 함께 적는다.

> **원문 확보 경로**: 평가원 수능 홈페이지(suneung.re.kr) 자료실 → "2028학년도 대학수학능력시험 예시문항 문제지·정답표" 및 "예시문항 안내" PDF. `13-corpus.md` 참조.

## 4. 신유형: 융합 세트

`[분석]` 2028 대비에서 **가장 중요한 새 변수**다.

### 4-1. 화법 + 언어 융합

**예상 형태**:
- 대화/발표 담화를 제시하고, 그 담화에 나타난 **문법 현상**을 묻는다
- 예: 담화 속 높임 표현의 사용 양상, 지시어의 지시 대상, 피동 표현의 효과, 담화 상황에 따른 종결어미 선택

**왜 이 형태인가** `[분석]`: 문법을 고립된 지식이 아니라 **실제 언어 사용 맥락 안에서** 측정하라는 2022 개정 교육과정의 요구 때문이다. 이는 교육과정 문서의 지향과 정확히 맞아떨어져 출제 정당화가 쉽다.

**대비 방법**:
- 문법 개념 중 **담화에서 관찰 가능한 것**을 우선 학습: 높임법, 지시·대용, 시제, 피동·사동, 종결 표현, 인용
- 화법 지문을 읽을 때 **문법 요소에 표시하는 훈련**을 추가

### 4-2. 독서 + 작문 융합

**예상 형태**:
- 독서 지문(정보 텍스트)을 읽고, 그 내용을 활용해 **글을 쓰는 상황**을 제시
- 예: 지문을 읽고 작성한 학생의 초고 → 자료 활용 적절성, 고쳐쓰기
- 또는 작문을 위해 수집한 자료 중 하나로 독서 지문이 기능

**대비 방법**:
- "읽은 것을 쓰기에 활용하는" 대응 훈련. `05-speech-writing.md`의 화법+작문 융합 세트 훈련과 동일한 방식
- **지문 요약 → 요약을 근거로 주장문 쓰기** 활동이 직접적 대비가 된다

### 4-3. 융합 세트가 시간 관리에 미치는 영향 `[분석]`

융합 세트는 **자료가 둘 이상**이다. 대조할 것이 늘어난다는 뜻이고, 이는 **시간 압박이 커진다**는 뜻이다. 45문항 80분은 그대로인데 세트당 자료량이 늘면 부담은 증가한다.

**결론**: 2028 대비에서 시간 훈련의 중요도가 이전보다 커진다. 노베이스 커리큘럼 후반부에 시간 단축 훈련 블록을 반드시 넣는다.

## 5. 선택과목 폐지의 파급

`[분석]`

| 대상 | 영향 |
|---|---|
| 화작 선택 예정이었던 학생 | **문법을 반드시 해야 한다.** 가장 큰 부담 증가 |
| 언매 선택 예정이었던 학생 | 매체 학습이 무의미해짐. 화법·작문 부담 증가 |
| 전체 | 선택과목 간 표준점수 유불리 논란이 사라짐 |
| 학습 전략 | "유리한 과목 고르기"가 불가능. **전 영역 최소 방어**가 유일한 전략 |

`[분석]` **노베이스에게는 오히려 유리한 변화일 수 있다.** 선택 전략이 사라지면서, 규칙적이고 학습량이 예측 가능한 영역(문법·화작)에서 확실히 득점하고 독서에서 방어하는 구조가 가능해진다. 옛 체제에서는 화작런/언매런이라는 회피 경로가 오히려 학습 설계를 왜곡했다.

## 6. 2028 대비 학습 배분 권장

`[분석]` 노베이스 기준. 시간 배분이지 중요도 순위가 아니다.

| 영역 | 학습 시간 비중 | 이유 |
|---|---|---|
| 독서(비문학) | **40%** | 배점 최대, 습득 시간 최장 |
| 문학 | 25% | 풀이 유한, 회수율 높음 |
| 언어(문법) | 20% | 좁고 반복적, 필수화됨 |
| 화법·작문 | 15% | 규칙적, 훈련량이 곧 점수 |

**주의**: 초기 3개월은 이 비중을 쓰지 않는다. 초기에는 **문법 40% + 화작 30% + 문학 20% + 독서 10%**로 시작해 **빠른 성공 경험**을 만든 뒤 비중을 옮긴다. 노베이스가 독서부터 시작하면 대부분 이탈한다. → `10-curriculum-novice.md`
