# 24. EBS 연계의 실제 작동 방식 — 실물 대조로 밝힌 변형 규칙

`01-exam-system.md` §5에서 EBS 연계를 "간접연계, 화제만 겹치고 지문은 새로 쓴다"고 서술했다. **이제 그 '새로 쓰는 방식'의 규칙을 실물로 확인했다.**

## 0. 자료

`[검증: 단일 출처 / EBS 원문과 모평 지문을 직접 대조]` 한 국어 전문학원이 **2027학년도 6월 모의평가**(2026.6.4 시행 — 현재 기준 가장 최근 평가원 시행)의 지문과 **2026학년도 EBS 수능특강** 원문을 나란히 놓고 대조한 자료다. EBS 해제·주제·문단 구성이 그대로 인용되어 있다.

**이것이 귀한 이유**: 대부분의 연계 분석은 "겹친다/안 겹친다"로 끝난다. 이 자료는 **무엇이 유지되고 무엇이 추가되었는지**를 문단 단위로 보여준다.

## 1. 실물 대조 3건

### 대조 ① 독서 이론 — SQ3R

| | EBS 수능특강 | **2027 6월 모평 [1~3]** |
|---|---|---|
| 제목 | SQ3R과 CSQ3R | SQ3R 읽기 전략 |
| 핵심 | SQ3R 5단계: 훑어보기·질문하기·읽기·확인하기·재검토하기 | SQ3R 5단계: 훑어보기·질문하기·읽기·**암송하기**·재검토하기 |
| 확장 | **CSQ3R** = 시각 바꾸기 추가 | **'관점 바꾸기' + '숙고하기'** 추가한 확장 전략 |
| 문단 | 4문단 (도입 / 5단계 / CSQ3R / 활용·의의) | 구성·원리 → 확장 전략 |

**변형 규칙**: 기본 틀은 그대로. **확장 항목을 하나에서 둘로 늘렸다.**

### 대조 ② 사회 — 정보 비대칭

| | EBS 수능특강 | **2027 6월 모평 [10~13]** |
|---|---|---|
| 제목 | 정보 비대칭과 역선택 | 온라인 정보 비대칭 상황과 **사상의 자유 시장 이론** |
| 개념 | 정보 비대칭 → 역선택 | 정보 비대칭 (동일) |
| 해결책 | 신호 발송 / 선별 / 평판 구축 (3가지) | **정부의 시장 개입** |
| 추가된 것 | — | **온라인 + 생성형 AI 허위·과장 광고** 맥락 / **정부 개입 찬반 논쟁** |
| 구조 | 문제 → 해결 방안 나열 | 문제 → **대립하는 두 입장** |

**변형 규칙**: 개념은 그대로 가져오되 **① 최신 맥락(온라인·생성형 AI)을 씌우고 ② 해결책 나열을 대립 구도로 바꿨다.**

`[분석]` **골격이 바뀌었다.** EBS는 골격 F(문제 해결형)인데 모평은 **골격 B(대립 구도형)** 로 재조립되었다. → `03-reading.md` §3

### 대조 ③ 과학·기술 — 라플라스 식

| | EBS 수능특강 | **2027 6월 모평 [14~17]** |
|---|---|---|
| 제목 | 폐포의 표면 장력과 계면 활성제 | **라플라스 식의 원리와 적용 사례** |
| 범위 | **폐포 하나**에 한정 | **구형 액체 방울 일반**으로 확대 |
| 라플라스 법칙 | 폐포 붕괴 설명 도구로 등장 | **지문의 중심 개념으로 승격** |
| 적용 사례 | 폐포 (1개) | **폐포 / 두 기포의 합체 / 잉크젯 프린터 (3개)** |

**변형 규칙**: **하위 사례를 상위 원리로 끌어올리고, 적용 사례를 1개에서 3개로 늘렸다.**

`[분석]` 이것이 가장 전형적인 변형이다. EBS에서 "폐포를 설명하는 도구"였던 라플라스 법칙이 모평에서는 **주인공**이 되고, 폐포는 여러 사례 중 하나로 강등된다.

## 2. 도출되는 변형 규칙 4가지

`[분석]` 세 건의 공통 패턴이다. 표본이 셋뿐이므로 규칙이 아니라 **경향**으로 다룬다.

### 규칙 A — 층위 상승 (Level-up)
> EBS의 **구체 사례**를 모평의 **상위 원리**로 올린다.

```
EBS: 폐포(구체) ← 라플라스 법칙으로 설명
        ↓
모평: 라플라스 식(원리) → 폐포·기포·잉크젯(사례들)
```

### 규칙 B — 사례 증식 (Multiply)
> 적용 사례를 **1개 → 2~3개**로 늘린다. `<보기>` 문항의 재료가 된다.

### 규칙 C — 맥락 갱신 (Re-contextualize)
> 개념은 유지하고 **최신 상황을 씌운다.**
> 정보 비대칭 → **온라인 + 생성형 AI 허위광고**

### 규칙 D — 구도 전환 (Re-frame)
> **나열형을 대립형으로** 바꾼다. 해결책 3개 나열 → 정부 개입 찬반 논쟁.
> 대립 구도가 되면 "각 입장이 상대의 무엇을 부정하는가" 문항이 만들어진다.

## 3. 학습에 주는 함의

`[분석]`

### EBS 교재를 어떻게 볼 것인가

| 잘못된 방식 | 옳은 방식 |
|---|---|
| 지문을 통째로 외운다 | **개념과 원리만 뽑아 정리한다** |
| "이 지문이 나오나?" | **"이 개념이 더 넓은 원리의 사례는 아닌가?"** |
| 사례를 암기 | **"이 원리가 적용될 다른 사례는?"** 스스로 찾기 |
| 지문 구조를 그대로 기억 | **"이 내용을 대립 구도로 바꾸면?"** 상상해 보기 |

### 구체적 훈련 절차

EBS 지문 하나를 읽은 뒤 다음 4칸을 채우게 한다.

```
[규칙 A] 이 글의 중심 개념보다 상위의 원리는 무엇인가?
         ______________________________________

[규칙 B] 이 원리가 적용될 다른 사례 2개는?
         ① ______________  ② ______________

[규칙 C] 이 개념에 최신 맥락을 씌우면?
         ______________________________________

[규칙 D] 이 내용을 두 입장의 대립으로 바꾸면?
         (가) ______________ ↔ (나) ______________
```

`[분석]` **이 훈련이 EBS 연계 대비의 정석이다.** 지문을 외우는 학생은 변형된 지문 앞에서 무너지고, 이 훈련을 한 학생은 "아, 그거 확장한 거네"로 읽는다.

## 4. 연계 강도의 변화

`[검증: 해당 자료의 서술]`

> "이전에는 **제재가 겹치는 수준**에서 EBS 연계로 출제되었다면, 이번에는 **중심 내용이 거의 비슷한 수준**으로 출제되었다."
> "말뿐인 연계가 아닌 **실질적인 연계**로 출제되었다. EBS 수능특강을 잘 공부한 학생들은 쉽게 내용을 파악할 수 있도록 출제되었다."

`[분석]` **연계 체감도가 올라가는 방향으로 움직이고 있다.** 2022학년도에 70%→50%로 줄이고 간접연계로 전환했지만, 최근에는 그 50% 안에서 **연계 강도를 높이는** 쪽으로 조정되는 것으로 보인다.

**단, 이것은 2027학년도 6월 모평 1회 관찰이다.** 본수능에서 같은 강도가 유지된다는 보장은 없다. 모의평가는 대체로 본수능보다 평이하게 출제되는 경향이 있다(이 회차 1등급컷 화작 96, 언매 95).

## 5. 2028에서는 어떻게 되는가

`[분석]`

- EBS 연계 50% 기조는 2028에도 유지될 것으로 보인다 (시행 기본계획으로 확정됨)
- **다만 연계 교재 자체가 2022 개정 교육과정 기준으로 새로 나온다.** 과목명이 `화법과 언어`·`독서와 작문`·`문학`으로 바뀌므로 교재 구성도 바뀐다
- **위 변형 규칙 A~D는 교재가 바뀌어도 유효할 가능성이 높다.** 규칙은 교재 내용이 아니라 출제 방식이기 때문이다
- 융합 세트에서는 **한 EBS 제재가 독서 지문과 작문 자료 양쪽에 쓰일** 수 있다
