# 03. 독서(비문학) — 지문 구조와 논리

`[검증]` 2022~2027학년도 체제에서 국어 45문항은 **공통 34(독서 17 + 문학 17) + 선택 11**이다. 독서는 17문항으로 단일 영역 최대 비중이며, 대체로 3개 세트(제재가 다른 지문 3개)로 구성된다. 2028 체제의 배분은 `09-2028-shift.md` 참조.

가장 배점이 크고, 노베이스가 가장 크게 무너지는 영역이다. 이 문서는 지문이 **어떻게 조립되는지**를 설명한다. 조립 규칙을 알면 읽는 순서가 바뀐다.

## 1. 지문은 '글'이 아니라 '문항 제작을 위한 구조물'이다

`[분석]` 이 인식 전환이 전부다.

수능 독서 지문은 원전을 그대로 옮긴 것이 **아니다.** 출제진이 원자료를 읽고 **문항 5~6개를 뽑을 수 있도록 재설계한 인공 텍스트**다. 그래서:

- 문단마다 **문항이 걸릴 지점**이 심어져 있다
- 정보가 균등하게 분포하지 않는다. 핵심 정보는 특정 문장에 압축된다
- 원전에 있었을 완충 설명·예시·중복은 대부분 삭제되어 있다 → 그래서 밀도가 높고 어렵게 느껴진다
- **모든 문장이 어딘가에 쓰인다.** 장식용 문장은 거의 없다

**교육적 함의**: "천천히 여러 번 읽어라"는 최악의 조언이다. **어디에 무엇이 심겼는지 예측하며 읽어라**가 맞다.

## 2. 제재 지도

`[분석]` 33년 기출에서 관찰되는 제재 분포와 각 제재의 지문 문법.

### 2-1. 인문 (철학·윤리·역사·언어)

| 하위 | 전형적 지문 형태 | 문항이 걸리는 곳 |
|---|---|---|
| 서양철학 | 한 개념에 대한 두 철학자의 대립 | 두 입장의 차이점, 각 입장이 반박하는 지점 |
| 동양철학 | 유가·도가 개념의 층위 구분 | 개념어의 정의 경계 |
| 역사·사학사 | 사료 해석 방법론의 변천 | 방법론 간 전제 차이 |
| 논리학·언어철학 | 명제·지시·의미 이론 | 조건 관계, 반례 |

**지문 문법**: 개념 정의 → 그 개념의 문제점 → 대안 제시 → 대안의 한계. 4단 구조가 압도적으로 흔하다.

### 2-2. 사회 (법·경제·정치·행정)

| 하위 | 전형적 지문 형태 | 문항이 걸리는 곳 |
|---|---|---|
| 법 | 제도의 요건·효과, 예외 규정 | **요건과 예외의 경계** — 최다 출제 지점 |
| 경제 | 시장 메커니즘, 정책 효과의 인과 사슬 | 변수 간 증감 방향 |
| 정치·행정 | 권한 배분, 절차 | 주체별 권한 범위 |

**지문 문법**: 원칙 제시 → 요건 나열 → **예외 또는 단서** → 사례 적용. 법·경제 지문의 정답은 **단서 조항 근처에 놓이는 경우가 많다.**

> **노베이스 지도 핵심**: 사회 지문에서 "다만", "단", "그러나", "~인 경우에는"이 나오면 형광펜. 여기가 문항이다.

### 2-3. 과학 (물리·화학·생명·지구)

| 하위 | 전형적 지문 형태 | 문항이 걸리는 곳 |
|---|---|---|
| 생명과학 | 생체 내 과정의 단계별 진행 | 단계 순서, 물질의 증감 |
| 물리·화학 | 현상의 원리 + 정량 관계 | 비례/반비례 관계 |
| 지구·천문 | 관측 원리, 모형의 발전 | 모형이 설명하는 것과 못하는 것 |

**지문 문법**: 현상 제시 → 원인 설명 → 메커니즘 단계화 → 조건 변화 시 결과. 과학 지문의 `<보기>`는 **조건을 바꿔서 결과를 묻는** 형태가 표준.

### 2-4. 기술 (공학·정보)

- 장치·시스템의 작동 과정 서술이 핵심
- **그림·도식이 붙는 비율이 가장 높다**
- 각 부품/단계의 기능과 순서가 문항이 됨
- 정답 오류 위험이 낮아 출제진이 선호하는 제재

**지문 문법**: 목적 → 구성 요소 → 작동 순서 → 성능 제약 요인.

### 2-5. 예술 (미술·음악·건축·영화)

- 양식/사조의 대비, 매체 특성 논의
- 상대적으로 짧고 평이한 편
- 인문 지문의 변형으로 다뤄도 된다

### 2-6. 융합·주제 통합

`[분석]` 2019학년도 전후로 정착한 형태. 두 텍스트를 (가)(나)로 병치하거나, 한 화제를 두 학문 관점으로 다룬다.

- (가) 이론/원리 + (나) 그 적용/비판
- (가) 서양 관점 + (나) 동양 관점
- **문항의 절반이 "(가)와 (나)의 관계"를 묻는다**

이 형태는 2028의 융합 세트로 이어진다. → `09-2028-shift.md`

## 3. 지문 논리 골격 8종

`[분석]` 제재를 가로질러 반복되는 **논리 뼈대**다. 지문을 읽을 때 "이건 몇 번 골격이지?"를 먼저 판단하게 훈련한다.

### 골격 A — 개념 정의형
```
X란 무엇인가 → X의 구성 요소 → 요소 간 관계 → X의 적용 범위/한계
```
문항: 정의의 경계를 건드림. "X에 해당하지 않는 것은?"

### 골격 B — 대립 구도형
```
쟁점 제시 → 갑의 입장(근거) → 을의 입장(근거) → 대립의 핵심 → (때로) 절충
```
문항: **각 입장이 상대의 무엇을 부정하는가.** 가장 흔한 오답: 갑의 근거를 을에게 붙이기.

### 골격 C — 통시적 발전형
```
초기 이론 → 문제 발견 → 수정 이론 → 남은 문제 → 현재
```
문항: **단계 순서**와 "각 단계가 해결한 문제 / 해결 못 한 문제". 오답은 시점 뒤섞기.

### 골격 D — 과정 서술형 (과학·기술 주력)
```
목적/현상 → 1단계 → 2단계 → … → n단계 → 결과 → 변수 변화 시 결과 변화
```
문항: 단계 건너뛰기, 순서 바꾸기, 증감 방향 뒤집기.

### 골격 E — 원칙·예외형 (법·제도 주력)
```
원칙 → 요건 ①②③ → 효과 → 예외 상황 → 예외의 근거
```
문항: 사례를 주고 요건 충족 여부 판정. **`<보기>` 문항 필연.**

### 골격 F — 문제 해결형
```
문제 상황 → 원인 분석 → 해결책 A(장단점) → 해결책 B(장단점) → 선택 기준
```
문항: 각 해결책이 어떤 원인을 겨냥하는가.

### 골격 G — 모형·이론 적용형
```
모형 소개 → 가정 → 도출 결과 → 가정이 깨지면? → 수정 모형
```
문항: **가정의 역할.** "가정 ①이 없다면 어떻게 되는가"

### 골격 H — 비교 병렬형 (융합 지문)
```
(가) 관점1 전개 ‖ (나) 관점2 전개 → 공통 화제 → 차이의 층위
```
문항: 공통점·차이점, 한쪽 관점으로 다른 쪽 평가하기.

### 골격 판별 훈련법 (노베이스용)

지문 첫 두 문단만 읽고 골격을 찍게 한다. 정답률 자체보다 **"골격을 생각하며 읽는 습관"**이 목표다.

| 신호어 | 골격 |
|---|---|
| "~란 ~을 말한다", "~로 정의된다" | A |
| "반면", "이에 대해 ~는 반박한다" | B |
| "이후", "그러나 이 이론은 ~ 한계에 부딪혔다" | C |
| "먼저 ~ 다음으로 ~ 마지막으로" | D |
| "원칙적으로", "다만", "~에 한하여" | E |
| "이러한 문제를 해결하기 위해" | F |
| "~라고 가정하면" | G |
| (가)/(나) 병치 | H |

## 4. 정보 배치 규칙 — 어디에 문항이 숨는가

`[분석]` 지문 안에서 문항이 걸리는 지점에는 규칙성이 있다.

### 고빈도 지점 (형광펜 대상)

1. **정의 문장** — "~란 ~이다", "~를 ~라 한다"
2. **인과 연결어** — 따라서, 그러므로, ~때문에, ~로 인해
3. **역접·전환** — 그러나, 하지만, 반면, 그런데
4. **한정·조건** — 다만, ~인 경우에만, ~에 한해, ~가 아니라면
5. **비교급·정도** — 더, 덜, 클수록, 반비례
6. **열거 표지** — 첫째/둘째, 하나는/다른 하나는
7. **부정 표현** — ~는 아니다, ~와 달리, ~하지 않는다
8. **지시어의 지시 대상** — 이, 그, 이러한, 이때
9. **괄호 안 부연** — 대개 여기서 한 선지가 나온다
10. **마지막 문단의 한계·전망** — "다만 ~는 한계가 있다"

### 저빈도 지점 (읽되 붙들지 않을 곳)

- 도입부의 일반론·배경 (첫 2~3문장)
- 이해를 돕기 위한 비유·예시 (단, `<보기>`에서 다시 쓰일 수 있음)
- 고유명사·연도 (그 자체를 묻는 경우는 드물다)

> **노베이스 훈련**: 지문 하나를 주고 "문항이 걸릴 것 같은 문장 5개에 밑줄" → 실제 문항과 대조. 이 훈련이 독해 강의 어떤 것보다 효과가 크다.

## 5. 문항 유형 6종과 각각의 공략

`[분석]` 독서 세트는 대체로 아래 유형의 조합으로 구성된다.

### 유형 1 — 전개 방식 / 서술 방식 (대체로 세트 첫 문항)
- 발문: "윗글의 서술 방식으로 적절한 것은?", "(가)와 (나)의 공통점은?"
- 판정: 지문 **전체**의 형식적 특징. 내용의 옳고 그름이 아님
- 흔한 오답: 지문에 실제로 없는 서술 방식(예: "통념을 반박하며 시작한다"인데 통념 제시가 없음)
- **노베이스 공략**: 이 유형은 지문을 다 안 읽어도 문단 첫 문장만으로 상당 부분 풀린다. 시간 관리상 먼저 푸는 것을 권장

### 유형 2 — 내용 일치 / 세부 정보
- 발문: "윗글의 내용과 일치하는 것은?" / "~에 대한 이해로 적절하지 않은 것은?"
- 판정: 선지 하나하나를 지문 문장에 **대응시켜** 확인
- **핵심**: 선지의 서술어와 지문의 서술어가 같은지 본다. 주어는 같은데 서술어가 미묘하게 다른 것이 표준 오답

### 유형 3 — 추론
- 발문: "윗글을 바탕으로 추론한 내용으로 적절한 것은?"
- 판정: 지문에 직접 없지만 **지문 정보만으로 도출되는** 것
- 함정: "그럴듯하지만 지문 정보로 도출 안 되는 것"(상식 유도형)
- **노베이스 공략**: 추론이라고 상상하지 말 것. "지문의 어느 문장 + 어느 문장을 합치면 이 말이 나오나"를 반드시 짚는다. 못 짚으면 오답이다

### 유형 4 — 구체적 사례 적용 (`<보기>` 문항, 3점 다수)
- 발문: "윗글을 바탕으로 `<보기>`를 이해한 내용으로 적절하지 않은 것은?"
- 판정: 지문의 원리 ↔ `<보기>`의 사례를 **대응**시킴
- 함정: 대응 자체를 어긋나게 하거나, 증감 방향을 뒤집음
- **노베이스 공략**: `<보기>`를 먼저 읽고 지문과 대응표를 손으로 그린다. 지문의 A=보기의 a, 지문의 B=보기의 b 식으로

### 유형 5 — 어휘 (문맥적 의미)
- 발문: "@의 문맥적 의미와 가장 가까운 것은?" / 밑줄 친 어휘를 바꿔 쓰기
- 판정: 사전적 뜻이 아니라 **그 문장에서의 쓰임**
- **노베이스 공략**: 밑줄 어휘를 선지 단어로 바꿔 **문장 전체를 소리 내어 읽어본다.** 어색하면 탈락. 가장 확실한 득점처이므로 반드시 챙기게 한다

### 유형 6 — 지시어 / 특정 부분 이해
- 발문: "㉠에 대한 설명으로 적절한 것은?", "㉠~㉤ 중 성격이 다른 것은?"
- 판정: 밑줄 친 부분의 **국소적** 의미와 기능
- **노베이스 공략**: 밑줄 앞뒤 두 문장 안에 답이 있다. 지문 전체를 뒤지지 않게 한다

### 세트 구성의 전형 `[분석]`

일반 독서 세트(지문 1개, 문항 4~6개)의 흔한 배열:

```
① 전개 방식 또는 중심 내용
② 세부 정보 일치
③ 추론 또는 특정 부분 이해
④ <보기> 적용 (3점)
⑤ 어휘
```

**시간 배분 지도**: ⑤ → ① → ② → ③ → ④ 순으로 푸는 것이 노베이스에게 유리하다. 쉬운 것부터 확보하고, 시간을 많이 먹는 `<보기>` 문항을 마지막에 둔다.

## 6. 독서 지문의 자료 출처

`[분석]` + `[확인필요]` — 개별 지문의 원자료는 평가원이 공개하지 않는다. 아래는 지문에 드러난 특징으로부터의 추정이며, 단정하지 마라.

지문의 성격상 다음 유형의 자료가 재구성 원천으로 쓰이는 것으로 보인다:

| 자료 유형 | 특징 | 제재 |
|---|---|---|
| 대학 교양 교재·개론서 | 개념 정의가 정돈되어 있어 재구성 용이 | 인문·사회 전반 |
| 학술 논문의 서론·이론 배경부 | 쟁점 정리가 되어 있음 | 인문·사회 |
| 과학 교양서·과학 저널 리뷰 논문 | 메커니즘 서술 | 과학 |
| 기술 개론서·표준 문서 | 작동 원리 | 기술 |
| 법령·판례 해설서 | 요건·효과 구조 | 법 |
| 미학·예술사 개론 | 사조 대비 | 예술 |

**중요한 점**: 원자료가 무엇이든 **최종 지문은 출제진이 새로 쓴 글**이다. 원전을 찾아 읽는 것은 학습 효율이 낮다. 원전 추적은 교사의 이해를 위한 작업이지 학생 과제가 아니다.

`[분석]` 다만 **화제 선정**에는 관찰 가능한 경향이 있다:
- 고교 교육과정과 접점이 있되 교과서에 그대로 없는 화제
- 정치적·종교적 논쟁을 피할 수 있는 화제 (이의신청 리스크 회피)
- 정답이 하나로 확정되는 화제 (해석 여지가 큰 인문 담론은 회피되는 경향)
- 최신 시사 이슈는 회피 (합숙 기간과 시행 사이의 시차 때문)

## 7. 노베이스용 독서 학습 설계

`[분석]` 이 순서를 어기면 실패한다.

### 0단계 — 문장 읽기 (2~3주)
지문 이전에 **한 문장**을 다룬다. 주어-서술어 찾기, 수식 관계 끊기. 기출 지문에서 한 문장씩 뽑아 쓴다.

### 1단계 — 문단 요약 (3~4주)
문단 하나를 읽고 **한 문장으로** 요약. 정답과 대조. 이 단계에서 골격 A~H를 소개한다.

### 2단계 — 지문 구조 그리기 (4주)
`assets/passage-analysis-sheet.md` 사용. 문단별 역할 표시, 골격 판정, 형광펜 지점 표시. **문제는 아직 풀지 않는다.**

### 3단계 — 유형별 문항 (6주)
유형 5(어휘) → 1(전개) → 2(일치) → 6(부분) → 3(추론) → 4(`<보기>`) 순. 유형별로 몰아서 훈련.

### 4단계 — 세트 통풀이 + 시간 관리 (지속)
지문 1세트 12~15분 → 10분으로 단축.

**흔한 실패**: 0~1단계를 건너뛰고 2단계부터 시작. 문장을 못 읽는 학생에게 구조를 그리라고 하면 구조만 베낀다.
