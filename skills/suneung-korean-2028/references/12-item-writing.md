# 12. 문항 자작 규격 — 평가원의 틀로 만들기

기출이 부족하거나 특정 유형을 반복 훈련시켜야 할 때 문항을 만든다. **자작임을 반드시 밝히고**, 아래 규격을 지킨다. 규격을 안 지킨 자작 문항은 학생에게 잘못된 감각을 심는다.

## 1. 자작 전 확인

- [ ] 이 유형의 기출이 정말 부족한가? (있으면 기출을 쓴다)
- [ ] 목표 유형과 목표 오답 태그를 정했는가?
- [ ] 자작임을 표기할 준비가 되었는가?

## 2. 독서 지문 자작 규격

### 2-1. 분량

`[분석]` 현행 기출 규격에 맞춘다.

| 세트 규모 | 지문 길이 | 문항 수 |
|---|---|---|
| 소형 (훈련용) | 600~900자 | 2~3 |
| 표준 | 1,300~1,800자 | 4~5 |
| 융합/장문 | 2,000~2,600자 | 5~6 |

### 2-2. 지문 작성 절차

```
1) 골격 선택 (A~H, 03-reading.md §3)
2) 화제 선택 — 정치·종교 논쟁 회피, 정답 확정 가능한 것
3) 문단 설계표 작성:
   ①문단: 역할 ____ / 심을 정보 ____ / 여기서 나올 문항 ____
   ②문단: …
4) 각 문단을 쓴다. 문단마다 최소 1개의 '형광펜 지점' 배치
5) 전체 검토: 장식 문장이 있으면 삭제하거나 정보를 넣는다
```

### 2-3. 지문의 필수 요건

- **모든 문장이 어딘가에 쓰인다.** 문항과 무관한 문장은 지문 밀도를 왜곡한다
- **핵심 관계는 명시적으로 진술한다.** "A가 커지면 B가 작아진다"를 애매하게 쓰지 않는다 — 정답 시비의 원천
- **단서·예외를 최소 1개** 넣는다. 여기서 좋은 문항이 나온다
- **정의 문장을 최소 2개** 넣는다

### 2-4. 흔한 자작 실패

| 실패 | 증상 | 교정 |
|---|---|---|
| 정보 밀도 부족 | 문항 3개를 못 만든다 | 문단당 정보 2개 이상 |
| 관계 서술 애매 | 정답이 둘로 갈린다 | 관계를 문장으로 명시 |
| 지나친 전문성 | 배경지식 없으면 못 읽는다 | 지문 내에서 개념을 다 설명 |
| 원전 베끼기 | 저작권 문제 + 밀도 불일치 | 자기 문장으로 재구성 |

## 3. 발문 작성 규격

`[분석]` 평가원 발문의 문형을 따른다. 자의적 발문은 즉시 티가 난다.

### 표준 발문 문형

| 유형 | 표준 문형 |
|---|---|
| 전개 방식 | 윗글의 서술상 특징으로 가장 적절한 것은? |
| 내용 일치 | 윗글의 내용과 일치하지 **않는** 것은? |
| 이해 | 윗글에 대한 이해로 적절하지 **않은** 것은? |
| 추론 | 윗글을 바탕으로 추론한 내용으로 가장 적절한 것은? |
| 보기 적용 | 윗글을 바탕으로 `<보기>`를 이해한 내용으로 적절하지 **않은** 것은? |
| 부분 이해 | ㉠에 대한 설명으로 가장 적절한 것은? |
| 어휘 | ⓐ의 문맥적 의미와 가장 가까운 것은? |
| 문학 표현 | (가)와 (나)의 공통점으로 가장 적절한 것은? |
| 문학 보기 | `<보기>`를 참고하여 윗글을 감상한 내용으로 적절하지 **않은** 것은? |

### 발문 규칙

- 부정형("않는")을 쓸 때는 **굵게** 표시 (기출은 굵게 표시함)
- "가장 적절한"과 "적절한"을 구분해서 쓴다
- 발문에서 답을 흘리지 않는다
- 한 발문에 요구 사항 1개

## 4. 선지 작성 규격 — 가장 중요

`[분석]` 여기서 자작 문항의 질이 결정된다.

### 4-1. 정답 선지

- 지문 문장의 **환언**으로 만든다 (`07-choice-logic.md` §2의 4가지 방식)
- 지문에 없는 새 개념어를 넣지 않는다
- 지문의 **두 문장 이상을 결합**해야 할 때는 결합 지점을 분명히 한다
- **길이가 유독 길거나 짧지 않게** — 기출에서 정답 선지는 길이로 튀지 않는다

### 4-2. 오답 선지

- **각 오답은 정확히 하나의 T태그**를 갖는다. 두 군데 틀린 오답은 만들지 않는다(판정이 흐려진다)
- 5개 선지의 오답 태그가 **서로 다르게** 배치되면 훈련 효과가 높다
- 최소 1개는 **매력적 오답**으로 설계한다 (`07-choice-logic.md` §4의 원리 적용)

### 4-3. 선지 세트 설계표

문항마다 아래 표를 먼저 채운 뒤 선지를 쓴다.

```
문항 목표: 조건-결과 관계 판정 훈련
정답: ③  근거: ②문단 2번째 문장 + ③문단 단서

① T4 범위 확대 — "모든"으로 넓힘
② T6 조건 혼동 — 필요조건을 충분조건으로  ★매력적 오답
③ [정답] ②문단 환언 (어휘 대체 방식)
④ T1 인과 역전
⑤ T8 외삽 — 상식적으로 맞지만 지문 근거 없음
```

### 4-4. 선지 길이·형식

- 5개 선지의 길이를 비슷하게
- 문형을 통일 (전부 "~하고 있다" 또는 전부 "~이다")
- 선지 안에 판단 지점 2~3개를 두려면, **절 단위로 자연스럽게 끊기도록** 쓴다

## 5. `<보기>` 작성 규격

### 독서 `<보기>`
- 지문 원리에 **정확히 대응**하는 사례/자료를 만든다
- 대응 요소마다 기호를 붙일 수 있게 설계 (a, b, c)
- 지문에 없는 원리를 요구하지 않는다
- 수치가 있으면 지문의 관계식과 모순이 없는지 검산

### 문학 `<보기>`
- 3~6문장
- 문장마다 **작품의 특정 요소를 지시**하도록
- 학계 통설과 어긋나는 해석을 주지 않는다
- 작품에 근거 없는 진술을 넣지 않는다 (정답 시비)

## 6. 문법 문항 자작 규격

- 예문은 **명확히 하나의 분석만 가능**해야 한다. 중의적 문장 금지
- 반례를 오답으로 쓸 때는 경계가 분명한 것으로
- 교과서(학교문법) 기준을 따른다. 학술적 이견이 있는 분석은 피한다
- 중세국어 자료를 쓸 때는 **현대어 풀이를 반드시 병기**

## 7. 화작 문항 자작 규격

- 담화/자료의 발화·문장에 번호를 매긴다
- 오답은 T3(주체 혼동), T8(자료에 없음) 중심으로
- 자료에 근거가 100% 있도록 — 화작에서 추론 요구는 규격 이탈

## 8. 자작 문항 검수 체크리스트

만든 뒤 반드시 돌린다. 하나라도 걸리면 고친다.

### 지문
- [ ] 골격이 명확한가
- [ ] 장식 문장이 없는가
- [ ] 핵심 관계가 문장으로 명시되어 있는가
- [ ] 배경지식 없이 읽히는가
- [ ] 단서/예외가 있는가

### 발문
- [ ] 평가원 표준 문형인가
- [ ] 부정어가 표시되어 있는가
- [ ] 요구 사항이 하나인가

### 선지
- [ ] 정답이 지문의 환언인가
- [ ] **정답이 하나로 확정되는가** (제3자에게 확인받는 것이 가장 좋다)
- [ ] 각 오답이 정확히 하나의 지점에서 틀리는가
- [ ] 오답 태그가 서로 다른가
- [ ] 매력적 오답이 최소 1개 있는가
- [ ] 선지 길이가 고르게 분포하는가
- [ ] 정답 선지가 길이·형식으로 튀지 않는가

### `<보기>`
- [ ] 지문/작품과 정확히 대응하는가
- [ ] 대응 기호를 붙일 수 있는가
- [ ] 근거 없는 진술이 없는가

### 전체
- [ ] **자작임을 표기했는가**
- [ ] 저작권 문제가 있는 원문을 그대로 쓰지 않았는가
- [ ] 목표 유형·목표 태그를 실제로 훈련시키는가

## 9. 기출을 "평가원 스타일인가" 판정할 때

사설 문항의 규격 적합성을 물어오면 아래로 판정한다.

| 항목 | 평가원 규격 | 이탈 신호 |
|---|---|---|
| 정답 근거 | 지문 문장으로 특정 가능 | "종합적으로 판단하면" |
| 오답 결함 | 한 지점, 명확 | 애매하게 틀림, 두 군데 틀림 |
| 발문 | 표준 문형 | 자의적 표현 |
| 선지 길이 | 고름 | 정답만 길거나 짧음 |
| 배경지식 | 불필요 | 알아야 풀림 |
| `<보기>` | 지문과 정확 대응 | 새 원리 요구 |
| 지문 밀도 | 장식 문장 없음 | 여백이 많음 |

각 항목을 O/X로 판정해 표로 제시한다. 총평보다 항목별 판정이 훨씬 유용하다.
