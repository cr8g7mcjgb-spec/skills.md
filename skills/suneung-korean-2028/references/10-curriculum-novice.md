# 10. 노베이스 커리큘럼 — 0에서 시작하는 설계

이 문서는 "국어를 아예 안 한 학생"을 전제로 한다. 기존 커리큘럼이 노베이스에게 실패하는 이유는 난도가 아니라 **순서**다.

## 1. 진단 — 무엇을 못 하는지 특정한다

`[분석]` "국어 못한다"는 정보가 아니다. 아래 5개 진단 과제로 정확한 지점을 찾는다. 각 과제는 5~10분.

### 진단 과제 5종

| # | 과제 | 통과 기준 | 실패 시 시작 지점 |
|---|---|---|---|
| **D1** | 기출 독서 지문의 **한 문장**을 주고 주어·서술어 찾기 (5문장) | 4/5 | **0단계: 문장 읽기** |
| **D2** | 독서 지문 **한 문단**을 읽고 한 문장으로 요약 (3문단) | 2/3 | **1단계: 문단 요약** |
| **D3** | 현대시 1편 + 화자·정서 답하기 | 정확 | 문학 1단계 |
| **D4** | 문장 5개의 서술어 개수 세기(겹문장 판별) | 4/5 | 문법 1단계 |
| **D5** | 화작 세트 1개, 시간 무제한 | 3/3 정답 | 화작은 시간 훈련만 |

**해석 규칙**:
- D1 실패 → 다른 진단 볼 필요 없다. **문장 읽기부터.** 여기서 시작하지 않으면 무엇을 해도 무너진다.
- D1 통과, D2 실패 → 문단 요약부터
- D5는 대부분 통과한다. 통과하면 "너는 국어를 못하는 게 아니라 안 해본 것"이라고 말해줘라. **노베이스의 첫 성공 경험**으로 쓴다

### 진단 결과 기록 양식

```
학생: ___   진단일: ___
D1 ○/✕  D2 ○/✕  D3 ○/✕  D4 ○/✕  D5 ○/✕
시작 지점: ______
주요 약점: ______
```

## 2. 설계 원칙 5가지

`[분석]` 노베이스 커리큘럼이 다른 커리큘럼과 달라야 하는 지점.

### 원칙 1 — 쉬운 영역부터 시작한다 (독서 아님)

노베이스가 독서(비문학)부터 시작하면 **80% 이상이 이탈한다.** 성취감이 안 나오기 때문이다.

**시작 순서**: 화작 → 문법 → 문학 → 독서

- **화작**: 대조만 하면 맞는다. 첫 주에 정답률이 오른다
- **문법**: 개념 하나 배우면 즉시 문항이 풀린다. 인과가 짧다
- **문학**: 갈래별 접근법을 배우면 반은 열린다
- **독서**: 마지막. 습득에 가장 오래 걸리고 즉각적 보상이 없다

### 원칙 2 — 난도를 낮추지 말고 작업을 쪼갠다

기출 지문을 쉬운 지문으로 바꾸지 마라. **같은 지문을 더 작은 단위로 다루게** 한다.

| 잘못된 방식 | 올바른 방식 |
|---|---|
| 쉬운 사설 지문으로 시작 | 기출 지문의 **1문단만** 다루기 |
| 지문 요약해서 제공 | 원문 그대로, 대신 **문단마다 멈춤** |
| 선지를 짧게 고쳐 제공 | 원 선지, 대신 **슬래시로 끊어 읽기** |

이유: 학생은 결국 기출 규격의 텍스트를 만난다. 쉬운 텍스트에 적응시키면 전이가 일어나지 않는다.

### 원칙 3 — 문제 풀이는 나중에 온다

초기 4~6주는 **문제를 거의 풀지 않는다.** 읽기·표시하기·요약하기만 한다.

노베이스가 문제부터 풀면: 찍는다 → 채점한다 → 틀린다 → 해설을 본다 → 이해한 척한다 → 다음 문제도 똑같이 틀린다. 이 순환에 들어가면 시간만 소모된다.

### 원칙 4 — 절차를 준다, 설명을 주지 않는다

"왜 그런가"를 설명하는 대신 **"이렇게 하라"는 단계**를 준다.

| 설명형 (실패) | 절차형 (성공) |
|---|---|
| "지문의 구조를 파악해야 합니다" | "1) 문단마다 첫 문장에 밑줄 2) 접속어에 세모 3) 문단 옆에 역할 한 단어 적기" |
| "선지를 꼼꼼히 읽으세요" | "선지에 슬래시를 긋고 각 조각에 O/X/? 표시" |
| "화자의 정서를 파악하세요" | "화자가 있는 곳, 보고 있는 대상, 태도를 한 단어씩 적기" |

**절차는 검사 가능하다. 설명은 검사 불가능하다.** 노베이스 지도에서 이 차이는 결정적이다.

### 원칙 5 — 언어를 통제한다

- 설명 문장은 **40자 이내**
- 한 문장에 **새 개념 1개**
- 전문 용어 첫 등장 시 **반드시 괄호 풀이**: "관형절(문장이 통째로 명사를 꾸미는 것)"
- 한자어를 우리말로: "대응시킨다" → "짝을 짓는다", "환언" → "바꿔 쓰기"
- 지시어 최소화: "이것", "그러한" 대신 대상을 다시 쓴다

## 3. 24주 표준 커리큘럼

`[분석]` 주당 학습 6~8시간 기준. 학생 상황에 맞게 늘리되 **순서는 바꾸지 않는다.**

### 1블록 (1~4주) — 성공 경험 만들기

| 주 | 내용 | 산출물 |
|---|---|---|
| 1 | 진단 + 화작 담화 유형 5종 + 대조 훈련 | 화작 세트 3개 정답 |
| 2 | 화작: 발표·강연 / 작문 계획하기 | 정답률 70% |
| 3 | 문법: 품사 9개 + 문장 성분 | 개념 카드 |
| 4 | 문법: 겹문장 (서술어 세기 → 절 나누기) | 문장 50개 분석 |

**1블록의 목표는 점수가 아니라 "할 수 있다"는 경험이다.**

### 2블록 (5~10주) — 문장·문단 읽기

| 주 | 내용 |
|---|---|
| 5 | 문장 읽기: 주어-서술어 찾기, 수식 관계 끊기 (기출 문장 사용) |
| 6 | 문장 읽기: 긴 문장 쪼개기, 접속 관계 표시 |
| 7 | 문단 요약: 한 문단 → 한 문장 |
| 8 | 문단 요약 + 문단 역할 판정(도입/전개/전환/정리) |
| 9 | 문법: 문법 요소 5종(높임·시제·피동·사동·부정) |
| 10 | 문학: 갈래별 접근법 개관 + 현대시 화자·정서 |

### 3블록 (11~16주) — 구조와 갈래

| 주 | 내용 |
|---|---|
| 11 | 독서: 지문 골격 A~H 판별 (문제 안 풂) |
| 12 | 독서: 형광펜 지점 10종 표시 훈련 |
| 13 | 문학: 고전시가 어휘·관습 |
| 14 | 문학: 고전소설 구조 상수 |
| 15 | 문학: 표현 기법 사전 |
| 16 | 문법: 단어 형성 + 음운 변동 |

### 4블록 (17~22주) — 문항 유형별 훈련

| 주 | 내용 |
|---|---|
| 17 | 선지 분해 프로토콜 집중 (`07-choice-logic.md`) |
| 18 | 독서 유형 5(어휘)·1(전개)·2(일치) |
| 19 | 독서 유형 6(부분)·3(추론) |
| 20 | `<보기>` 문항 집중 (독서 + 문학) |
| 21 | 문학 세트 통풀이 |
| 22 | 문법 지문형 세트 + 중세국어 기초 |

### 5블록 (23~24주+) — 통합과 시간

| 주 | 내용 |
|---|---|
| 23 | 영역별 시간 목표 설정 및 단축 훈련 |
| 24 | 45문항 통풀이 (80분) → 이후 주 1회 반복 |

**24주 이후**: 기출 회차 단위 반복 + 오답 태그 집계 기반 약점 보강.

## 5. 주간 운영 표준

`[분석]` 한 주의 구조. 이 리듬을 지키는 것이 내용보다 중요하다.

```
[학습]     새 개념/절차 습득          — 주 1~2회, 회당 40분
[적용]     그 절차로 자료 처리         — 주 3~4회, 회당 30분
[점검]     오답 태그 기록 + 재풀이     — 주 1회, 40분
[누적]     지난 주 내용 5분 복습       — 매 회차 시작 시
```

**[누적]을 빼지 마라.** 노베이스는 새로 배운 것을 다음 주에 잊는다. 매 회차 5분 복습이 강의 1회보다 효과가 크다.

## 6. 이탈 방지

`[분석]` 노베이스 지도의 실질적 최대 과제는 학습 내용이 아니라 **지속**이다.

| 이탈 신호 | 원인 | 대응 |
|---|---|---|
| 과제를 안 해옴 | 과제가 너무 큼 | 과제 단위를 절반으로 |
| "해도 안 늘어요" | 성장이 안 보임 | **정답률 대신 절차 수행률**을 지표로 |
| 독서만 계속 틀림 | 정상. 가장 늦게 오름 | 미리 예고: "독서는 3개월 뒤에 오른다" |
| 문법 포기 | 겹문장에서 막힘 | 겹문장만 다시, 문장 수를 100개로 |
| 시간 부족 호소 | 절차가 아직 자동화 안 됨 | 시간 훈련은 아직 이르다. 절차 반복으로 회귀 |

### 성장 지표를 바꿔라

노베이스에게 정답률은 나쁜 지표다. 초기 3개월간은 아래를 지표로 쓴다:

- 문단 요약 정확도 (교사 채점)
- 선지 슬래시 표시 수행률
- 형광펜 지점 적중률 (실제 문항이 걸린 지점과 대조)
- 오답 태그 기록 완성도

이 지표들은 **노력에 즉각 반응한다.** 정답률은 3개월 뒤에야 움직인다.

## 7. 목표 설정의 현실

`[분석]` 정직하게 말할 것.

- 노베이스가 6개월 만에 1등급이 되는 일은 흔하지 않다. 그렇게 말하지 마라
- 현실적 목표: **6개월에 안정적으로 절반 이상 득점**, 12개월에 중상위권 진입
- 가장 빨리 오르는 것: 화작·문법 (1~2개월)
- 가장 늦게 오르는 것: 독서 `<보기>` 적용 문항 (6개월+)

**학생에게 주는 로드맵**:
> "1~2개월: 화작·문법에서 확실히 맞는다. 3~4개월: 문학이 열린다. 5~6개월: 독서가 읽히기 시작한다. 독서 점수는 마지막에 온다. 그때까지 못 오르는 건 실패가 아니라 정상이다."

이 예고가 이탈을 크게 줄인다.
