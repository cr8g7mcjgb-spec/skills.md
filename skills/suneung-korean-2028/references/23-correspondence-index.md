# 23. 임용 ↔ 수능 대응 색인

**평가원의 경우의 수를 손에 쥐는 문서.**

임용 문항 분석 자료는 개념마다 "이건 임용 어디, 수능 어디에 나왔다"를 기록한다. 그 기록을 뒤집으면 **평가원이 하나의 개념을 몇 번, 어느 시험에, 어떤 형태로 꺼냈는지**가 보인다. 이것이 곧 출제 가능 범위의 실측 지도다.

## 0. 표기와 신뢰도

`[확인필요: 단일 출처]` **이 색인 전체가 한 출처(임용 전공 국어 문항 분석 자료)에서 나왔다.** 교차 검증되지 않았다. 다만 임용 전문 분석이고 문항 코드를 정확히 특정하므로 신뢰도는 낮지 않다.

**수업 자료에 쓸 때는 "확인 필요"를 달거나, 원문 대조 후 쓴다.**

### 여기서 읽어야 할 것

`[분석]`

**① 22 수능 필수부사어 문항의 정체가 드러난다.**
> "동일 조사 '에'가 결합한 것이 **필수/수의 부사어로 나뉜다**"

같은 조사가 붙었는데 하나는 필수, 하나는 수의. **이것이 평가원이 좋아하는 형태다** — 표면이 같고 기능이 다른 쌍. `18-grammar-inventory.md` §4-3의 "필수적 부사어" 함정이 실물로 확인된 것이다.

**② 개념 하나가 20년에 걸쳐 반복된다.**
구개음화는 임용에서 01, 04, 09모, 15A, 16A에 나오고 수능에서 24에 나왔다. **평가원의 개념 풀은 좁고 깊다.** 새 개념을 만들지 않고 같은 개념을 다른 각도로 재출제한다.

**③ 임용에서 먼저 다뤄진 개념이 수능 지문형으로 내려온다.**
기저형·적용 환경은 임용 24A08의 주제인데, 이런 학문문법 논점이 수능에서는 **지문이 개념을 설명한 뒤 사례를 판정시키는 형태**로 변환된다. → `21-kice-lens.md` §5

### 5-3. 여기서 나오는 전략

`[분석]`

**① 작가는 반복되고 작품은 바뀐다.**
이육사·이용악·윤흥길·양귀자·이호철 — 같은 작가의 **다른 작품**이 임용과 수능에 번갈아 나온다. 이것이 평가원의 작품 선정 방식이다.

> **따라서 "이 작가가 나왔으니 이 작가는 끝났다"는 틀렸다.** 오히려 **한 번 나온 작가는 다시 나올 확률이 높다.** 다른 작품으로.

**② 임용에만 나온 작품이 수능 후보군이다.**
이육사 「교목」, 이용악 「전라도 가시내」, 양귀자 「비 오는 날이면…」은 임용에만 나왔다. 정전성·해석 안정성이 이미 검증된 작품들이다. → `16-literature-canon.md` §2의 선정 필터를 이미 통과했다는 뜻

**③ 주제축이 반복된다.**
도시빈민·소시민의 삶(윤흥길·양귀자·김승옥·이호철·조세희)이 임용과 수능에 공통으로 나온다. **작품이 아니라 주제축으로 준비하는 것이 옳다.**

## 6. 평가원 로직 — 추가 확보분

`[검증: 임용 분석 자료의 직접 서술]` 앞서 `21-kice-lens.md` §7에서 두 문장을 기록했다. 여기에 세 가지가 더 붙는다.

### 6-1. 문학 정답은 "무난하고 대세적인" 것이다

> "문학은 **'상호주관성'**을 전제로 해석과 감상을 공유한다. 다른 감상자들이 대체로 동의·납득·공감할 수 없는 설명은 아무리 전공자의 말일지라도 수용되지 못한다. 따라서 보통은 독창적이고 창의적인 해석이 아닌, **무난하고 대세적인 생각을 적으면 그것이 정답일 가능성이 높다.**"

`[분석]` **문학에서 "깊이 생각한 답"은 대체로 오답이다.** 정답은 가장 평범한 해석이다. 이는 `20-item-construction-norms.md`의 "관점에 따라 오답이 될 가능성은 없는가" 검토 항목과 같은 뿌리다.

> **학생에게**: "문학에서 남들 다 틀리고 너만 맞는 답은 없다. 제일 평범한 걸 골라라."

### 6-2. 매력적 오답은 작품 안에 하나씩 심겨 있다

> "인용 문제에서는 **작품 안에 매력적인 오답이 하나씩 포함된 경우가 많은데**, 보통 `<보기>`의 설명 안에 뚜렷한 힌트가 숨겨져 있거나, 가장 보편적인 의미에서 수용될 만한 1가지만이 정답 처리될 것이다. **(출제자는 분명 정확히 1가지 답을 도출할 수 있게끔 문제를 출제할 테니까)**"

**실물 사례 — 24A10 (윤동주 시)**

| 구분 | 시구 | 왜 |
|---|---|---|
| **함정** | '부끄런' | 작품 표면에 있는 정서어. 그러나 '얼굴'에 직접 호응하지 않음 |
| **정답** | '욕될까' | '얼굴'에 직접 호응 |

| 구분 | 시구 | 왜 |
|---|---|---|
| **매력적 오답** | "어리석게도 그토록 기록할 것이 많았구나" | '기록 행위'는 맞지만, **성찰의 기록이 아니라 청년기 창작의 기록** |
| **정답** | "그리하여 나는 우선 여기에 짧은 글을 남겨 둔다" | 성찰에 대한 기록 |

`[분석]` **오답 제조의 실물이다.** 둘 다 "기록 행위"라는 상위 범주는 맞는데, **무엇에 대한 기록인가**에서 갈린다. → `07-choice-logic.md`의 **T9(부분 진실)** 과 정확히 같은 구조.

### 6-3. 문학 주제는 '지향' 아니면 '비판'이다

> "주제는 **지향 / 비판** 둘 중 하나로 정리할 수 있다. 지향·비판의 대상은 일반적으로 **'가치관 / 정서 / 시대상 / 인성적 요소'** 등이 된다."

`[분석]` 이 2×4 격자가 문학 주제 진술의 거의 전부를 덮는다.

```
              가치관    정서    시대상    인성적 요소
   지향(긍정)    □       □       □          □
   비판(부정)    □       □       □          □
```

**`<보기>` 문항에서 "이 작품의 주제는?"을 물을 때, 이 격자 밖으로 나가지 않는다.** 학생에게 이 격자를 주면 문학 주제 판정이 즉시 단순해진다.

## 7. 아직 수능에 안 나온 것들 — 저수지 목록

`[분석]` 임용에는 나왔는데 수능 기록이 없는 개념. **2028 대비에서 우선 주목할 후보군이다.**

```

관련성의 원리 / 적절성의 원리
나 전달법(I-message)
```

```
일면 메시지 ↔ 양면 메시지
```


### 문학
```
향가의 효용과 주술성 / 시적 소통 구조
영웅의 일대기 구조 + 꿈 화소(예지몽)
미의식, 화자의 대응 방식
```

**주의**: 이것은 **적중 예언이 아니다.** "평가원이 이미 다루기로 결정한 개념 중 수능에는 아직 안 쓴 것"의 목록이다. 나올 수도, 영영 안 나올 수도 있다. 다만 **완전히 새로운 개념보다는 이 목록에서 나올 가능성이 높다.**
