# 수능 국어 2028 — 평가원 출제 문법 스킬

이 스킬은 "평가원이 어떻게 문제를 만드는가"를 재구성한 설계도다. 문제를 푸는 요령이 아니라 **문제를 만드는 규칙**을 담았고, 그 규칙을 뒤집어 수업 자료를 만든다.

## 시작하기 전에 — 반드시 읽을 것

**`references/00-scope-and-limits.md`를 먼저 읽어라.** 이 스킬이 무엇을 담고 있고 무엇을 담고 있지 않은지, 기출 원문을 어디서 어떻게 확보하는지, 문서 안의 신뢰도 표시(`[검증]`/`[분석]`/`[확인필요]`)를 어떻게 읽어야 하는지가 적혀 있다. 이 단계를 건너뛰면 스킬의 분석을 확정 사실로 오독하게 된다.

핵심만 미리 말하면: 이 스킬에는 **기출 문제 원문이 들어 있지 않다**(저작권·분량). 원문 대조가 필요한 작업이면 `references/13-corpus.md`의 절차로 먼저 코퍼스를 확보하고, 확보 전에는 "원문 미대조" 상태임을 산출물에 명시한다.

**자료를 찾아야 할 때는 네이버 검색 도구를 먼저 쓴다.** `13-corpus.md` §1-B에 검증된 검색 절차·검색어 패턴·출처별 신뢰도 등급이 있다. 다만 **PDF 원문 텍스트는 이 경로로 얻을 수 없다** — 그때는 사용자에게 링크가 아니라 **PDF 파일 업로드**를 요청하고 `pdf` 스킬로 추출한다.

## 이 스킬이 강제하는 5가지 원칙

수업 자료를 만들 때 아래를 어기지 마라. 이것이 이 스킬의 실질이다.

### 1. 근거 없는 단정 금지 — 세 가지 표시를 구분해서 쓴다

산출물에서 사실과 해석을 섞지 않는다.

- `[검증]` 공식 문서·시행계획·공개 보도로 확인된 것
- `[분석]` 기출 패턴에서 도출한 경향. **규칙이 아니라 확률**이다. "항상/반드시" 금지, "대체로/~한 경우가 많다"로 쓴다
- `[확인필요]` 원문 대조가 필요한 것

학생용 최종본에서는 표시를 지워도 되지만, **교사용/내부 분석본에는 반드시 남긴다.** 학생용에서도 `[분석]`에 해당하는 내용을 "평가원 규칙"이라고 말하지 않는다.

### 2. 정답 근거는 지문 안에서 인용으로 특정한다

해설을 쓸 때 "지문에서 알 수 있다"로 끝내지 않는다. 반드시:

```
정답 근거: 3문단 "…따라서 A는 B에 의존한다" (문장 단위로 인용)
오답 근거: ①은 2문단의 '조건'을 '결과'로 뒤집음 → 인과 역전형
```

근거 문장을 특정할 수 없으면 그 해설은 미완성이다.

### 3. 오답 해설이 정답 해설보다 길어야 한다

노베이스 학습자는 정답을 못 고르는 게 아니라 **오답을 못 버린다.** 정답 해설 1줄, 오답 해설 4줄이 기본 비율이다. 각 오답에는 `07-choice-logic.md`의 오답 유형 태그를 붙인다.

### 4. 노베이스 대상이면 어휘·문장 길이를 통제한다

`10-curriculum-novice.md`의 통제 규칙을 따른다. 요약하면:
- 설명 문장은 한 문장 40자 이내, 한 문장에 새 개념 1개
- 국어 전문 용어(대유, 반어, 통사 구조, 관형절…)는 첫 등장 시 반드시 괄호 풀이
- 지문 난도를 낮추지 말고 **작업 단위를 쪼갠다**(지문은 기출 그대로, 대신 문단 단위로 끊어 읽힘)

### 5. 기출 왜곡 금지

기출 지문·선지를 인용할 때 **줄이거나 다듬지 않는다.** 분량 때문에 일부만 쓸 때는 생략 표시(`(중략)`)와 함께 생략 사실을 밝힌다. 기억에 의존해 지문을 "복원"해서 쓰지 않는다 — 원문이 없으면 자작 지문임을 명시하고 자작한다(`12-item-writing.md`).

## 표준 작업 절차

수업 자료 제작 요청이 들어오면:

1. **대상·범위·형식을 먼저 확정한다.** 학년/현재 수준/영역/분량/용도(자습용·강의용·과제용). 불명확한 항목이 결과를 크게 바꾸면 물어보고, 아니면 기본값으로 진행하고 명시한다.
   - 기본값: 고1 노베이스 / 2028 체제 / A4 4쪽 / 자습 가능한 해설 포함
2. **해당 영역 문서를 읽는다.** 위 표 참조.
3. **`11-lesson-protocol.md`의 산출물 구조**를 따라 작성한다.
4. **자체 검수**: `assets/self-check.md`의 체크리스트를 돌린다. 통과 못 한 항목은 고치거나 산출물에 한계로 적는다.

## 2028 체제 한 줄 요약

`[검증]` 2028학년도 수능 국어는 **선택과목이 없다.** 모든 수험생이 `화법과 언어` + `독서와 작문` + `문학` 범위를 함께 본다. 45문항 80분은 유지. `매체`는 출제 범위에서 빠졌다. 화법·작문·문법이 전원 필수가 되었다는 뜻이고, 이는 "화작런/언매런" 같은 선택 전략이 사라졌다는 뜻이다.

가장 큰 실질 변화는 **융합 세트의 신설**이다. 예시문항에서 `화법 + 언어` 세트와 `독서 + 작문` 세트(정보 글 (가)(나) + 학생 초고 (다))가 등장했다. 2027 이전 기출만으로는 이 세트를 대비할 수 없다. 자세한 것은 `09-2028-shift.md`.
