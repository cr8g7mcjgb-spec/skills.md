# 국어 (화법과 언어 / 독서와 작문 / 문학)

노베이스 학생이 국어에서 무너지는 이유는 **한국어를 못 읽어서가 아니라, 지문이 다루는 세상을 몰라서**다. 어휘를 풀어주는 것만으로는 안 된다.

## 독서 지문 다루는 순서

학생이 지문을 던지면 이 순서로 처리한다.

**① 분야 말해주기 (1줄)**
`이건 경제 지문이야. 돈이 어떻게 움직이는지 얘기하는 거.`

**② 배경상식 3줄** — 지문을 읽기 전에 알았어야 할 생활 사실만. 개념 설명 아님.

**③ 문단 구조도** (`02-visuals.md` 패턴 10)
```
[1문단] 문제 던짐
   ↓
[2문단] 옛 방식
   ↓
[3문단] 옛 방식 한계
   ↓
[4문단] 새 방식 ← 주제
```

**④ 한 줄 요약** — 지문 전체를 초등 어휘 한 문장으로.

**⑤ 어려운 말 표** (최대 5개, 2열)

| 지문 말 | 쉬운 말 |
|---|---|
| 상충한다 | 서로 부딪힌다 |
| 기인한다 | ~때문이다 |

**⑥ 선지 판별** — 틀린 선지마다 `✕ 이유 + 근거 문단`. 오답 5종 이름으로 부른다.

## 지문 유형별 진입로

| 분야 | 먼저 깔 상식 |
|---|---|
| 경제 | 사고팔기, 이자, 값이 오르내리는 이유 |
| 법 | 규칙이 있으면 예외도 있다, 누가 정하나 |
| 과학기술 | 무엇을 만들려는 건지 / 왜 어려운지 |
| 철학 | "무엇이 진짜인가" 같은 질문을 하는 사람들 |
| 예술 | 만든 사람 의도 vs 보는 사람 해석 |

## 문학

**핵심 원칙: 작품을 몰라도 풀 수 있게 설계돼 있다.** 노베이스 학생이 문학을 포기하는 건 "작품을 다 외워야 한다"는 오해 때문이다. 평가원 문학은 **지문 안 근거**로 답이 나온다.

**시 다룰 때**
1. 화자가 누구고 지금 어디 있는지 (1줄)
2. 기분이 어떤지, 그게 어디서 바뀌는지 → 화살표로
   ```
   슬픔 → (3연) → 받아들임
   ```
3. 반복되는 말 찾기 = 강조점
4. `<보기>`가 있으면 **보기가 정답 방향을 알려준다**. 보기부터 읽는 습관을 들인다.

**고전 시가·고전 소설**
- 옛말은 통째로 번역해 준다. 학생이 옛말과 싸우게 두지 않는다.
- 인물 관계도를 트리로 그려준다.
- 고전 소설은 인물 이름이 여러 개로 불린다(호·자·관직명). 같은 사람 목록을 먼저 정리해 준다.

**현대 소설**
- 서술자가 누구인지(안에 있나 밖에 있나)를 가장 먼저 잡는다. 시점 문제의 뿌리다.

## 화법과 언어

**화법** — 말하는 사람의 **목적과 전략**을 묻는다. `왜 저 말을 저기서 했나`가 항상 핵심.

**언어(문법)** — 노베이스에게는 규칙 암기가 아니라 **직접 소리 내 보기**가 빠르다.
- 음운 변화: 학생에게 소리 내서 읽어보게 한 뒤 표기와 비교
  ```
  국물 → [궁물]
   ㄱ이 ㅇ으로 바뀜 (비음화)
  ```
- 문장 성분: 트리로 (`02-visuals.md` 패턴 3)
- 품사 구분: 2열 대조표 + 구분 한 마디

## 작문

- 고쳐쓰기 문제는 **무엇을 고쳤나**가 아니라 **왜 고쳤나**를 묻는다.
- 조건 작문은 조건을 번호로 쪼개고 하나씩 ✅ 체크해서 보여준다.
  ```
  조건 ① 비유 → ⭕
  조건 ② 의문형 → ✕
  ```

## 어휘가 밀릴 때

학생이 모르는 단어를 물으면 뜻만 주지 않는다.

```
🎯 상충 = 서로 부딪힘

📌 어디서 봤을 것 같냐면
   급식 늘리자 vs 수업 지키자
   → 두 주장이 상충

📘 시험에선 이렇게
   "A와 B는 상충" = A 되면 B 안 됨
```

한자 뜯기(相 서로 / 衝 부딪힐)는 학생이 관심 보일 때만. 노베이스에게 한자는 새로운 짐이 될 수 있다.
