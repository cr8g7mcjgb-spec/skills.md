# 고등학생 일상 예시 뱅크 (🏫 블록용)

## 왜 일상 예시인가

노베이스 학생이 못 읽는 진짜 이유는 어휘가 아니라 **배경 상식 구멍**이다. "인플레이션 억제를 위한 금리 인상"은 세 단어를 다 풀어줘도 안 읽힌다. "돈을 맡기면 이자를 준다"는 생활 감각이 없어서다.

🏫 블록은 그 구멍을 **학생이 확실히 겪어본 장면**으로 메운다. 동시에 기억에 박히게 한다. 이해와 암기를 한 번에 처리하는 자리다.

## 예시 고르는 기준

1. **학생이 진짜 겪은 일** — 급식, 매점, 야자, 수행평가, 시간표, 자리 바꾸기, 카톡, 배달, 버스, 체육대회, 축제, 게임, 충전기
2. **구조가 같아야 한다** — 소재가 비슷한 게 아니라 **관계가 같아야** 한다. 이게 핵심이다
3. **한 줄로 그려지는 장면** — 설명이 필요한 비유는 실패다
4. **한계를 말할 수 있는 것** → `⚠️ 딱 여기까지: 실제로는 ○○가 달라`

**피할 소재** — 연애, 외모, 집 형편, 성적으로 사람 비교하기, 특정 학교·지역 비하. 웃기려다 학생을 찌르면 그 대화는 거기서 끝난다.

# 구조별 예시 뱅크

**구조로 찾는다.** 과목이 아니라 "관계 모양"으로 골라야 아무 개념에나 붙는다.

## 1. 일정하게 늘어남 → 등차수열, 일차함수, 비례

```
🏫 매점 컵라면 1개 900원
   1개 900 / 2개 1800 / 3개 2700
   → 하나 늘 때마다 +900

이게 「등차수열」. 900이 「공차」
```

## 2. 배로 불어남 → 등비수열, 지수함수, 세균 증식

```
🏫 단톡방에 링크 올림
   1명이 2명한테 퍼뜨림
   1 → 2 → 4 → 8 → 16

이게 「등비수열」. 2가 「공비」
```

## 3. 순식간에 줄어듦 → 지수 감소, 반감기

```
🏫 폰 배터리
   100% → 50% → 25% → 12%
   줄어드는 양 자체가 줄어든다
```

## 4. 하나 고르면 하나 포기 → 기회비용, 자원의 희소성

```
🏫 점심시간 40분
   매점 가면 → 축구 못 함
   축구 하면 → 매점 못 감

포기한 쪽 값 = 「기회비용」
```

## 5. 모자라서 다툼 → 희소성, 분배 정의

```
🏫 급식 돈까스가 딱 3개 남음
   먹고 싶은 사람은 10명

'모자람' = 「희소성」
'누구한테 줄까' = 「분배 정의」
```

## 6. 값 올리면 안 삼 → 수요, 가격 탄력성

```
🏫 핫바 1500 → 3000원
   아무도 안 삼
   생수는 값 올라도 삼

핫바가 「가격 탄력성」 큰 쪽
```

## 7. 힘을 나눠 놓음 → 권력 분립, 견제와 균형

```
🏫 시험 문제 내는 쌤
   채점하는 쌤
   성적 이의 받는 쌤
   전부 같은 사람이면? → 망함

나눠 놓는 게 「권력 분립」
```

## 8. 다 같이 정함 → 사회적 합의, 민주적 절차

```
🏫 반 티셔츠 색깔 투표
   30명이 손 들어 정함
   → 마음에 안 들어도 따름

이게 「사회적 합의」
```

## 9. 짝지어 대응 → 함수, 정의역·치역

```
🏫 시간표
   1교시 → 국어
   2교시 → 수학
   한 교시에 과목 하나씩

이 관계가 「함수」
교시들 = 「정의역」
```

## 10. 순서를 바꿔 세기 → 경우의 수, 순열·조합

```
🏫 자리 바꾸기
   3명이 앉는 방법
   가-나-다 / 가-다-나 …
   순서 다르면 다른 경우 → 「순열」

조 짜기는 순서 상관없음 → 「조합」
```

## 11. 전체 중 일부 → 확률, 표본

```
🏫 반 30명 중 안경 낀 사람 6명
   아무나 한 명 뽑았을 때 안경?
   6/30 = 1/5

전교생을 다 안 세고
한 반만 보고 짐작 = 「표본」
```

## 12. 가팔라짐 / 완만해짐 → 미분, 순간변화율

```
🏫 자전거로 언덕 오르기
   가파른 데선 힘듦
   꼭대기에선 평평 → 힘 안 듦

'얼마나 가파른가' = 「미분계수」
평평한 지점 = 「극대·극소」
```

## 13. 쌓아서 총량 → 적분, 누적

```
🏫 하루 걸음 수
   1시간마다 조금씩 쌓임
   하루 끝 = 다 더한 값

쌓아 더하기 = 「정적분」
```

## 14. 돌고 돌아 제자리 → 주기함수, 순환

```
🏫 버스 배차 10분
   같은 상황이 계속 반복

반복되는 모양 = 「주기」
삼각함수가 이렇게 생겼다
```

## 15. 뺏고 뺏김 → 산화·환원

```
🏫 보조배터리로 폰 충전
   보조배터리는 잃고
   폰은 얻음
   동시에 일어남

잃는 쪽 「산화」 / 얻는 쪽 「환원」
```

## 16. 스스로 맞춰 돌아옴 → 항상성, 피드백

```
🏫 교실 에어컨
   더우면 켜지고 시원하면 꺼짐
   → 항상 비슷한 온도

이게 「항상성」
```

## 17. 사례 모아 결론 → 귀납 / 규칙에서 판단 → 연역

```
🏫 귀납
   우리 반 급식 5번 다 짬
   → "이 학교 급식은 짜다"
   (6번째가 안 짤 수도 있음)

🏫 연역
   "3학년은 야자 필수"
   나는 3학년 → 나도 필수
   (규칙이 맞으면 무조건 참)
```

## 18. 조건이 걸림 → 필요조건·충분조건, if절

```
🏫 "지각하면 청소"
   지각함 → 청소 (확실)
   청소함 → 지각? (모름)
   딴 이유로 청소했을 수도

한쪽 방향만 확실한 게 핵심
```

## 예시가 안 통할 때

학생이 그래도 모르겠다고 하면 **어휘를 더 내리지 않는다.** 어휘는 이미 초5다. **예시를 갈아 끼운다.**

| 첫 예시 | 안 통하면 바꿀 것 |
|---|---|
| 급식·매점 | 게임·아이돌 투표 |
| 시험·수행평가 | 배달앱·편의점 |
| 교실·자리 | 지하철·버스 |

학생이 관심 있어 하는 쪽으로 옮긴다. 대화 중에 학생이 언급한 것(게임 이름, 좋아하는 것)을 기억해 두었다가 그걸로 예시를 만들면 가장 잘 박힌다.

## 비유 한계 표시

일상 예시는 다리일 뿐 사실이 아니다. 빠뜨리면 학생이 비유를 개념으로 외운다.

```
🏫 세포막은 축제 입구 같은 거야
   팔찌 있어야 들어감

⚠️ 딱 여기까지: 실제로는
   세포막이 골라주는 게 아니라
   크기·성질 때문에 자동으로
   그렇게 되는 거다
```
