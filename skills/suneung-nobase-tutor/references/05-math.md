# 수학 (대수 / 미적분Ⅰ / 확률과 통계)

2028 수능 수학은 **대수(이전 교육과정의 수학Ⅰ에 해당), 미적분Ⅰ(이전 수학Ⅱ에 해당), 확률과 통계** 세 과목에서 모두 같은 문제로 출제된다. 미적분Ⅱ·기하는 빠진다. 고1의 공통수학1·2는 수능 출제 과목은 아니지만 **여기 구멍이 나면 위 세 과목이 전부 막힌다.**

| 과목 | 큰 덩어리 |
|---|---|
| 대수 | 지수·로그, 삼각함수, 수열 |
| 미적분Ⅰ | 극한과 연속, 미분, 적분 |
| 확률과 통계 | 경우의 수, 확률, 통계 |

## 노베이스 수학의 진짜 문제

고3 내용을 못 푸는 게 아니라 **중학 내용이 비어 있어서** 못 푸는 경우가 대부분이다. 문제를 못 풀면 고등 개념을 다시 설명하기 전에 아래를 먼저 확인한다.

| 고등 단원 | 여기가 비면 못 함 |
|---|---|
| 지수·로그 | 거듭제곱, 분수 계산 |
| 삼각함수 | 직각삼각형 비, 원 |
| 수열 | 규칙 찾기, 문자식 |
| 미분 | 기울기, 일차함수 |
| 적분 | 넓이, 다항식 계산 |
| 확률 | 분수, 경우의 수 세기 |

**결손이 보이면 숨기지 말고 말한다.** 다만 이렇게 말한다:

> 이건 중2에서 배우는 건데 여기서 계속 쓰여. 5분만 채우고 가자.

`중학 거부터 다시 해` 라고 통째로 돌려보내지 않는다. **막힌 그 한 조각만** 채우고 원래 문제로 돌아온다.

## 수식 표기 (모바일 필수)

LaTeX 블록을 쓰지 않는다. 평문으로:

```
x²  √2  a/b  ≤  ≥  ≠  π  ×  ÷
log₂8 = 3
aₙ = 3n - 1
lim(x→2)
∫  Σ
```

분수는 `(x+1)/2` 처럼 괄호로 묶는다. 여러 줄 계산은 등호를 세로로 맞춘다.

```
 2x + 3 = 11
 2x     = 8
  x     = 4
```

## 풀이 쓰는 법

**한 줄 = 동작 하나.** 번호를 붙인다. 학생이 "③에서 막혔어"라고 말할 수 있어야 한다.

```
① 양쪽에서 3 빼기
② 2x = 8
③ 양쪽 2로 나누기
④ x = 4
```

**"왜 그렇게 하는지"를 한 줄씩 붙인다.** 절차만 있으면 응용이 안 된다.

```
① 양쪽에서 3 빼기
   ← x만 남기려고
```

## 개념별 진입로

**지수·로그** — 로그는 "몇 번 곱했나 묻는 것"이다.
```
2 × 2 × 2 = 8
 ↑ 3번
log₂8 = 3
```
`log₂8`은 "2를 몇 번 곱해야 8?" 이라고 매번 소리 내 읽게 한다.

**삼각함수** — 각도가 아니라 **원 위를 도는 점**으로 시작한다.
```
   위 ↑ sin
      ●
 ←────┼────→ cos
      │
```
sin = 위아래 위치, cos = 좌우 위치. 도는 동안 값이 오르락내리락 → 그래서 파도 모양.

**수열** — 표로 늘어놓고 규칙을 눈으로 보게 한다.
```
n :  1   2   3   4
aₙ:  3   5   7   9
       +2  +2  +2
```
`n번째 = 3 + 2×(n-1)` 을 학생이 표에서 직접 찾게 한다.

**미분** — "그 순간 얼마나 가파른가".
```
╱  가파름 = 미분값 큼
─  평평 = 미분값 0
       ↑ 꼭대기·바닥
```
극대·극소를 미분값 0으로 찾는 이유가 여기서 나온다.

**적분** — "쌓기 / 넓이".
```
█
██
███     ← 다 합치면 넓이
████
```

**확률** — 분수로 시작하지 말고 **개수 세기**로 시작한다.
```
전체 6가지
맞는 것 2가지
→ 2/6 = 1/3
```

## 문제 풀어줄 때

1. 문제에서 **구하라는 것**에 밑줄 (`구하는 것: x의 최댓값`)
2. 주어진 조건을 번호로 나열
3. 조건을 식으로 옮기기 ← **수능이 진짜 묻는 부분**
4. 계산
5. 답이 말이 되는지 확인 (단답형은 답이 자연수 형태로 나오게 설계된다. 이상하면 계산 실수 신호)

## 학생이 답만 원할 때

`답만 알려줘` 라고 해도 답만 주지 않는다. 대신 압축한다.

```
답: 4

핵심: 양변 3 빼고 2로 나눔

같은 유형 → 3x + 5 = 20
```
