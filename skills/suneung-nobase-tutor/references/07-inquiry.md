# 통합사회 · 통합과학 · 한국사

## 공통: 이 세 영역이 노베이스에게 유리한 이유

2028 수능 탐구는 **고1 과목(통합사회1·2, 통합과학1·2) 범위 안에서만** 출제된다. 고2·3에서 고르는 물리학·화학·지리·경제 같은 심화 과목 내용은 나오지 않는다. 2024년 9월 공개된 예시문항의 특징은 **자료 해석 중심의 융합형**이었다.

즉 **외운 양보다 자료를 읽는 법**이 점수를 가른다. 이건 배경지식이 적은 학생에게 오히려 유리한 구조다. 학생에게 이 사실을 알려준다 — 탐구를 포기하지 않게 하는 근거가 된다.

## 자료 읽는 법 (탐구 공통 기술)

그래프·표·지도가 나오면 항상 이 순서로 읽힌다.

```
① 제목 — 뭘 재고 있나
② 가로축 — 뭐가 변하나
③ 세로축 — 뭐가 따라 변하나
④ 모양 — 오르나 내리나
⑤ 그래서 뭐 — 한 문장
```

학생에게 이 5단계를 매번 똑같은 순서로 시킨다. 반복하면 습관이 된다.

```
   ↑ 인구
   │      ╱
   │    ╱
   │  ╱
   └────────→ 연도
   해석: 해가 갈수록 늘어남
```

## 통합사회

**진입로: 추상어를 학교 상황으로 바꾼다.**

| 교과서 말 | 학생 세계 |
|---|---|
| 사회적 합의 | 반에서 투표로 정한 규칙 |
| 자원의 희소성 | 급식 후식이 30개뿐 |
| 기회비용 | 매점 가면 축구 못 함 |
| 분배 정의 | 조별과제 점수 나누기 |
| 권력 분립 | 문제 내는 사람과 채점하는 사람 분리 |

**주요 갈래 구조도**
```
[통합사회]
 ├ 인간·행복
 ├ 자연환경·생활공간
 ├ 인권·헌법
 ├ 시장·경제
 ├ 정의·불평등
 └ 문화·세계화·지속가능
```

**설명 원칙** — 통합사회는 대부분 **입장이 둘 이상 부딪히는 구조**다. 항상 양쪽을 나란히 보여준다.

```
개발 ⇄ 보전
 일자리   환경
   ↓       ↓
  누가 손해?
   ↑ 시험은 여기를 묻는다
```

## 통합과학

**진입로: 눈에 보이는 현상 → 안 보이는 원리 순서.** 반대로 하면 노베이스는 첫 줄에서 튕긴다.

```
❌ 산화란 전자를 잃는 것이다
⭕ 쇠가 녹슨다 → 왜?
   → 산소랑 붙어서
   → 전자를 뺏김 = 산화
```

**주요 갈래**
```
[통합과학]
 ├ 물질과 규칙성
 ├ 시스템과 상호작용
 ├ 변화와 다양성
 └ 환경과 에너지
```

**단위와 기호 다루기** — 노베이스는 단위에서 무너진다. 처음 나오는 단위는 **크기 감각**을 같이 준다.

| 단위 | 감각 |
|---|---|
| 1 J | 사과 하나 1m 들기쯤 |
| 1 kW | 전자레인지 하나 |
| pH 7 | 물 (중성) |

**화학식은 그림으로**
```
CO₂
 C 하나 + O 둘
 ● ─ ○ ─ ○
```

**흐름은 화살표로**
```
빛 → [엽록체] → 포도당 + O₂
        ↑
     CO₂ + H₂O
```

## 한국사

**필수·절대평가. 40점이면 1등급.** 학생이 여기에 시간을 과하게 쓰지 않도록 초반에 말해 준다.

**진입로: 사건 암기가 아니라 흐름 한 줄.**

```
조선 → 문 열림 → 나라 뺏김
     → 되찾음 → 갈라짐 → 지금
```

큰 줄기를 먼저 심고, 사건은 그 줄기에 걸어 준다. 반대로 하면 사건 이름만 떠다닌다.

**타임라인으로**
```
1876 ─ 강화도조약
  │     문 열림
1894 ─ 갑오개혁
  │     제도 바꿈
1897 ─ 대한제국
  │
1910 ─ 국권 피탈
```

**사건마다 3가지만**
```
언제 / 왜 / 뭐가 바뀜
```

세부 인물명·조항은 학생이 흐름을 잡은 뒤에. 연도는 확실한 것만 말한다 — 헷갈리면 `이건 정확히 확인해봐` 라고 쓴다.
