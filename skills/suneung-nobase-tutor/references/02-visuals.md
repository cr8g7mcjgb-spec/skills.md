# 모바일 텍스트 시각화 패턴 12종

## 공통 규칙

- **폭 30칸 이내.** 한글은 한 글자가 2칸이므로 한글만 쓰면 15자다. 넘으면 줄여서 다시 그린다.
- 코드블록(```) 안에 넣으면 정렬이 유지된다. 표와 이모지 도식은 코드블록 밖에.
- 도식 하나에 정보 5덩어리 이내. 넘으면 두 개로 나눈다.
- 도식 밑에 **한 줄 해설**을 반드시 붙인다. 그림만 던지지 않는다.

---

## 1. 인과 흐름 (원인 → 결과)

과학 현상, 사회 제도, 역사 사건에 쓴다.

```
금리 올림
   ↓
저축 늘어남
   ↓
안 씀 → 물가 덜 오름
```

## 2. 순환 (돌아오는 구조)

물의 순환, 탄소 순환, 경제 순환.

```
  ┌→ 증발 →┐
증발       구름
  └← 비 ←──┘
```

## 3. 포함 관계 트리

분류·개념 위계. 국어 문법, 생물 분류, 사회 개념.

```
[문장 성분]
 ├ 주성분
 │  ├ 주어
 │  ├ 서술어
 │  └ 목적어
 └ 부속 성분
    ├ 관형어
    └ 부사어
```

## 4. 2열 대조표

헷갈리는 두 개를 구분시킬 때. **셀 안 8자 이내.**

| | 귀납 | 연역 |
|---|---|---|
| 방향 | 사례→규칙 | 규칙→사례 |
| 확실성 | 틀릴 수도 | 무조건 참 |
| 예 | 까마귀 관찰 | 삼단논법 |

표 밑에 **구분 한 마디**를 붙인다: `보고 나서 규칙 만들면 귀납.`

## 5. 비율 막대

통계, 비중, 확률.

```
찬성 ■■■■■■□□□□ 60%
반대 ■■■■□□□□□□ 40%
```

## 6. 수직선 / 부등식

부등식 범위, 정의역, 대소 비교.

```
──┬───┬───┬───┬──
 -1   0   1   2
      ●━━━━━━━▶
      x ≥ 0
```

● = 포함(≥, ≤), ○ = 미포함(>, <). 이 구분을 매번 말해준다.

## 7. 좌표·그래프 대체

그림을 못 그리므로 **모양과 특징**만 전달한다.

```
 y
 ↑
 │    ╱
 │   ╱
 │  ╱
─┼─╱────→ x
 │╱
```
`오른쪽 위로 감 = 기울기 +`

이차함수는 문자로:
```
  ╲     ╱
   ╲___╱
   꼭짓점 (2, -1)
```

## 8. 저울 (등식 변형)

방정식 푸는 과정.

```
 x + 3  ⚖  10
   -3       -3
 ─────────────
   x    ⚖   7
```
`양쪽에 똑같이 해야 안 기운다.`

## 9. 타임라인

한국사, 사건 순서.

```
1876 ─ 강화도조약
  │     (문 열림)
1894 ─ 갑오개혁
  │
1897 ─ 대한제국
  │
1910 ─ 국권 피탈
```

## 10. 지문 구조도 (국어 독서)

지문 전체 흐름을 한눈에. **독서 지문 설명할 때 거의 항상 쓴다.**

```
[1문단] 문제 던짐
   ↓
[2문단] 옛 이론 설명
   ↓
[3문단] 옛 이론 한계
   ↓
[4문단] 새 이론 ← 주제
```

## 11. 문장 구조 슬래시 (영어·국어)

긴 문장을 끊어 보여준다.

```
The boy / who ran / is my friend.
 주어      꾸밈       동사+설명
```

핵심 뼈대만 남기기:
```
뼈대 → The boy is my friend.
```

## 12. 선지 판별표 (문제 풀이)

객관식 채점·해설용. **근거 위치를 반드시 같이 쓴다.**

```
① ✕ 2문단, 반대로 씀
② ✕ 지문에 없는 말
③ ⭕ 3문단 마지막 줄
④ ✕ 범위를 넓혔음
⑤ ✕ 원인·결과 뒤바꿈
```

`✕ 이유 5종`을 반복 노출시키는 게 목적이다: **반대 / 없는 말 / 과장·확대 / 인과 뒤바꿈 / 일부를 전체로**

---

## 암기 카드 형식

학생이 `외울 거` 라고 하면:

| 앞면 | 뒷면 |
|---|---|
| 귀납 | 사례 모아 규칙 |
| 연역 | 규칙에서 사례 |

5장 넘기지 않는다. 다 외웠다고 하면 뒷면을 가리고 물어본다.
