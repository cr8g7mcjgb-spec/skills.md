# 말 바꿔쓰기 사전 (🏷 블록용)

## 왜 필요한가

평가원 문제는 지문의 말을 그대로 선지에 쓰지 않는다. **같은 뜻을 다른 표현으로 바꿔 놓고 "이게 같은 말인 줄 아느냐"를 묻는다.** 난도를 올릴 때 서술어를 유사 표현으로 바꾸거나, 떨어져 있는 두 정보를 바꿔 쓴 표현으로 이어 붙여 선지를 만든다. 추론·강화약화 유형에서 특히 심하다.

그래서 노베이스 학생은 **개념을 알아도 표현이 바뀌면 못 알아본다.** 이 사전은 그 간극을 메우는 용도다.

## 쓰는 법

🏷 블록에 이렇게 넣는다. 3~5개면 충분하다.

```
🏷 시험 용어
여러 개 보고 규칙 찾기 = 「귀납」
바꿔 나옴:
· 개별 사례에서 일반적 결론을
· 관찰 결과를 일반화하여
· 경험을 통해 얻은 규칙
```

**규칙**
- 특정 기출 문장을 그대로 옮기는 게 아니라 **자주 쓰이는 패턴**을 준다.
- 지문이 손에 있으면 사전보다 **그 지문의 실제 표현**을 우선한다.
- 연도·회차·문항 번호는 확실할 때만. 확실하지 않으면 붙이지 않는다.
- 반대말도 같이 주면 선지 판별이 빨라진다 → `↔ 연역`

## 바꿔쓰기가 만들어지는 4가지 방식

이 네 가지만 알면 처음 보는 표현도 뚫린다. 학생에게 이 틀 자체를 가르친다.

| 방식 | 원래 | 바뀐 모습 |
|---|---|---|
| 명사 → 풀어쓰기 | 귀납 | 사례에서 결론을 이끌어냄 |
| 능동 ↔ 피동 | A가 B를 정한다 | B는 A에 의해 정해진다 |
| 긍정 → 이중부정 | 항상 그렇다 | 예외가 없다 |
| 구체 → 추상 | 값이 오르면 안 산다 | 수요량이 감소한다 |

**함정 신호** — 바꿔쓰기처럼 보이지만 뜻이 달라진 경우다. 여기서 오답이 나온다.

```
지문: 대부분 그렇다
선지: 항상 그렇다     ← 과장
지문: A 때문에 B
선지: B 때문에 A      ← 뒤바꿈
```

# 과목별 사전

## 국어 — 논리·독서 공통

| 쉬운 말 | 정식 용어 | 바꿔 나오는 표현 |
|---|---|---|
| 여러 개 보고 규칙 찾기 | 귀납 | 개별 사례에서 일반적 결론을 / 관찰을 일반화하여 |
| 규칙으로 하나 판단하기 | 연역 | 일반 원리를 개별 사례에 적용하여 |
| 미리 깔고 가는 생각 | 전제 | 바탕에 두고 있는 / 당연하게 여기는 |
| 서로 부딪힘 | 상충 | 양립하기 어렵다 / 동시에 성립하지 않는다 |
| ~때문에 생김 | 기인 | ~에서 비롯되다 / ~에 근거를 두다 |
| 딱 잘라 말할 수 없음 | 유보 | 판단을 미루다 / 단정하지 않는다 |
| 뜻을 좁힘 | 한정 | ~에 국한하여 / 특정 조건에서만 |
| 뜻을 넓힘 | 확장 | ~까지 포괄하여 / 일반화하여 |

## 국어 — 문학

| 쉬운 말 | 정식 용어 | 바꿔 나오는 표현 |
|---|---|---|
| 말하는 사람 | 화자 | 시적 화자 / 말하는 이 |
| 이야기 들려주는 사람 | 서술자 | 이야기 밖 서술자(3인칭) / 이야기 안 서술자(1인칭) |
| 기분이 바뀜 | 정서의 변화 | 태도가 전환되다 / 인식이 달라지다 |
| 대놓고 말 안 함 | 함축 | 우회적으로 드러내다 / 간접적으로 제시하다 |
| 자연에 기분 얹기 | 감정 이입 | 대상에 정서를 투영하여 |
| 상황을 그림처럼 | 묘사 | 시각적으로 형상화하여 |

## 수학

| 쉬운 말 | 정식 용어 | 바꿔 나오는 표현 |
|---|---|---|
| 그 순간 기울기 | 미분계수 | 순간변화율 / 접선의 기울기 |
| 늘 같은 만큼 커짐 | 등차수열 | 공차가 일정한 / 이웃한 항의 차가 같은 |
| 늘 같은 배로 커짐 | 등비수열 | 공비가 일정한 / 이웃한 항의 비가 같은 |
| 끊기지 않음 | 연속 | 극한값과 함숫값이 같은 |
| 가장 높은 곳 | 극대 | 증가에서 감소로 바뀌는 |
| 두 개가 만나는 곳 | 교점 | 방정식의 실근 / 해의 개수 |
| 넓이 | 정적분 | 곡선과 x축으로 둘러싸인 영역 |

수학은 **문장을 식으로 옮기는 것**이 진짜 시험 대상이다. 바꿔쓰기가 곧 "조건 → 식" 번역이다.

```
"교점이 2개다"
   ↓
"실근이 2개다"
   ↓
"판별식 > 0"
```

## 영어

| 쉬운 말 | 시험 표현 | 바꿔 나오는 표현 |
|---|---|---|
| 그런데 | However | Nevertheless / On the contrary |
| 그래서 | Therefore | Consequently / As a result |
| 예를 들면 | For example | For instance / To illustrate |
| 게다가 | In addition | Moreover / Furthermore |

영어 빈칸·주제 문제는 **지문의 문장을 그대로 답으로 주지 않는다.** 정답 선지는 지문 문장을 바꿔 쓴 것이다. 그래서 "지문에 그대로 있는 말"이 오히려 오답인 경우가 많다. 이 사실을 학생에게 말해 준다.

## 통합사회

| 쉬운 말 | 정식 용어 | 바꿔 나오는 표현 |
|---|---|---|
| 모자람 | 희소성 | 욕구에 비해 자원이 한정된 |
| 포기한 것의 값 | 기회비용 | 선택하지 않은 대안의 가치 |
| 나눠 갖기 규칙 | 분배 정의 | 자원 배분의 공정성 |
| 힘을 나눠 놓음 | 권력 분립 | 견제와 균형 / 상호 감시 |
| 다 같이 정함 | 사회적 합의 | 구성원 간 동의를 통해 |

## 통합과학

| 쉬운 말 | 정식 용어 | 바꿔 나오는 표현 |
|---|---|---|
| 전자를 뺏김 | 산화 | 산소와 결합 / 전자를 잃는 |
| 전자를 얻음 | 환원 | 산소를 잃음 / 전자를 얻는 |
| 스스로 유지함 | 항상성 | 일정한 상태를 유지하는 |
| 형태만 바뀜 | 에너지 전환 | 에너지가 다른 형태로 |
| 총량 그대로 | 보존 | 전후 값이 같다 |

## 한국사

| 쉬운 말 | 정식 용어 | 바꿔 나오는 표현 |
|---|---|---|
| 강제로 맺음 | 불평등 조약 | 일방적으로 유리한 조항 |
| 제도를 뜯어고침 | 개혁 | 근대적 제도를 도입 |
| 나라를 뺏김 | 국권 피탈 | 주권 상실 |

한국사 선지는 **인물·시기·사건을 서로 바꿔치기**하는 방식이 많다. 사건 이름만 외우면 뚫린다. `언제 / 왜 / 뭐가 바뀜` 세 가지를 항상 같이 잡는다.

## 사전에 없는 개념일 때

만드는 방법은 위 4가지 방식 그대로다.

1. 개념을 한 문장으로 푼다
2. 그 문장을 **명사로** 뭉친다 → 정식 용어
3. 그 문장을 **피동으로** 바꾼다
4. 그 문장을 **더 추상적인 말로** 올린다

이 셋이 곧 바꿔쓰기 후보다. 확신이 없으면 `이런 식으로 바뀌어 나올 수 있어` 라고 쓰고, 단정하지 않는다.
