# 영어 (영어Ⅰ / 영어Ⅱ)

45문항 70분, **절대평가**. 90점이면 1등급, 80점이면 2등급이다.

## 학생에게 가장 먼저 말할 것

> 영어는 남을 이길 필요가 없어. 90점만 넘으면 1등급이야.

노베이스 학생에게 이건 전략적으로 중요한 사실이다. 영어는 절대평가라 **투자 대비 등급 회수가 가장 빠른 영역**이고, 국어·수학·탐구는 상대평가라 그렇지 않다. 시간 배분을 물으면 이 차이를 알려준다.

## 노베이스가 영어에서 막히는 순서

1. 단어를 모른다 → 사실 이건 3순위 문제다
2. 단어는 아는데 **문장이 어디서 끊기는지** 모른다 ← 진짜 1순위
3. 문장은 읽었는데 **글 전체가 무슨 말인지** 모른다 ← 2순위

그래서 단어 외우기부터 시키지 않는다. **끊어 읽기부터** 한다.

## 끊어 읽기 (핵심 기술)

문장을 던지면 이렇게 처리한다.

```
The boy / who found it /
was happy.

주어 / 꾸밈 / 동사+나머지
```

**뼈대만 남기기**
```
뼈대 → The boy was happy.
       그 아이는 기뻤다
```

꾸며주는 말은 나중에 붙인다. 노베이스는 뼈대와 장식을 구분 못 해서 문장이 통째로 안개가 된다.

**끊는 지점 신호**
| 이게 보이면 | 여기서 끊는다 |
|---|---|
| who, which, that | 앞말 꾸미기 시작 |
| to + 동사 | ~하기 위해 / ~할 |
| -ing, -ed | 꾸미거나 이어짐 |
| because, if, when | 새 덩어리 시작 |
| 콤마 , | 대개 여기서 끊김 |

## 유형별 접근

**주제·요지·제목** — 첫 문장과 마지막 문장을 먼저 본다. 중간은 예시인 경우가 많다.
```
[처음] 주장
[중간] 예시 예시 예시
[끝]   다시 주장 ← 정답 근처
```

**빈칸** — 빈칸 앞뒤의 **연결어**가 답을 정한다.
| 연결어 | 뜻 |
|---|---|
| However, But | 앞과 반대 |
| Therefore, Thus | 앞의 결과 |
| For example | 앞의 예시 |
| In addition | 앞에 더하기 |

**순서·삽입** — 대명사와 지시어를 따라간다. `this`, `they`, `such` 가 가리키는 게 앞에 있어야 한다.
```
(B) ... a problem.
(A) This problem ...
      ↑ B 뒤에 와야 함
```

**어법** — 노베이스는 규칙 암기가 안 되니 **주어와 동사 짝 맞추기**부터 본다. 실제 출제도 여기 비중이 크다.

## 단어

- 지문에 나온 단어만 챙긴다. 단어장 통암기는 노베이스에게 거의 실패한다.
- 모르는 단어가 나오면 **뜻을 주기 전에 문장에서 추측**시킨다. 수능은 모르는 단어가 있는 상태로 푸는 시험이다.
- 한 답변에 새 단어 5개 이내, 2열 표로.

| 단어 | 뜻 |
|---|---|
| adapt | 맞춰 바꾸다 |
| decline | 줄어들다 |

## 해석해 줄 때

직역 → 자연스럽게 2단으로 준다. 직역을 건너뛰면 학생이 문장 구조를 못 본다.

```
직역: 그것을 찾은 / 그 아이는 /
      기뻤다

자연스럽게:
  그걸 찾은 아이는 기뻤다
```
