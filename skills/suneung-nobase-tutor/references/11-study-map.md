# 같이 볼 개념 연결망 (🔗 블록용)

## 쓰는 법

답변 끝에 한 줄로 붙인다.

```
🔗 같이 볼 것: 연역(반대 개념),
   일반화의 한계
```

**진도 순서가 아니라 출제 묶음 기준으로 고른다.** 같은 문제·같은 지문에 자주 함께 나오는 것을 짚어야 다음 공부가 점수로 바뀐다. 1~2개면 충분하다. 셋 이상은 학생이 압도당한다.

**고를 때 우선순위**
1. 지금 개념과 **한 문제에서 같이 판단해야 하는 것** (예: 귀납 ↔ 연역)
2. 이걸 모르면 지금 개념이 반쪽인 것 (예: 미분 ← 기울기)
3. 바로 다음 단계 (예: 미분 → 극대·극소)

# 과목별 묶음 지도

## 국어 — 독서

```
[논증 구조]
 ├ 귀납 ↔ 연역
 ├ 전제 ↔ 결론
 └ 반박·한계 지적
      ↑ 지문 후반 단골
```

| 지금 배운 것 | 같이 볼 것 |
|---|---|
| 귀납 | 연역, 일반화의 한계 |
| 전제 | 숨은 전제 찾기, 반례 |
| 인과 | 상관관계와의 차이 |
| 정의 | 개념의 적용 범위 |

**지문 유형별 단골 짝**

| 분야 | 늘 같이 나오는 것 |
|---|---|
| 경제 | 수요·공급 + 기회비용 + 정책 효과 |
| 법 | 원칙 + 예외 + 적용 요건 |
| 과학기술 | 원리 + 한계 + 개선 방향 |
| 철학 | 두 입장 + 각각의 근거 + 비판 |

## 국어 — 문학

| 지금 배운 것 | 같이 볼 것 |
|---|---|
| 화자 | 화자의 태도 변화, 시선 이동 |
| 서술자 | 시점(1·3인칭), 서술 거리 |
| 감정 이입 | 객관적 상관물, 자연물의 역할 |
| 〈보기〉 해석 | 작품 외적 정보 적용 |

**문학은 〈보기〉가 붙으면 해석 방향이 정해진다.** 〈보기〉 읽는 법을 항상 함께 짚는다.

## 수학

```
[미적분Ⅰ 흐름]
 극한 → 연속 → 미분
              ↓
         극대·극소 → 그래프
              ↓
         적분 (넓이)
```

| 지금 배운 것 | 같이 볼 것 | 밑에 깔린 것 |
|---|---|---|
| 미분계수 | 접선의 방정식, 극대·극소 | 기울기, 일차함수 |
| 등차수열 | 등비수열, 합 공식 | 규칙 찾기, 문자식 |
| 지수 | 로그(지수의 반대) | 거듭제곱 |
| 삼각함수 | 주기·최댓값, 그래프 | 직각삼각형 비, 원 |
| 확률 | 경우의 수, 조건부확률 | 분수, 세기 |

**밑에 깔린 것이 비면 위가 안 올라간다.** 학생이 막히면 `밑에 깔린 것` 칸부터 확인한다. 통째로 중학교로 돌려보내지 말고 **막힌 한 조각만** 채운다.

## 영어

| 지금 배운 것 | 같이 볼 것 |
|---|---|
| 끊어 읽기 | 관계대명사, to부정사 |
| 빈칸 | 연결어, 지문 논리 흐름 |
| 순서·삽입 | 지시어(this, such), 대명사 |
| 주제·요지 | 첫·끝 문장, 바꿔 쓴 정답 선지 |

**영어 정답 선지는 지문 문장을 바꿔 쓴 것이다.** 지문에 그대로 있는 말이 오히려 오답인 경우가 많다.

## 통합사회

```
[통합사회]
 인간·행복 ─┐
 자연·공간 ─┤
 인권·헌법 ─┼→ 한 문항에 섞여 나옴
 시장·경제 ─┤   (융합형)
 정의·불평등┤
 문화·세계화┘
```

2028 탐구 예시문항은 **여러 영역을 섞은 융합형**이었다. 그래서 🔗에는 **다른 영역의 짝**을 붙이는 게 효과가 크다.

| 지금 배운 것 | 같이 볼 것 |
|---|---|
| 기회비용 | 희소성, 합리적 선택 |
| 분배 정의 | 불평등, 사회 복지 |
| 권력 분립 | 헌법, 기본권 보장 |
| 세계화 | 문화 다양성, 지역 격차 |

## 통합과학

| 지금 배운 것 | 같이 볼 것 |
|---|---|
| 산화 | 환원(동시에 일어남), 연소 |
| 에너지 전환 | 보존 법칙, 효율 |
| 항상성 | 되먹임 조절 |
| 광합성 | 호흡(반대 방향), 탄소 순환 |

**과학은 짝으로 외운다.** 산화↔환원, 광합성↔호흡처럼 반대쪽을 같이 보면 둘 다 안 헷갈린다.

## 한국사

```
1876 개항 → 1894 개혁
              ↓
1897 대한제국 → 1910 피탈
```

| 지금 배운 것 | 같이 볼 것 |
|---|---|
| 강화도조약 | 개항장, 불평등 조항 |
| 갑오개혁 | 신분제 폐지, 근대 제도 |
| 국권 피탈 | 이후 저항 운동 |

한국사 선지는 **인물·시기를 서로 바꿔치기**하는 방식이 많다. 사건 하나를 볼 때 `언제 / 왜 / 뭐가 바뀜` 세 가지를 같이 잡는다.

# 노베이스 우선순위 (학생이 `시험 언제까지` 물었을 때)

시간이 없는 학생에게 "전부 다 해"는 답이 아니다. 회수율 순으로 말해 준다.

| 순위 | 무엇 | 이유 |
|---|---|---|
| 1 | 영어 | 절대평가 90점이면 1등급. 남을 이길 필요 없음 |
| 2 | 한국사 | 절대평가 40점이면 1등급. 분량 적음 |
| 3 | 탐구(통합사회·통합과학) | 고1 범위 한정. 자료 해석 위주라 암기량 적음 |
| 4 | 국어 독서 | 배경 상식 채우면 오르지만 시간이 걸림 |
| 5 | 수학 | 결손 메우는 데 가장 오래 걸림. 대신 한 번 뚫리면 안 무너짐 |

**단, 이건 "무엇부터"의 순서지 "무엇만"이 아니다.** 국어·수학·탐구는 상대평가라 결국 다 해야 한다. 학생이 포기하려 하면 이 사실을 정확히 말해 준다 — 겁주는 게 아니라 사실이라서.

**남은 기간을 물어보면** 하루 단위 계획을 세워 주지 말고, **이번 주에 뚫을 것 하나**만 정해 준다. 노베이스는 긴 계획을 못 지킨다.
