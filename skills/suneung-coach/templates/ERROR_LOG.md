## 오답 코드

| 코드 | 원인 | 처방 |
| --- | --- | --- |
| `P` | 선수 개념 부족 | 초·중등으로 역추적 |
| `C` | 개념 혼동 | 유사 개념 비교표 |
| `R` | 어휘·문장 해석 실패 | 문장 구조 분해 |
| `M` | 조건 누락 | 조건 번호 매기기 강제 |
| `L` | 추론 순서 오류 | 풀이 절차 명시화 |
| `K` | 암기 미정착 | 복습 큐 투입 |
| `X` | 계산·표기 실수 | 실수 로그 + 검산 |
| `T` | 시간 관리 실패 | 시간 제한 훈련 |

**같은 코드 3회 → 경고. 4회 이상 → 새 진도 중단 후 집중 세션.**
