# 오개념 카탈로그

**이 파일이 이 스킬을 강하게 만드는 핵심이다.**

보통 AI는 학생이 틀리면 "정답은 ○입니다"라고 한다.
좋은 선생은 **"너 지금 이렇게 생각했지?"**라고 한다.

이 파일은 학생이 실제로 갖는 **잘못된 생각의 목록**이다.
학생 답이 틀렸을 때, 여기서 **어떤 오개념인지 먼저 찾는다.**

## 사용법

```
학생이 틀림
 ↓
여기서 해당 오개념을 찾는다
 ↓
"너 이렇게 생각했지?" 하고 먼저 맞힌다   ← 이게 신뢰를 만든다
 ↓
왜 그렇게 생각하는 게 자연스러운지 인정
 ↓
어디서 어긋나는지 딱 한 지점만 짚는다
```

**"틀렸습니다"로 시작하지 않는다.** "이렇게 생각했지?"로 시작한다.

---

## 수학

| 오개념 | 학생 생각 | 교정 |
| --- | --- | --- |
| 분배 남용 | `(a+b)² = a²+b²` | `(1+1)²=4`인데 `1+1=2`. 직접 넣어보게 한다 |
| 루트 분배 | `√(a+b) = √a+√b` | `√(9+16)=5`, `3+4=7`. 반례 하나면 끝 |
| 로그 분배 | `log(a+b) = log a + log b` | 로그는 **곱을 합으로** 바꾼다. 합은 못 바꾼다 |
| 음의 지수 | `2⁻² = -4` | 마이너스는 **뒤집으라는 신호**. `1/2² = 1/4` |
| 0제곱 | `2⁰ = 0` | `2³→2²→2¹` 갈수록 반씩. `2¹=2`의 반은 1 |
| 부등식 부호 | 음수 곱해도 부호 유지 | `2<3`에 -1 곱하면 `-2>-3`. 수직선으로 |
| 이항 부호 | `x+3=5` → `x=5+3` | 이항은 **반대편으로 넘기며 부호가 뒤집힌다** |
| 제곱근 | `√(x²) = x` | `x=-3`이면? `√9=3`. 답은 `|x|` |
| 함수 표기 | `f(x)`를 `f×x`로 읽음 | f는 기계, x는 넣는 것. 곱셈 아님 |
| 확률 독립 | 앞에서 앞면 3번 → 다음은 뒷면 확률 높음 | 동전은 기억이 없다 |
| 평균 | 평균이 오르면 모두가 오름 | 한 명이 크게 오르면 나머지가 떨어져도 평균은 오른다 |
| 기울기 | 가파른 게 무조건 큰 기울기 | 음수 기울기는 가파를수록 **작다** |

### 가장 자주 나오는 것 3개
`(a+b)²`, 음의 지수, 부등식 부호. **이 셋은 물어보기 전에 확인해도 좋다.**

## 국어

| 오개념 | 학생 생각 | 교정 |
| --- | --- | --- |
| 느낌 독해 | 답을 "느낌"으로 고름 | 근거 문장을 손으로 짚게 한다. 못 짚으면 오답 |
| 주제=첫문장 | 첫 문장이 항상 주제 | 도입은 화제 제시일 뿐. 주제는 대개 역접 뒤 |
| 어려운 선지=정답 | 말이 어려우면 정답 같음 | 정답은 지문을 **정확히** 옮긴 것. 어려움과 무관 |
| 지문 밖 상식 | 자기 배경지식으로 판단 | 지문에 없으면 오답. "내 생각"은 근거가 아니다 |
| 양화사 무시 | "일부"와 "모두"를 같게 봄 | 여기서 대부분의 오답이 나온다 |
| 반어=반대말 | 반어를 단순 반대로 이해 | 반어는 **말과 속뜻이 어긋남**. 상황이 있어야 성립 |
| 상징=비유 | 둘을 같게 봄 | 비유는 원관념이 있고, 상징은 없거나 숨는다 |
| 화자=작가 | 시의 화자를 작가로 봄 | 화자는 작가가 만든 인물 |
| 시점 혼동 | 1인칭 관찰자를 주인공으로 | "나"가 사건의 중심인가 지켜보는가 |
| 지양/지향 | 뜻을 뒤집어 앎 | **지양 = 안 하려 함.** 시험에 짝으로 나온다 |

### 국어에서 가장 치명적인 것
**"느낌으로 고르기".** 이걸 못 고치면 다른 걸 아무리 해도 4등급에서 안 올라간다.
학생이 답을 말하면 **항상 "몇 번째 문단 어느 문장?"을 묻는다.**

## 영어

| 오개념 | 학생 생각 | 교정 |
| --- | --- | --- |
| 어휘=해석 | 단어 다 알면 읽힌다 | 주어·동사를 못 찾으면 단어를 다 알아도 못 읽는다 |
| 앞에서부터 | 왼쪽부터 순서대로 해석 | 동사 먼저 찾고 뼈대를 세운다 |
| 첫 명사=주어 | 맨 앞 명사를 주어로 | 전치사구 안의 명사는 주어가 될 수 없다 |
| that 하나 | that을 다 같게 봄 | 접속사 / 관계대명사 / 지시어 — 뒤 문장으로 구분 |
| 관계사 | which/where를 감으로 | **뒤가 완전하면 부사, 불완전하면 대명사** |
| -ing = 진행 | 모든 -ing를 진행형으로 | 동명사·분사도 있다. 문장에 동사가 이미 있나 확인 |
| 수동태 | be+p.p.면 무조건 수동 | be동사 + 형용사화된 분사도 있다 |
| 현재완료 | 과거와 같게 봄 | 과거는 끝난 일, 완료는 **지금까지 이어짐** |
| 빈칸=어휘 | 빈칸에 어려운 단어 | 빈칸은 **논리**를 묻는다. 앞뒤 연결어가 답 |
| 지문 단어 선지 | 지문에 나온 단어면 정답 | 어휘가 같다고 논리가 같지 않다 |

### 영어에서 가장 치명적인 것
**주어·동사를 못 찾는 것.** 어휘 외우기 전에 이것부터.

## 사회 · 한국사

| 오개념 | 학생 생각 | 교정 |
| --- | --- | --- |
| 상관=인과 | 그래프가 같이 움직이면 원인 | 제3의 원인, 역방향, 우연을 먼저 의심 |
| 자유=마음대로 | 일상 의미로 이해 | 학문적 자유는 **간섭의 부재 / 자기결정** |
| 평등=똑같이 | 결과의 평등만 생각 | 기회의 평등과 결과의 평등은 다른 주장 |
| 상대주의 무제한 | 모든 문화가 다 옳다 | 보편 인권을 침해하면 한계가 있다 |
| 시장실패=시장 나쁨 | 실패했으니 정부가 맞다 | 정부실패도 있다. 둘 다 실패할 수 있다 |
| 진보/보수 | 좋고 나쁨으로 이해 | 변화 속도와 방향에 대한 입장 차이 |
| 역사=암기 | 연도만 외움 | **어떤 문제를 풀려 했나**로 저장 |
| 근대화=좋음 | 근대적이면 진보 | 갑오개혁은 근대적이면서 타율적. 둘 다 참 |
| 사건 순서 | 시대 감각 없음 | 굵은 사건 4개(임진왜란·개항·강점·광복)를 기둥으로 |
| 사료=사실 | 사료에 쓰인 게 다 사실 | 사료도 누군가의 관점이다 |

### 사회에서 가장 치명적인 것
**상관과 인과 혼동.** 자료 해석 문제의 오답 선지가 거의 여기서 나온다.

## 과학

| 오개념 | 학생 생각 | 교정 |
| --- | --- | --- |
| 무거우면 빨리 떨어짐 | 직관 | 공기저항 없으면 같다. 깃털과 망치 실험 |
| 힘=속도 | 힘을 주면 빨라진다 | 힘은 **가속도**를 만든다. 등속운동엔 알짜힘 0 |
| 진화=진보 | 더 나은 방향으로 발전 | 환경에 맞는 것이 남는 것. 방향 없음 |
| 진화=개체 변화 | 기린이 목을 늘림 | 개체가 변하는 게 아니라 **집단의 비율**이 변함 |
| 원자=분자 | 구분 못 함 | 원자는 알갱이, 분자는 붙은 덩어리 |
| 이온 | 뭔지 모름 | 전자를 잃거나 얻어 전기를 띤 것 |
| 에너지 소모 | 에너지가 사라진다 | 형태가 바뀔 뿐 총량은 보존 |
| 온실효과=나쁨 | 온실효과 자체가 문제 | 없으면 영하 18도. **강화**가 문제 |
| 세포=작은 생물 | 세포를 독립 생물로 | 세포는 구성 단위 |
| 열=온도 | 같은 것으로 봄 | 열은 이동하는 에너지, 온도는 상태 |

### 과학에서 가장 치명적인 것
**힘과 속도 혼동**, **입자 개념 부재.** 이 둘이 물리·화학 전체를 막는다.

## 학생 답이 틀렸을 때의 표준 대응

```
❌ 나쁜 대응
"틀렸습니다. 정답은 ③입니다.
 (a+b)² = a²+2ab+b² 이기 때문입니다."

✅ 강한 대응
"a²+b² 나왔지?

 그럴 만해. 괄호 밖 지수를
 안에 나눠준 거잖아.
 곱셈은 그게 되니까.

 근데 제곱은 안 돼.
 (1+1)² = 4
 1² + 1² = 2

 숫자 넣으면 바로 보여.
 왜 안 되는지 알겠어?"
```

차이:
1. **먼저 맞힌다** — "이렇게 생각했지?"
2. **자연스러운 오해임을 인정한다** — 학생이 방어하지 않게
3. **반례 하나로 무너뜨린다** — 설명보다 강하다
4. **한 지점만 짚는다** — 여러 개 짚으면 다 놓친다

---

## 이 파일을 언제 읽는가

- 학생이 **틀린 답을 말했을 때**
- 학생 설명에서 **미묘하게 어긋난 게 느껴질 때**
- 개념을 가르치기 **전에** (미리 함정을 알고 설명하면 훨씬 강해진다)

개념 설명 시 해당 오개념을 **선제적으로 차단**하면 좋다.

```
📖 log는 곱을 합으로 바꾼다.
⚠️ 합은 못 바꾼다.
   log(a+b)는 못 쪼갠다.
   여기서 다 틀린다.
```
