# 설명 대본 — 고빈도 개념

고1이 가장 자주 막히는 개념의 **완성된 설명**이다.
매번 새로 만들지 말고 여기서 가져다 쓴다. 그래야 설명 품질이 일정하다.

각 대본은 그대로 폰에 보내도 되는 형태다 (3열 이하, 좁은 도식).

**대본은 출발점이지 대사가 아니다.** 학생 상태에 맞춰 조정한다.

> ⚠️ **모든 대본에 이 셋이 들어가야 한다.**
> `예:` 구체적 사례 / `📖` 평가원 용어 / `🎯` 문제 양상
> 이게 없으면 학생은 이해해도 시험지에서 막힌다.
> 아래 대본 중 빠진 게 있으면 `21-exam-language.md`를 보고 채워 넣는다.

## 수학

### 음의 지수 — 최다 결손

```
**마이너스 지수 = 뒤집으라는 신호**

2³ = 8
2² = 4    ← 반
2¹ = 2    ← 반
2⁰ = 1    ← 반
2⁻¹= 1/2  ← 반
2⁻²= 1/4  ← 반

계속 반씩 줄어들 뿐이야.
마이너스 붙었다고 음수 아님.

예: 10⁻³ = 1/1000
    (밀리미터가 딱 이것)

📖 시험 말
   위 숫자 = 밑
   작은 숫자 = 지수

🎯 문제로는
   지수법칙 계산에 섞여 나옴.
   "2⁻²×2⁵" 같은 꼴.
   함정: 부호 보고 음수로 착각

❓ 3⁻² 는?
```

### 로그

```
**로그 = "몇 번 곱했냐"를 묻는 기호**

2를 몇 번 곱하면 8?
  → 3번
기호로: log₂8 = 3

비유: 계단 몇 칸 올라갔나
단, 계단은 정수뿐인데
로그는 소수도 됨 (log₂5≈2.32)

예: 소리 크기(데시벨)도 로그.
    10배 커질 때마다 10dB

📖 시험 말
   2 = 밑
   8 = 진수
   3 = 지수

🎯 문제로는
   "log₂(x-1)이 정의되도록
    하는 x의 범위는?"
   = 진수가 0보다 커야 한다
   함정: 진수 조건 빼먹기

❓ log₃81은?
```

### 이차함수 최댓값·최솟값

```
**꼭짓점이 답이다**

y = a(x-p)² + q
→ 꼭짓점 (p, q)

 a>0        a<0
  ＼／      ／＼
 최소 q    최대 q

괄호 안은 부호 반대로,
밖은 그대로.

왜? x-p가 0 되려면 x=p니까.

⚠️ (x-2)²이면 꼭짓점 x=2.
   -2 아님.

❓ y=(x+3)²-1 의 꼭짓점은?
```

### 판별식

```
**판별식 = 그래프가 x축을 몇 번 만나나**

D = b²-4ac

D>0  ／‾＼  두 점에서 만남
     ─┴─┴─

D=0  ／‾＼  한 점에서 스침
     ──┴──

D<0  ／‾＼  안 만남
     ─────

📖 실근의 개수

🎯 "서로 다른 두 실근" → D>0
   "중근" → D=0
   "실근 없음" → D<0

❓ x²-4x+4=0 은 어느 경우?
```

### 확률 — 조건부

```
**조건부확률 = 세는 무리를 줄이는 것**

전체 100명 중
안경 쓴 사람 40명
그중 여자 25명

"안경 쓴 사람 중 여자일 확률"
= 25/40   ← 분모가 100이 아님

전체 100명이 아니라
'안경 쓴 40명'만 놓고 세는 것.
무리가 작아진 거야.

⚠️ 아래 숫자를 100으로 쓰면 틀림.
   "~중에"가 나오면
   아래 숫자가 바뀐다.

❓ 여자 중 안경 쓸 확률의 분모는?
```

## 국어

### 문장 성분 — 모든 것의 바닥

```
**긴 문장은 뼈대부터 찾는다**

"시장에서 형성되는 가격은
 자원을 효율적으로 배분하는
 신호로 기능한다."

주어:   가격은
서술어: 기능한다
나머지: 전부 꾸미는 말

→ 뼈대: 가격은 기능한다
→ 무엇으로? 신호로

예: "밥은 맛있다"에 살을
    계속 붙인 게 긴 문장

📖 시험 말
   주어 · 서술어 · 목적어 · 보어
   = 주성분

🎯 문제로는
   "안긴문장의 종류는?"
   "이 문장의 주성분 개수는?"
   함정: 수식어를 주성분으로 셈

❓ 이 문장 주어는?
"우리가 흔히 쓰는 이 말은
 원래 다른 뜻이었다."
```

### 선지 판단 — 감으로 고르기 교정

```
**정답을 고르지 말고 오답을 지운다**

선지를 읽고
 ↓
"이게 맞으려면 지문에
 뭐라고 써 있어야 하지?"
 ↓
그 문장을 찾는다
 ↓
못 찾으면 → 오답

⚠️ "느낌상 맞는 것 같아서"
   이건 틀린 것과 같다.

오답 만드는 6가지 수법
· 일부 → 모두 (과대)
· 조건 빼기 (과소)
· 인과 뒤집기
· 너무 넓게 말하기
· 지문에 없는 정보
· 한 문단을 전체로

❓ 방금 고른 답, 몇 문단 어느 문장이 근거야?
```

### 음운 변동

```
**소리가 바뀌는 5가지 방식**

교체  국물 → [궁물]
      (ㄱ이 ㅇ으로 바뀜)
탈락  좋아 → [조아]
      (ㅎ이 사라짐)
첨가  솜이불 → [솜니불]
      (ㄴ이 생김)
축약  좋고 → [조코]
      (ㅎ+ㄱ이 ㅋ으로 합침)

📖 된소리되기도 교체의 일종
   국밥 → [국빱]

🎯 수능은 "몇 번 일어났나"를 묻는다.
   한 단어에 두 개 겹치는 게 함정.

❓ '맏형'은 어떤 변동?
```

## 영어

### 주어·동사 찾기 — 영어의 전부

```
**동사부터 찾는다**

The researchers who had been
studying the phenomenon for
decades finally concluded that
the effect was negligible.

① 시제 있는 동사 찾기
   → concluded
② 그 앞에서 주어 찾기
   → The researchers
③ 나머지에 괄호
   → (who~decades) 는 설명

뼈대: researchers concluded
→ 연구자들이 결론 내렸다

⚠️ 맨 앞 명사가 주어인 건 아니다.
   전치사구 안 명사는 주어 못 됨.

❓ 이 문장 동사는?
"The book on the desk is mine."
```

### 관계대명사 vs 관계부사

```
**뒤 문장이 완전한가 불완전한가**

the book [which I read ___]
              ↑ 목적어 없음
→ 불완전 → 관계대명사 which

the place [where I lived]
              ↑ 완전한 문장
→ 완전 → 관계부사 where

📖 판단은 이 한 줄이면 끝:
   완전 → 부사
   불완전 → 대명사

⚠️ 뜻으로 고르면 틀린다.
   "장소니까 where" 아님.

❓ the reason ___ he left
   (뒤: he left = 완전)
```

### 빈칸 추론

```
**빈칸은 어휘가 아니라 논리**

① 빈칸 있는 문장 먼저 읽기
② 빈칸 위치 확인
   앞  → 주제 제시
   중간 → 부연 또는 전환
   뒤  → 결론
③ 앞뒤 연결어 확인
   however  → 반대
   therefore → 결과
   for example → 구체화
   in other words → 재진술
④ 글 주제를 한 단어로
⑤ 방향 맞는 선지

⚠️ 지문에 나온 단어가 들어간
   선지가 함정이다.
   어휘 같다고 논리 같지 않다.

❓ 이 글 주제를 한 단어로?
```

## 사회

### 수요·공급 그래프

```
**점이 움직이나, 선이 움직이나**

가격만 변함
→ 선 위에서 점만 이동
  (수요량 변화)

가격 말고 다른 게 변함
→ 선 자체가 이동
  (수요 변화)

  P
  │＼   ＼
  │ ＼   ＼  ← 선이 통째로 이동
  │  ＼   ＼
  └────────── Q

📖 소득↑, 유행, 인구 → 선 이동
   가격만 → 점 이동

🎯 여기가 최다 오답 지점.

❓ 커피값이 올라 수요가 줄었다.
   선? 점?
```

### 상관과 인과

```
**같이 움직인다 ≠ 원인이다**

아이스크림 판매 ↑
익사 사고 ↑

아이스크림이 원인?
→ 아님. 둘 다 '여름' 때문.

가능성 4가지
· A가 B의 원인
· B가 A의 원인
· C가 둘 다의 원인
· 우연

🎯 자료 해석 문제에서
   "따라서 A가 B를 유발한다"
   이런 선지는 대부분 오답.

⚠️ 자료는 '함께 변함'만 보여준다.
   원인은 자료 밖의 판단.

❓ 독서량 많은 학생이 성적이 높다.
   독서가 원인일까?
```

## 과학

### 힘과 운동

```
**힘은 속도가 아니라 '변화'를 만든다**

등속으로 달리는 차
→ 알짜힘 = 0
  (엔진힘 = 마찰력)

힘을 주면
→ 빨라지거나 느려지거나
  방향이 바뀐다

📖 힘 → 가속도
   힘 ≠ 속도

⚠️ "움직이니까 힘이 작용 중"
   이건 틀림.
   우주선은 힘 없이도 계속 간다.

❓ 일정한 속도로 도는 회전목마.
   힘이 작용할까?
```

### 원자 · 분자 · 이온

```
**셋을 구분하는 게 화학의 시작**

원자  기본 알갱이       ⚪
분자  원자가 붙은 것    ⚪-⚪
이온  전기를 띤 것      ⚪⁺

이온이 되는 법
전자를 잃음 → +
전자를 얻음 → −

📖 전자는 (−)다.
   잃으면 +가 남는다.

⚠️ "전자를 얻었으니 +"
   반대다. 여기서 다 헷갈린다.

❓ Na가 전자 1개를 잃으면?
```

## 대본에 없는 개념을 물었을 때

이 파일의 **형식**을 따라 새로 만든다.

```
결론 한 줄 (초등 수준 말로)
  ↓
좁은 도식 또는 표          ← 필수
  ↓
비유 + 비유가 깨지는 곳
  ↓
예: 구체적인 사례 하나      ← 필수
  ↓
📖 시험 말                 ← 필수
   쉬운 말 → 평가원 용어
  ↓
🎯 문제로는                ← 필수
   발문 한 줄 = 무슨 뜻
   함정: 어디서 틀리는지
  ↓
❓ 질문 1개
```

**📖🎯를 빼지 않는다.** 이게 초·중등 수준과 수능 사이의 다리다.
빼면 학생은 "이해했는데 시험만 보면 안 돼요"가 된다.

암기법(🧠)·응용(🔄)은 **학생이 물어볼 때만** 붙인다.
