# 과학 (통합과학)

2028 개편에서 인문계 지망생도 **통합과학에 응시**한다 `[사실 — 2023.12 교육부 발표]`
따라서 "인문이니까 과학은 버린다"는 선택지가 없다.

다만 통합과학은 심화 과목이 아니다. **개념 이해 + 자료 해석**이 중심이다.
인문 지망생에게는 **효율적으로 등급을 확보할 수 있는 과목**이다.

---

## 1. 설명 구조 (고정)

```
현상(무슨 일이 보이나)
  → 원인(왜 그런가)
  → 과정(어떤 순서로)
  → 결과
  → 변수(무엇을 바꾸면 무엇이 바뀌나)
  → 문제 적용
```

'변수' 단계가 핵심이다. **통합과학 문제는 대부분 "A를 늘리면 B는?" 형태**다.

---

## 2. 영역별 핵심

| 영역 | 핵심 | 자주 터지는 지점 |
| --- | --- | --- |
| 물질과 규칙성 | 원소의 생성, 주기율, 화학 결합 | 원자·분자·이온 구분 |
| | 지각·생명체 구성 물질 | 규산염 사면체, 단백질/핵산 |
| 시스템과 상호작용 | 역학적 시스템(중력, 운동) | 속도 vs 가속도 |
| | 지구 시스템(지권·수권·기권·생물권) | 권역 간 상호작용 |
| | 생명 시스템(세포, 물질대사, 유전자) | 효소, 전사·번역 |
| 변화와 다양성 | 화학 변화(산화·환원, 산·염기) | 전자 이동 방향 |
| | 생물 다양성, 진화 | 자연선택 오해 |
| 환경과 에너지 | 생태계 평형, 지구온난화 | 에너지 흐름 vs 물질 순환 |
| | 에너지 전환·효율, 발전 | 에너지 보존 |

---

## 3. 인문계 학생이 과학에서 무너지는 3가지 원인

### ① 입자 개념 부재
원자 / 분자 / 이온 / 전자를 구분하지 못한다. 화학 전체가 여기서 무너진다.

```
원자:  물질의 기본 알갱이            ⚪
분자:  원자가 붙어 만든 덩어리        ⚪-⚪
이온:  전자를 잃거나 얻어 전기를 띤 것  ⚪⁺
```
결손 발견 시 **최우선 복구**.

### ② 비례 관계 감각
"A가 2배가 되면 B는?" — 초6 비례가 바닥이다.
정비례 / 반비례 / 제곱에 비례를 그래프로 구분시킨다.

```
정비례      반비례       제곱비례
  /          \             /
 /            \___        /
/                        /
```

### ③ 용어를 일상 의미로 이해
- '일(work)' — 일상의 노동이 아니다
- '힘(force)' — 세기가 아니라 벡터
- '에너지' — 막연한 기운이 아니라 양으로 정의된 것
- '진화' — 발전이나 진보가 아니다

**과학 용어는 일상어와 다르다는 것을 명시적으로 경고한다.**

---

## 4. 자료 해석 절차

통합과학 문제의 대부분이 그래프·표·모식도다.

```
① 축과 단위 확인
② 무엇이 독립변수(내가 바꾼 것), 무엇이 종속변수(따라 바뀐 것)인가
③ 통제된 변수는 무엇인가 ← 여기서 함정이 나온다
④ 경향 한 줄
⑤ 자료가 말하지 않는 것
```

**"다른 조건이 같을 때"라는 문구가 있으면 반드시 표시한다.**

---

## 5. 과학에서의 "왜?" 질문 예시

- 왜 무거운 물체와 가벼운 물체가 같은 속도로 떨어지는가?
- 왜 소금은 물에 녹는데 기름은 안 녹는가?
- 왜 생태계에서 먹이 단계가 올라갈수록 개체 수가 줄어드는가?
- 왜 이산화탄소는 온실효과를 일으키는가?
- 왜 효소는 온도가 너무 높으면 기능을 잃는가?

---

## 6. 암기 방식

| 금지 | 대체 |
| --- | --- |
| 용어 정의 반복 | 그림으로 그리고 화살표로 관계 표시 |
| 순서 나열 암기 | 인과 사슬로 연결 (앞 단계가 뒤 단계의 원인) |
| 공식 암기 | 단위에서 공식 복원 (속도 = m/s → 거리÷시간) |

**단위에서 공식을 복원하는 훈련**은 이 학생에게 특히 유효하다.
암기가 약해도 단위만 기억하면 공식이 나온다.

---

## 7. 시간 배분

통합과학은 심화 과목이 아니므로 **과잉 투자를 경계한다.**
권장: 전체 학습 시간의 **10~15%**. 개념 정리 + 자료 해석 훈련 위주.

인문계 지망생이 과학에 시간을 과하게 쓰는 것은 전형적인 전략 실패다.
학생이 그 방향으로 가면 **명시적으로 경고한다.**
