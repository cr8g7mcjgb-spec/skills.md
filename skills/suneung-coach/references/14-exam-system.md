# 2029학년도 수능 · 시험 체제 팩트

> ⚠️ **이 파일의 모든 내용은 재확인 대상이다.**
> 입시 제도는 바뀐다. 이 학생의 시험은 2028년 11월에 시행된다.
> 학생에게 제도 정보를 줄 때는 반드시 **기준일과 재확인 안내**를 붙인다.
> 1순위 출처: 교육부(moe.go.kr), 한국교육과정평가원(kice.re.kr), 서울대 입학처.

## 1. 확정된 골격 (2028 대입개편)

`[사실 — 교육부 2023.12.27 「2028 대학입시제도 개편 확정안」]`

2029학년도 수능은 2028학년도부터 적용된 개편 체제를 따른다.

| 항목 | 내용 |
| --- | --- |
| 적용 교육과정 | 2022 개정 교육과정 |
| 수능 구조 | **선택과목 폐지, 통합형·공통 출제** |
| 국어 | 화법과 언어 / 독서와 작문 / 문학 (공통) |
| 수학 | 대수 / 미적분Ⅰ / 확률과 통계 (공통) |
| 영어 | **절대평가** 유지 |
| 한국사 | 필수, 절대평가 |
| 탐구 | **통합사회 + 통합과학** (계열 구분 없이 모두 응시) |
| 심화수학 | **미출제** (미적분Ⅱ·기하 제외) |
| 제2외국어/한문 | 절대평가 |
| 내신 | **5등급제** (기존 9등급제 폐지) |

### 이 학생에게 갖는 의미

1. **인문계도 통합과학을 본다.** 과학을 버릴 수 없다.
2. **선택과목 유불리가 없다.** 모두 같은 문제를 푼다 → 순수 실력 경쟁
3. **심화수학이 없다.** 수학 부담이 이전 세대보다 낮다 → 이 학생에게 유리
4. **영어 절대평가.** 90점만 넘기면 된다 → 시간 재배분 가능

## 2. 등급 체계 — 혼동 금지

**내신과 수능은 다른 등급제를 쓴다.** 학생이 가장 자주 혼동한다.

### 내신 (고교 학교생활기록부) — 5등급제 `[사실]`

| 등급 | 비율 | 누적 |
| --- | --- | --- |
| 1 | 10% | 10% |
| 2 | 24% | 34% |
| 3 | 32% | 66% |
| 4 | 24% | 90% |
| 5 | 10% | 100% |

### 수능 — 9등급제 유지 `[사실]`

| 등급 | 비율(누적) |
| --- | --- |
| 1 | 4% |
| 2 | 11% |
| 3 | 23% |
| 4 | 40% |
| 5 | 60% |
| 6 | 77% |
| 7 | 89% |
| 8 | 96% |
| 9 | 100% |

**절대평가 과목(영어·한국사·제2외국어)은 원점수 기준 9등급.**
영어 1등급 = 90점 이상, 2등급 = 80점 이상 (10점 간격) `[사실]`

### 학생 현재 위치
프로필상 **내신 5등급제 기준 약 4등급** = 상위 66~90% 구간.
수능 1등급(상위 4%)까지의 거리를 축소해서 말하지 않는다.
