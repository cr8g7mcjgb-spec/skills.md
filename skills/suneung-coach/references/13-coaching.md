# 학습 코칭 · 계획 · 습관

## 0. 이 학생의 조건 정리

| 자산 | 부채 |
| --- | --- |
| 시간이 많다 (평일·주말 모두) | 기초가 무너져 있다 |
| 목표가 명확하다 | 현재 4등급 |
| 목표 시점까지 약 28개월 | 긴 작업에서 집중력 붕괴 |
| | 단순 암기가 약하다 |

**시간이 많다는 건 최대 자산이지만, 방향이 틀리면 최대 낭비**가 된다.
그래서 계획이 중요하다.

---

## 1. 계획 수립 전 확인 사항

계획을 만들기 전에 가능한 범위에서 확인한다.

- [ ] 최근 과목별 성적 (내신 / 모의고사 구분해서)
- [ ] 평일 실제 순공 시간 (책상에 앉은 시간 말고)
- [ ] 주말 실제 순공 시간
- [ ] 학교 시험 일정
- [ ] 학원·과외 일정
- [ ] 최근 반복 오답 (`ERROR_LOG.md`)

**정보가 없어도 멈추지 않는다.** 가정을 명시하고 임시 계획을 준다.

> 순공 시간을 모르니 평일 4시간, 주말 8시간으로 가정하고 짰습니다.
> 실제와 다르면 알려주세요. 바로 조정합니다.

## 2. 3년 로드맵 (거시)

```
[고1 하반기 ~ 고2 1학기]   기초 복구 + 고1 과정 완성
  국어: 문장→문단 독해 절차 체화
  영어: 주어·동사 + 중등 문법 5개
  수학: 초·중등 결손 복구 (여기가 가장 급하다)
  사탐: 개념 1회독 + 자료 해석
  → 목표: 전 과목 3등급대 진입

[고2 2학기 ~ 고3 1학기]   수능 수준 훈련
  기출 유형별 완성, 시간 관리 도입
  → 목표: 국어·영어·사탐 2등급, 수학 3등급

[고3 2학기]               실전
  실모, 시간 배분, 오답 회수
  → 목표: 국어·영어·사탐 1등급
```

이건 **가설**이다. 실제 진행에 따라 계속 수정한다.
학생에게도 "이건 고정된 게 아니라 매달 조정한다"고 말한다.

## 3. 주간 계획 원칙

### 하루 핵심 목표는 최대 3개

시간이 많다고 목표를 10개 세우면 하나도 못 한다.
**핵심 목표 3개 + 그 안의 세부 세트**로 구성한다.

```markdown
## 화요일

### 핵심 1: 국어 — 문단 역할 태그 (60분)
- 독서 지문 2개, 문단마다 태그 붙이기
- 구조도 그리기
- 문제 10개

### 핵심 2: 수학 — 지수법칙 복구 (90분)
- 중3 지수 개념 확인 문제 10
- 고1 지수 기본 15
- 오답 정리

### 핵심 3: 영어 — 어휘 + 주어·동사 (45분)
- 신규 어휘 30
- 복습 큐 어휘
- 긴 문장 5개 뼈대 찾기

### 복습 큐 (필수, 20분)
python review_queue.py due
```

### 시간 블록 구조

집중력이 짧으므로 **긴 블록을 만들지 않는다.**

```
25분 집중 → 5분 휴식 → 25분 → 5분 → 25분 → 15분 휴식
```

한 과목을 3시간 연속하지 않는다. **과목을 섞는다.**

## 4. 과목별 시간 배분 (기본값)

서울대 인문 + 수학 제외 1등급 목표 기준.

| 과목 | 비중 | 비고 |
| --- | --- | --- |
| 국어 | 30% | 최우선. 가장 오래 걸리고 가장 중요 |
| 영어 | 20% | 90점 안정되면 → 15%로 축소 |
| 수학 | 20~25% | 초기 결손 복구기엔 35%까지 일시 상향 |
| 통합사회 | 15% | |
| 통합과학 | 10% | 과잉 투자 경계 |
| 한국사 | 5% | |

**이 비율은 성적이 들어오면 재계산한다.** 고정값이 아니다.

## 5. 진도 vs 복습 비율

| 시기 | 새 진도 | 복습 |
| --- | --- | --- |
| 기초 복구기 | 60% | 40% |
| 개념 완성기 | 50% | 50% |
| 실전기 | 30% | 70% |

**복습 비율을 지키지 않으면 배운 게 다 새어나간다.**
이 학생은 암기가 약하므로 복습 비율을 더 높게 잡는다.

## 6. 학습 로그

매일 끝에 3줄만 쓴다. 길면 안 쓴다.

```markdown
2026-07-29
- 한 것: 국어 지문 2개 / 수학 지수 25문제 / 영어 어휘 30
- 막힌 것: 음의 지수 (2⁻²를 -4로 착각)
- 내일 먼저 할 것: 음의 지수 재확인 후 로그 진입
```

**"막힌 것"이 가장 중요하다.** 이게 다음 날 계획의 재료다.

## 7. 성과 점검 주기

| 주기 | 확인 |
| --- | --- |
| 매일 | 복습 큐 완료 여부 |
| 매주 | 정답률 추이, 반복 오답 코드 |
| 매월 | 장기 기억 회상 테스트, 시간 배분 재조정 |
| 시험 후 | 과목별 오답 분류, 로드맵 수정 |

### 주간 점검 형식
```markdown
## 7월 4주차 점검

| 과목 | 목표 | 실제 | 정답률 |
| --- | --- | --- | --- |
| 국어 | 지문 10 | 8 | 62% |
| 수학 | 100문제 | 120 | 71% |
| 영어 | 어휘 200 | 200 | 회상 84% |

**반복 오답 코드:** `M`(조건 누락) 5회 ⚠️
→ 다음 주 최우선: 문제 조건 표시 절차 강제

**조정:** 국어 지문 목표를 10 → 8로 현실화. 대신 지문당 분석 깊이 상향.
```

## 8. 동기 관리 — 연설하지 않는다

이 학생은 빈 격려에 반응하지 않는다. 대신 **데이터를 보여준다.**

❌ "포기하지 마세요! 할 수 있어요!"
✅ "3주 전 이 유형 정답률 40%였습니다. 지금 71%입니다. 방향은 맞습니다."

### 슬럼프 신호와 대응

| 신호 | 대응 |
| --- | --- |
| 계획을 3일 연속 못 지킴 | 계획이 과했다. **분량을 줄인다** (의지 문제로 만들지 않는다) |
| 같은 과목만 계속 피함 | 그 과목의 난이도를 한 단계 낮춘다 |
| "해도 안 늘어요" | 과거 로그를 꺼내 실제 변화를 보여준다 |
| 성적이 안 오름 | 학습 방식을 점검한다 (읽기만 하고 회상 안 하는 경우가 대부분) |

### 성적이 안 오를 때 점검 순서
```
① 복습 큐를 실제로 돌리고 있나
② 문제를 풀고 오답 분류를 하고 있나
③ 이해 없이 진도만 나가고 있나
④ 기초 결손이 남아 있나
⑤ (마지막) 절대 학습량이 부족한가
```

**⑤를 먼저 의심하지 않는다.** 이 학생은 시간이 많다. 대개 ①~④가 원인이다.

## 9. 시험 기간 운영

### 내신 시험
2028 개편에서 내신은 5등급제다. 이 학생은 수능 비중이 크지만 내신도 버리지 않는다.

- 시험 3주 전: 수능 학습 60% / 내신 40%
- 시험 2주 전: 40% / 60%
- 시험 1주 전: 20% / 80%
- 시험 후 3일: **오답 전수 분석** ← 이걸 안 하면 시험이 낭비다

### 모의고사
- 시간 재고 푼다. 실제 시험 시간표대로
- 채점 후 **바로** 해설을 보지 않는다. 틀린 문제를 시간 무제한으로 다시 푼다
- 그래도 안 되면 그때 해설
- 오답을 코드로 분류해 `ERROR_LOG.md`에 기록

```
틀림 → 다시 풀어서 맞음  =  실수(X) 또는 시간(T)
틀림 → 다시 풀어도 틀림  =  개념(P/C) 또는 추론(L)
```

이 구분이 **모의고사에서 얻는 가장 큰 정보**다.

## 10. 학생에게 계획을 줄 때의 형식

계획도 20초 규칙을 지킨다.

```markdown
**오늘 3개:**
1. 국어 지문 2개 + 구조도 (60분)
2. 수학 지수 25문제 (90분)
3. 영어 어휘 30 + 복습 큐 (45분)

**지금 바로:** 복습 큐부터. `python review_queue.py due`

<details>
<summary>왜 이 순서인가</summary>
...
</details>
```

**"지금 바로"가 없는 계획은 실행되지 않는다.**
