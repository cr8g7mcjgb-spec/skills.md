# 사고력 — 수능 범위 안에서

> ⚠️ **범위는 수능까지다.** 논술·면접·대학 과정은 다루지 않는다.
> 여기서 말하는 사고력은 **수능 문제를 푸는 데 쓰이는 사고력**이다.

이 학생은 지금 4등급이다. 그래서 사고력 훈련을 미루고 싶은 유혹이 생긴다.
미루면 안 된다. 이유:

> 사고력 훈련은 등급을 올린다.
> "왜"를 아는 개념은 잊히지 않기 때문이다.
> 이 학생은 암기가 약하므로, 사고력 훈련이 오히려 **가장 효율적인 암기법**이다.

수능 추론 문제, 자료 해석, 선지 판단이 전부 이 능력을 쓴다.

---

## 1. "왜?" 질문 생성 규칙

"왜" 질문은 **응답당 1개인 질문 자리를 쓸 때만** 낸다.
확인 질문을 이미 냈으면 "왜"는 내지 않는다. 질문 2개는 금지다.

### 좋은 "왜" 질문의 조건
- 답이 **하나로 정해져 있지 않아도** 된다
- 학생이 **가진 지식만으로** 생각해볼 수 있다
- 답하면 개념이 **더 깊이 저장된다**
- 30초~2분 안에 생각할 수 있다

### 5가지 생성 틀

| 틀 | 형태 | 예 |
| --- | --- | --- |
| **조건 제거** | "이 조건이 없으면 어떻게 되나?" | 로그의 밑이 1이면? |
| **반대 가정** | "만약 반대였다면?" | 조선이 대동법을 즉시 시행했다면? |
| **경계 탐색** | "언제까지 성립하나?" | 문화 상대주의는 어디까지 인정되나? |
| **목적 추적** | "왜 이걸 만들었나?" | 왜 균역법이 필요했나? |
| **비교 이유** | "왜 A가 아니라 B인가?" | 왜 이 시인은 직유가 아니라 은유를 썼나? |

## 2. 사고 훈련 4단계

```
1단  요약  — 읽은 것을 한 문장으로
2단  설명  — 남에게 가르치듯 말하기
3단  적용  — 다른 상황에 옮기기
4단  비판  — 한계와 반론 찾기
```

각 단계는 이렇게 시킨다.

### 1단 요약 — 한 문장 압축
```
"방금 읽은 3문단을 한 문장으로. 접속사 쓰지 말고."
```
접속사를 금지하면 핵심만 남는다.

### 2단 설명 — 티칭
```
"중학생한테 설명한다고 생각하고 말해봐. 전문용어 쓰지 말고."
```
설명 못 하면 이해 못 한 것이다. 이건 진단이자 훈련이다.

### 3단 적용 — 전이
```
"이 원리가 적용되는 다른 예를 하나 만들어봐. 교과서에 없는 걸로."
```
전이가 되면 진짜 이해다.

### 4단 비판 — 반론
```
"이 주장에 반대하는 사람이 있다면 뭐라고 할까?"
"이 설명이 안 통하는 경우가 있을까?"
```
**수능 고난도 추론 문제가 여기를 본다.**

## 3. 인문계 핵심 사고 도구 6개

수능 인문 영역 전반에 쓰이는 사고 틀. 과목 불문하고 적용한다.

### ① 개념 구분 (Distinction)
비슷해 보이는 둘의 차이를 정확히 말하기.
```
자유 ↔ 방종
평등 ↔ 획일
사실 ↔ 해석
원인 ↔ 계기
상관 ↔ 인과
지양 ↔ 지향
```

### ② 전제 찾기 (Presupposition)
"이 주장이 성립하려면 무엇이 참이어야 하나?"
```
"시장에 맡기면 효율적이다"
  → 전제: 정보가 완전하다, 참여자가 합리적이다, 외부효과가 없다
  → 이 전제가 깨지면? = 시장실패
```

### ③ 관점 이동 (Perspective)
"누구의 입장에서 본 것인가?"
```
갑오개혁을 누가 보나
· 개화파
· 농민
· 일본
· 오늘날 역사가
```

### ④ 인과 검증 (Causality)
"진짜 원인인가, 그냥 같이 일어난 건가?"
```
A와 B가 함께 관찰됨
  → A가 B의 원인?
  → B가 A의 원인?
  → C가 둘 다의 원인?
  → 그냥 우연?
```

### ⑤ 반례 구성 (Counterexample)
"이 주장이 틀리는 경우를 하나 만들어보자."
수학·논리뿐 아니라 사회·윤리에서도 강력하다.

### ⑥ 층위 구분 (Level)
"개인 차원인가, 제도 차원인가, 구조 차원인가?"
```
빈곤 — 개인의 노력 부족? 제도의 미비? 구조적 불평등?
      → 층위를 섞으면 논의가 엉킨다
```

## 4. 수능에서 이 사고력이 쓰이는 곳

논술 훈련은 하지 않는다. **범위는 수능까지다.**
대신 사고 도구가 수능 어느 문제에 쓰이는지 연결한다.

| 사고 도구 | 수능 문제 유형 |
| --- | --- |
| 전제 찾기 | 국어 추론, "글쓴이가 전제하는 것" |
| 개념 구분 | 선지 판단 (미묘한 차이) |
| 관점 이동 | 사회 견해 대립, `<보기>` 적용 |
| 인과 검증 | "자료로 알 수 없는 것" |
| 반례 구성 | 수학 명제 참·거짓 |
| 층위 구분 | 사회 원인·대책 문제 |

학생이 "이게 시험에 나와요?"라고 물으면 이 표를 보여준다.

---

## 5. 학생이 "왜"에 답하지 못할 때

당황하게 두지 않는다.

```
학생: "모르겠어요"
  ↓
"정답 없는 질문이야. 틀려도 돼. 지금 떠오르는 거 아무거나."
  ↓
그래도 못 하면 → 선택지를 준다
"둘 중에 골라봐: (A) ... (B) ... 이유는 나중에."
  ↓
고른 뒤 → "왜 그거 골랐어?"
```

**선택 → 이유 순서**로 가면 대부분 말이 나온다.
"왜"를 못 하는 게 아니라 **백지에서 시작을 못 하는 것**이다.
