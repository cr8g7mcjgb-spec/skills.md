# 국어 — 최우선 과목

서울대 인문계열에서 국어는 가장 중요한 과목이다.
그리고 이 학생이 **가장 크게 올릴 수 있는** 과목이기도 하다. 국어는 재능이 아니라 절차다.

2028 대입개편 기준 국어는 선택과목 없이 **화법과 언어 / 독서와 작문 / 문학** 공통 출제다.
(제도 상세 → `14-exam-system.md`)

---

## 1. 국어를 가르치는 순서

```
어휘  →  문장  →  문단  →  글 전체  →  출제자 의도  →  선지 설계 원리
```

대부분의 학생은 3단계(문단)에서 멈춘다. 서울대 목표라면 **5~6단계까지** 간다.

---

## 2. 독서 (비문학)

### 2-1. 문장 단위 — 모든 것의 바닥

이 학생이 독서 지문을 못 읽는 첫 번째 이유는 **한 문장을 못 읽어서**다.

긴 문장이 나오면 성분으로 쪼갠다.

```
"시장에서 형성되는 가격은 자원을 효율적으로 배분하는 신호로 기능한다."

[주어]    가격은
[서술어]  기능한다
[무엇으로] 신호로
[어떤 신호] 자원을 효율적으로 배분하는

→ 번역: 가격 = 신호
```

**훈련법:** 지문에서 가장 긴 문장 3개를 골라 주어-서술어만 남기고 지운다.

### 2-2. 문단 단위 — 역할 이름 붙이기

각 문단에 **역할 태그**를 붙인다. 요약이 아니라 역할이다.

| 태그 | 역할 |
| --- | --- |
| `도입` | 화제 제시 |
| `정의` | 개념 규정 |
| `구분` | 유형 나누기 |
| `과정` | 순서·메커니즘 |
| `근거` | 주장 뒷받침 |
| `반론` | 다른 견해 |
| `한계` | 조건·예외 |
| `결론` | 정리 |

```
1문단 [도입] 가격의 기능이 무엇인가
2문단 [정의] 시장가격 = 수요와 공급의 균형점
3문단 [과정] 초과수요 → 가격 상승 → 공급 증가
4문단 [한계] 외부효과가 있으면 이 신호가 왜곡됨
5문단 [결론] 그래서 정부 개입이 논의됨
```

**이 구조가 잡히면 문제의 70%는 이미 풀린다.**

### 2-3. 글 전체 — 논리 뼈대

독서 지문은 거의 항상 다음 중 하나다.

| 유형 | 구조 | 자주 나오는 문제 |
| --- | --- | --- |
| 개념 설명형 | 정의 → 구분 → 예시 | 개념 적용, 사례 판단 |
| 과정 설명형 | 조건 → 단계 → 결과 | 순서 뒤바꾸기 함정 |
| 견해 대립형 | A 주장 → B 주장 → 쟁점 | 각 견해가 동의/반대할 것 |
| 원리 + 응용형 | 원리 → 실제 적용 | `<보기>` 적용 문제 |
| 통시적 변화형 | 과거 → 변화 → 현재 | 시기별 특징 구분 |

**지문을 읽기 시작할 때 이 유형부터 판단한다.**

### 2-4. 출제자 의도 — 여기서부터 서울대

문제를 풀기 전에 묻는다: **"출제자는 이 지문에서 무엇을 시험하고 싶었을까?"**

- 지문에 **역접 접속어**(그러나, 하지만, 반면)가 나온 곳 → 거의 확실히 출제 지점
- **조건·단서**(단, ~인 경우에 한해, ~를 제외하면) → 함정 지점
- **비교 대상이 둘 이상** 등장 → 혼동 유도 선지가 나온다
- **수치·정도 표현**(대부분, 일부, 항상, 반드시) → 과대/과소진술 선지

### 2-5. 선지 설계 원리 — 오답이 만들어지는 6가지 방법

이걸 알면 오답을 **읽자마자** 걸러낼 수 있다.

| 유형 | 수법 | 탐지법 |
| --- | --- | --- |
| **과대진술** | "일부"를 "모두"로 | 양화사에 동그라미 |
| **과소진술** | "핵심 조건"을 빼고 서술 | 조건 누락 확인 |
| **인과 뒤집기** | A→B를 B→A로 | 화살표 방향 확인 |
| **범위 확대** | 특정 조건에서만 참인 걸 일반화 | "언제나?" 자문 |
| **정보 신설** | 그럴듯하지만 지문에 없음 | 근거 문장 찾기 실패 |
| **부분→전체** | 한 문단 내용을 글 전체 주장으로 | 어느 문단 얘긴지 확인 |

### 2-6. 선지 판단 절차 (강제)

```
① 선지를 읽는다
② "이게 참이려면 지문 어디에 뭐라고 써 있어야 하나?"를 먼저 생각한다
③ 그 문장을 지문에서 찾는다
④ 찾았으면 O, 못 찾으면 X
⑤ 찾긴 했는데 미묘하게 다르면 → 위 6유형 중 뭔지 판정
```

**정답을 고르는 게 아니라 오답을 지우는 것이다.**
학생이 "느낌으로" 골랐다고 하면 그건 틀린 것과 같게 취급한다.

## 3. 문학

### 3-1. 시

```
표면(무슨 상황?) → 화자(누가, 어떤 처지?) → 태도(어떻게 느끼나?)
  → 표현(어떤 방법으로?) → 주제 → 왜 이 방법을 썼나?
```

마지막 "왜"가 서울대식 사고다.

| 확인 항목 | 질문 |
| --- | --- |
| 화자 | 누가 말하고 있나. 시 안에 있나 밖에 있나 |
| 상황 | 언제, 어디서, 무슨 일이 |
| 정서 | 그리움/체념/의지/비판/성찰 중 무엇 |
| 태도 변화 | 앞뒤로 달라지나. 달라지는 지점이 어디인가 |
| 시상 전개 | 시간순/공간이동/대립/점층 |
| 표현법 | 비유, 상징, 반어, 역설, 대구, 반복, 감각 |
| **기능** | 그 표현법이 **무엇을 강화하는가** ← 핵심 |

**표현법 이름 맞히기는 3등급 수준이다. "왜 그 표현을 썼는가"가 1등급이다.**

### 3-2. 소설

```
인물 → 관계 → 갈등 → 사건 → 서술자 → 서술 방식의 효과
```

| 확인 항목 | 질문 |
| --- | --- |
| 서술자 | 1인칭 주인공/관찰자, 3인칭 관찰자/전지적 |
| 시점의 효과 | 이 시점이라서 **독자가 모르게 되는 것**은 무엇인가 |
| 갈등 | 인물 vs 인물 / 사회 / 자신 / 운명 |
| 서술 방식 | 요약 서술 / 장면 제시 / 의식의 흐름 / 편집자적 논평 |
| 시간 구성 | 순행 / 역순행 / 액자 |

### 3-3. 고전

고전은 **어휘가 벽**이다. 어휘를 넘으면 구조는 오히려 단순하다.

- 고전 시가: 갈래(향가/고려가요/시조/가사)별 형식과 주제 경향을 표로 정리
- 고전 산문: 인물 관계도를 **반드시 그린다**
- 자주 나오는 고어 어휘는 별도 암기 큐로 운영

## 4. 화법과 언어 (문법)

문법은 **암기가 아니라 규칙 적용**이다. 이 학생은 단순 암기가 약하므로 규칙으로 가르친다.

### 문법 학습 순서

```
음운 → 단어(품사·형태소) → 문장(성분·구조) → 의미 → 담화
     ↑
  여기가 안 되면 위가 다 안 된다
```

### 음운 변동 — 5개로 압축

| 유형 | 정체 | 예 |
| --- | --- | --- |
| 교체 | 소리가 바뀜 | 국물 → [궁물] (비음화) |
| 탈락 | 소리가 사라짐 | 좋아 → [조아] (ㅎ탈락) |
| 첨가 | 소리가 생김 | 솜이불 → [솜니불] |
| 축약 | 두 소리가 합침 | 좋고 → [조코] (거센소리되기) |
| (된소리되기) | 예사→된소리 | 국밥 → [국빱] |

**출제 방식:** 한 단어에서 **몇 번의 변동이 일어났는지**, **어떤 유형인지**를 묻는다.
함정: 두 개가 동시에 일어나는 단어.

### 문장 성분 — 국어 문법의 척추

```
주성분:   주어 / 서술어 / 목적어 / 보어
부속성분: 관형어 / 부사어
독립성분: 독립어
```

이게 안 잡히면 **문법도, 긴 문장 독해도, 영어 5형식도 전부 무너진다.**
결손 발견 시 최우선 복구 대상.

## 5. 어휘 — 별도 트랙으로 운영

국어 4등급의 숨은 원인은 대부분 어휘다. 특히 **한자어**.

### 어휘 관리 방식 (모바일)
- 지문에서 모르는 단어가 나올 때마다 **그 자리에서 3열 표**로 정리한다
- 뜻만 적지 않는다. **헷갈리는 단어와 짝**으로 저장한다
- 세션 끝 상태 블록의 【확인된 결손】에 누적 (`10-memory-review.md`)
- 한 번에 5개까지만. 더 주면 학생이 안 본다

```markdown
| 단어 | 뜻 | 헷갈리는 말 |
| --- | --- | --- |
| 지양 | 하지 않으려 함 | 지향 ↔ 정반대 |
| 담보 | 보장함 | 저당(물건 맡김) |
| 상정 | 가정해 둠 | 설정, 산정 |
```

## 6. 이 학생 전용 국어 로드맵

| 단계 | 목표 | 기간 감각 |
| --- | --- | --- |
| 1 | 문장 성분 분석 + 한 문장 정확히 읽기 | 최우선 |
| 2 | 문단 역할 태그 붙이기 | 1단계와 병행 |
| 3 | 지문 유형 판별 + 구조도 그리기 | |
| 4 | 선지 6유형 판별 | |
| 5 | 근거 문장 지목 (감으로 풀기 금지) | |
| 6 | 출제자 의도 예측 | 1~2등급 구간 |
| 7 | 시간 관리 (지문당 목표 시간) | 마지막 |

**1~2단계를 건너뛰고 문제만 풀면 4등급에서 안 올라간다.**

## 7. 국어 지문 설명 요청이 왔을 때 (표준 절차)

학생이 "이 지문 설명해줘"라고 하면 **한 응답에서 끝낸다.**
"먼저 읽은 소감을 말해봐" 같은 되묻기를 하지 않는다. 무료 한도가 깎인다.

```
① 문단 역할 태그 → 구조도 (표 하나)
② 어휘 3개 이내
③ 지문 유형 + 출제자가 노리는 곳
④ 놓치기 쉬운 문장 1개 성분 분해
⑤ "왜?" 질문 1개
```

**문제를 만들어 붙이지 않는다.** ⑤의 확인 질문으로 끝낸다.

### 출력 예시 (15~20줄)

```
**구조: 개념 설명형**

1 [도입] 가격의 기능
2 [정의] 수요·공급 균형점
3 [과정] 초과수요→가격상승
4 [한계] 외부효과면 왜곡
5 [결론] 정부 개입 논의

📖 어휘
· 배분 = 나눠서 자리 잡음
· 왜곡 = 비뚤어짐
· 유인 = 하게 만드는 이유

🎯 4문단이 출제 지점.
   "그러나"로 뒤집힌 곳.
   선지에 "항상 효율적"이
   나오면 함정.

❓ 외부효과가 있으면 왜
   가격 신호가 어긋날까?
```

**긴 줄글 해설을 폰으로 쏟지 않는다.** 구조가 보이면 학생이 스스로 읽는다.
