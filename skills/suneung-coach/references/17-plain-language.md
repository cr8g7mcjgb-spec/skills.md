# 쉬운 말 규칙 — 기준은 초등 5학년

## 0. 실제 수준

학생이 직접 말했다: **"값이 갈린다도 무슨 뜻인지 모르겠다."**

이게 진짜 수준이다. 낮춰 잡은 게 아니라 **사실**이다.

```
"극한값이 존재하지 않는다"  ← 당연히 모름
"값이 갈린다"              ← 이것도 모름  ← 여기가 문제
"답이 두 개 나와"          ← 이제 안다
```

**두 번째 줄이 함정이다.** 쉬워 보여서 그냥 쓴다. 그런데 학생은 모른다.

### 기준

> **초등학교 5학년이 학교 밖에서 쓰는 말인가?**

아니면 바꾼다. 이게 유일한 기준이다.

---

## 1. 가장 중요한 규칙 — 추상어 대신 구체적으로

짧게 쓰려다가 추상어를 쓰게 된다. **그게 가장 큰 함정이다.**

```
❌ 값이 갈린다          (4글자. 짧지만 모름)

✅ 왼쪽에서 다가가면 3
   오른쪽에서 다가가면 5
   답이 두 개라 하나로 못 정해   (3줄. 길지만 안다)
```

> **추상어 한 단어보다 구체적인 세 문장이 낫다.**
> 길어지는 건 괜찮다. 못 알아듣는 게 문제다.

이건 "15~20줄" 규칙보다 위다. **줄 수를 맞추려고 추상어를 쓰면 안 된다.**

### 구체적으로 만드는 3가지 방법

| 방법 | 예 |
| --- | --- |
| **숫자를 직접 보여준다** | "값이 커진다" → "3, 6, 12, 24…" |
| **눈에 보이는 걸로 바꾼다** | "배분된다" → "나눠 갖는다" |
| **누가 뭘 하는지 쓴다** | "왜곡된다" → "가격이 이상해진다" |

---

## 2. ⚠️ 쉬워 보이는데 안 쉬운 말

**이 목록이 이 파일의 핵심이다.**
학교에서만 쓰는 말인데, 어른은 일상어로 착각한다.

### 전 과목 공통

| 안 쓴다 | 쓴다 |
| --- | --- |
| 값 | 답 / 숫자 |
| 갈린다 | 두 개로 나뉜다 / 달라진다 |
| 구한다 | 찾는다 / 계산한다 |
| 성립한다 | 맞다 / 된다 |
| 대응한다 | 짝이 된다 |
| 범위 | 어디부터 어디까지 |
| 조건 | 단서 / 지켜야 할 것 |
| 경우 | 때 / 상황 |
| 요소 | 부분 / 하나하나 |
| 관계 | 어떻게 이어지는지 |
| 변화 | 바뀌는 것 |
| 상태 | 지금 어떤지 |
| 특성 | 특징 / 어떤 점 |
| 구조 | 어떻게 짜였는지 |
| 형태 | 모양 |
| 방식 | 방법 |
| 기준 | 재는 잣대 |
| 대상 | 무엇을 |
| 적용한다 | 갖다 쓴다 |
| 파악한다 | 알아낸다 |
| 판단한다 | 정한다 |
| 도출한다 | 끌어낸다 |
| 해당한다 | ~에 들어간다 |

### 어른이 가장 자주 흘리는 말

```
"~에 대하여"   → "~는"
"~을 통하여"   → "~로"
"~의 경우"     → "~는 / ~때는"
"~함으로써"    → "~해서"
"~에 있어서"   → "~에서"
```

이런 말은 뜻이 없는데 문장만 어렵게 만든다. **전부 뺀다.**

## 3. 어려운 말 → 쉬운 말 (과목별)

### 국어

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 논지 | 제일 하고 싶은 말 |
| 근거 | 왜 그런지 대는 것 |
| 견해가 나뉜다 | 사람마다 생각이 다르다 |
| 전제 | 미리 깔고 가는 것 |
| 함의 | 속뜻 |
| 형상화 | 그림처럼 보여줌 |
| 부각 | 눈에 띄게 함 |
| 환기 | 떠올리게 함 |
| 서술 방식 | 어떻게 썼는지 |
| 시상 전개 | 시가 흘러가는 순서 |

### 수학

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 임의의 | 아무거나 |
| 만족한다 | 조건에 맞는다 |
| 수렴한다 | 한 숫자에 점점 가까워진다 |
| 상수 | 안 바뀌는 숫자 |
| 변수 | 바뀌는 숫자 |
| 실근 | 진짜 답 |
| 정의된다 | 쓸 수 있다 |
| 최댓값 | 제일 큰 답 |

### 사회

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 배분 | 나눠 갖기 |
| 왜곡 | 이상해짐 / 비뚤어짐 |
| 유인 | 하고 싶게 만드는 것 |
| 상충 | 서로 부딪힘 |
| 저해 | 방해 |
| 제고 | 높임 |
| 개입 | 끼어듦 |
| 형평성 | 공평함 |

### 과학

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 전환된다 | 모양이 바뀐다 |
| 보존된다 | 없어지지 않는다 |
| 생성된다 | 새로 생긴다 |
| 비례한다 | 같이 커진다 |
| 반비례한다 | 하나 커지면 하나 작아진다 |
| 통제한다 | 안 바뀌게 붙잡는다 |

## 4. 문장 규칙

| 규칙 | 예 |
| --- | --- |
| 한 문장 = 한 가지만 | 두 가지면 자른다 |
| 20자 안쪽 | 넘으면 자른다 |
| 주어를 쓴다 | "이는" ❌ → "이 방법은" ✅ |
| 피동형 금지 | "여겨진다" ❌ → "~라고 본다" ✅ |
| 명사 2개까지 | "가격 결정 구조" ❌ |

### 명사 뭉치가 가장 큰 벽

명사를 붙이면 갑자기 어려워진다. **동사로 푼다.**

```
❌ 시장 가격 결정 구조
✅ 시장에서 가격이 어떻게 정해지는지

❌ 문학 작품 표현 방식 파악
✅ 작가가 어떤 방법으로 썼는지 찾기

❌ 자료 해석 능력 향상
✅ 표랑 그래프를 잘 읽게 되기
```

## 5. 3단 낮추기 — 실제로 이렇게 한다

한 번에 안 내려간다. **두 번 내린다.**

### 예 1 — 수학

```
1단 (교과서)
"함수의 극한값이 존재하지 않는다"

2단 (아직 어려움)
"값이 갈린다"          ← 학생이 모르는 지점

3단 (된다)
"왼쪽에서 다가가면 3
 오른쪽에서 다가가면 5
 답이 두 개라 하나로 못 정해"
```

### 예 2 — 사회

```
1단 "시장에서 자원이 효율적으로 배분된다"

2단 "자원이 잘 나눠진다"     ← 아직 모름

3단 "필요한 사람한테
     물건이 잘 돌아간다"
```

### 예 3 — 국어

```
1단 "글쓴이의 논지를 파악한다"

2단 "글의 주장을 안다"       ← 아직 모름

3단 "글쓴이가 제일 하고 싶은
     말이 뭔지 찾는 것"
```

### 예 4 — 과학

```
1단 "에너지가 전환된다"

2단 "에너지가 바뀐다"        ← 아직 모름

3단 "에너지가 없어지는 게 아니라
     모양만 바뀐다.
     전기 → 빛 처럼"
```

**2단에서 멈추면 안 된다.** 지금까지 코치가 거기서 멈췄다.

## 6. 그다음에 시험 말을 붙인다

쉬운 말로 끝내면 시험지에서 막힌다. **반드시 되돌려 준다.**

```
✅ 왼쪽에서 다가가면 3
   오른쪽에서 다가가면 5
   답이 두 개라 하나로 못 정해

📖 시험에선 이렇게 나와
   "극한값이 존재하지 않는다"
   = 방금 그 얘기
```

**"= 방금 그 얘기"** 이 한마디가 다리를 놓는다.
상세 → `21-exam-language.md`

## 8. 학생이 "무슨 말인지 모르겠어" 할 때

먼저 묻는다. 이거 하나만.

```
"어느 단어가 걸려? 그것만."
```

단어를 알려주면 → **그 단어만** 3단으로 내려서 다시.
개념 자체를 모르면 → 재설명 사다리 (`00-response-protocol.md` §4).

**둘을 섞지 않는다.** 단어 문제인데 개념을 다시 설명하면 또 못 알아듣는다.

### 학생이 모른다고 안 할 수도 있다

이 학생은 모른다고 말 안 하고 그냥 넘어갈 수 있다.
그래서 **어려운 말을 썼다 싶으면 먼저 풀어준다.**

```
"극한값" (= 가까워지는 답)
```

**괄호로 그 자리에서 푸는 게 가장 싸다.**
