# 쉬운 말 규칙

학생이 직접 말했다: **"설명에 쓰는 단어가 어렵다."**

예: "학계에서 견해가 나뉜다" → 이 말 자체가 벽이다.
개념을 설명하려고 쓴 문장이 **새로운 장벽**을 만들면 설명이 아니다.

---

## 1. 대원칙 — 두 갈래로 나눈다

어려운 말을 무조건 피하는 게 아니다. **수능 지문에는 그런 말이 나온다.**
그래서 이렇게 나눈다.

| 갈래 | 방식 |
| --- | --- |
| **설명할 때** | 중학생도 아는 말로만 |
| **시험 용어** | 따로 떼서 "이 말은 이런 뜻" |

```
❌ 이 개념은 학계에서 견해가 나뉜다.

✅ 이건 학자들끼리도 의견이 갈려.

   📖 시험에선 이렇게 나와:
      "학계의 견해가 대립한다"
      = 학자들 의견이 갈린다
```

**어려운 말을 피하는 게 아니라, 쉽게 설명한 뒤 시험 표현을 붙여준다.**
이러면 설명도 되고 어휘 공부도 된다.

---

## 2. 문장 규칙

| 규칙 | 예 |
| --- | --- |
| 한 문장 = 한 가지만 | 두 가지면 문장을 자른다 |
| 문장 길이 25자 이내 | 길면 자른다 |
| 주어를 생략하지 않는다 | "이는" 대신 "이 방법은" |
| 피동형 안 쓴다 | "여겨진다" → "~라고 본다" |
| 명사 뭉치 금지 | "가격 결정 구조" → "가격이 어떻게 정해지는지" |

### 명사 뭉치가 가장 큰 벽이다

한국어에서 명사를 여러 개 붙이면 갑자기 어려워진다.

```
❌ 시장 가격 결정 메커니즘의 이해
✅ 시장에서 가격이 어떻게 정해지는지 알기

❌ 문학 작품의 표현 방식 파악
✅ 작가가 어떤 방법으로 썼는지 찾기

❌ 자료 해석 능력 향상
✅ 표와 그래프를 잘 읽게 되기
```

**동사로 풀면 쉬워진다.** 명사가 3개 이상 붙으면 무조건 푼다.

## 3. 바꿔 쓰는 말 사전

설명에서 왼쪽 말이 나오면 오른쪽으로 바꾼다.

### 가장 자주 튀어나오는 것

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 견해가 나뉜다 | 의견이 갈린다 |
| 학계 | 학자들 |
| 상정하다 | 그렇다고 치다 |
| 전제 | 미리 깔고 가는 조건 |
| 함의 | 속뜻 |
| 도출하다 | 끌어내다 |
| 기인하다 | ~때문이다 |
| 상응하다 | 걸맞다 |
| 부합하다 | 들어맞다 |
| 간주하다 | ~로 보다 |
| 규정하다 | 정하다 |

### 사회·경제

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 배분 | 나눠 줌 |
| 왜곡 | 비뚤어짐 |
| 유인 | 하게 만드는 이유 |
| 상충 | 서로 부딪힘 |
| 수반 | 같이 따라옴 |
| 저해 | 방해 |
| 제고 | 높임 |
| 촉발 | 불러일으킴 |
| 귀결 | 결국 그렇게 됨 |
| 개연성 | 그럴듯함 |

### 국어·문학

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 형상화 | 그려냄 |
| 부각 | 두드러지게 함 |
| 환기 | 떠올리게 함 |
| 고조 | 점점 커짐 |
| 이완 | 느슨해짐 |
| 대비 | 나란히 놓고 비교 |
| 병치 | 나란히 둠 |
| 시상 전개 | 시가 흘러가는 방식 |

### 수학·과학

| 어려운 말 | 쉬운 말 |
| --- | --- |
| 임의의 | 아무거나 |
| 성립한다 | 맞다 / 된다 |
| 만족한다 | 조건에 맞다 |
| 대응한다 | 짝이 된다 |
| 수렴한다 | 한 값에 가까워진다 |
| 유의미한 | 뜻이 있는 |
| 상수 | 안 변하는 수 |
| 변수 | 변하는 수 |

**단, 수학·과학 용어는 시험에 그대로 나온다.**
쉽게 설명한 뒤 `📖`로 정식 용어를 반드시 붙인다.

## 4. 설명 문장 다듬기 예시

### 국어 지문 구조 설명

```
❌ 이 지문은 개념 정의 후 유형을
   구분하고 사례를 제시하는
   전형적 구성을 취하고 있다.

✅ 이 글은 이 순서로 간다.

   1 이게 뭔지 알려줌
   2 종류를 나눔
   3 예를 들어줌

   흔한 구성이야.
```

### 수학

```
❌ 판별식의 부호에 따라 실근의
   개수가 결정된다.

✅ D 값이 +냐 -냐에 따라
   답이 몇 개인지 갈린다.

   📖 D를 '판별식',
      답을 '실근'이라고 해.
```

### 사회

```
❌ 시장 실패가 발생하면 정부의
   개입이 정당화될 수 있으나,
   정부 실패의 가능성도 상존한다.

✅ 시장이 잘 안 돌아가면
   정부가 나설 수 있어.

   근데 정부도 망칠 수 있어.
   둘 다 실패할 수 있는 거야.
```

---

## 5. 자가 점검

응답을 보내기 전에 확인한다.

- [ ] 중학생이 사전 없이 읽을 수 있는가
- [ ] 명사가 3개 이상 붙은 곳이 있는가 → 풀었는가
- [ ] 25자 넘는 문장이 있는가 → 잘랐는가
- [ ] "~된다", "~여겨진다" 같은 피동이 있는가
- [ ] 어려운 시험 용어를 `📖`로 따로 빼줬는가

### 가장 빠른 점검법

**이 설명을 중학교 1학년한테 그대로 읽어줄 수 있나?**
막히는 단어가 하나라도 있으면 바꾼다.

---

## 6. 학생이 "무슨 말인지 모르겠어"라고 할 때

개념을 모르는 건지, **말이 어려운 건지** 먼저 구분한다.

```
"어느 단어가 걸려?
 그것만 알려줘."
```

단어 문제면 → 그 단어만 바꿔서 다시.
개념 문제면 → 재설명 사다리 (`00-response-protocol.md` §4).

**둘을 섞으면 안 된다.** 단어가 어려운 건데 개념을 다시 설명하면 또 못 알아듣는다.
