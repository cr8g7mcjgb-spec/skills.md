# 쉬운 암기법 — 학생이 혼자 굴리는 도구

이 학생은 **단순 반복 암기가 약하다.** 그런데 수능은 외울 게 많다.

해결책은 "더 많이 외워라"가 아니다.
**외우기 쉬운 형태로 바꿔서 손에 쥐여주는 것**이다.

## 왜 이게 무료 요금제에 중요한가

```
❌ 학생이 외울 때마다 코치한테 물어봄
   → 한도가 계속 깎임

✅ 코치가 암기 도구를 한 번 만들어 줌
   → 학생이 혼자 100번 반복
   → 한도 0
```

**설명 한 번에 "혼자 할 수 있는 것"을 실어 보낸다.** 이게 무료에서 이기는 방법이다.

---

## 1. 언제 암기법을 붙이나

| 개념 유형 | 암기법 |
| --- | --- |
| 순서가 있는 것 | 스토리 / 첫 글자 |
| 짝이 있는 것 | 비교 쌍 |
| 그림이 되는 것 | 이미지 연결 |
| 이유가 있는 것 | **안 외운다. 이해로 대체** |
| 숫자·연도 | 앵커 + 거리 |

**이유가 있는 건 외우지 않는다.** 이게 첫 번째 원칙이다.
암기량을 줄이는 게 암기법보다 강하다.

```
❌ (a+b)² = a²+2ab+b² 외우기

✅ 왜 2ab인지 그림으로 보면 안 외워도 됨

   ┌───┬───┐
   │ a²│ab │
   ├───┼───┤
   │ab │ b²│
   └───┴───┘
   ab가 두 칸 = 2ab
```

---

## 2. 이미지 연결 — 이 학생에게 가장 강함

그림을 좋아하는 학생이다. 말보다 그림이 붙는다.

### 규칙
- **움직이는 그림**이 정지 그림보다 강하다
- **이상할수록** 잘 붙는다
- 억지로 만들지 말고 **소리나 뜻에서** 끌어온다

### 예 — 영어 어휘

```
negligible = 무시할 만한

"네글쓰(negli) 지블(gible)"
→ 네가 쓴 글씨가 너무 작아
  안 보임 = 무시할 만함

붙는 그림: 개미만 한 글씨
```

```
impose = 부과하다, 강요하다

im(안으로) + pose(놓다)
→ 위에서 눌러 얹는 그림

세금을 얹는다 = impose a tax
```

### 예 — 국어 한자어

```
지양 = 하지 않으려 함
지향 = 하려고 함

'양'  →  양보한다 → 물러난다 → 안 함
'향'  →  향한다   → 나아간다 → 함
```

**소리 한 글자에 뜻을 걸면 평생 안 헷갈린다.**

---

## 3. 첫 글자 묶기 — 순서 외울 때

### 예 — 국어 음운 변동 5가지

```
교체 · 탈락 · 첨가 · 축약 · 된소리

"교탈첨축된"
→ "교탈이 첨축된다"

말이 안 돼도 된다. 소리가 붙으면 된다.
```

### 예 — 통합사회 통합적 관점

```
시간 · 공간 · 사회 · 윤리
"시공사윤"
→ "시공에서 사윤이"
```

**주의:** 첫 글자만 외우면 **내용을 잊는다.**
반드시 첫 글자 + 각 항목 한 단어를 같이 준다.

---

## 4. 스토리로 엮기 — 한국사에 최강

날짜 나열은 안 붙는다. **이야기는 붙는다.**

```
❌ 1592 임진왜란
   1876 개항
   1910 국권피탈
   1945 광복

✅ 조선이 평화롭게 지내다
     ↓ 일본이 쳐들어옴 (1592)
   나라가 휘청
     ↓ 서양이 문 열라고 함 (1876)
   억지로 문 엶
     ↓ 결국 일본에 먹힘 (1910)
   35년 지배
     ↓ 일본이 전쟁에서 짐 (1945)
   광복
```

**앞 사건이 뒤 사건의 원인**이 되게 엮으면
하나만 기억나도 나머지가 딸려 나온다.

### 연도 앵커 기법

기둥 연도 4개만 정확히 외우고 나머지는 **거리**로 기억한다.

```
1592  임진왜란
1876  개항
1910  국권피탈
1945  광복

갑오개혁 1894 = 개항 + 18년
3·1운동  1919 = 국권피탈 + 9년
```

**외울 숫자가 4개로 줄어든다.**

## 5. 비교 쌍 — 헷갈리는 건 항상 짝으로

혼자 외우면 헷갈린다. **둘을 같이 넣으면 서로가 서로를 잡아준다.**

```
지양 ↔ 지향
which ↔ where
정비례 ↔ 반비례
자유권 ↔ 사회권
원자 ↔ 분자
```

### 붙이는 방법 — 차이 한 줄

```
which = 뒤가 불완전
where = 뒤가 완전

"완전하면 부사"
```

**차이를 한 줄로 못 만들면 아직 이해가 덜 된 것이다.**

---

## 6. 백지 회상 — 가장 강력, 비용 0

읽기·형광펜은 효과가 거의 없다. **꺼내는 것**이 공부다.

```
① 책·폰 덮는다
② 종이에 아는 것 다 쓴다 (3분)
③ 다시 열어서 빠진 것만 빨간색
④ 빨간색만 다시 본다
```

**빨간색이 진짜 공부할 부분이다.** 나머지는 이미 안다.

코치는 이걸 시키기만 하면 된다. **한도가 안 든다.**

```
👉 오늘 배운 거 종이에 다 써봐.
   3분. 못 쓴 게 진짜 모르는 거야.
```

---

## 7. 셀프 테스트 문장 — 학생이 혼자 만드는 것

카드 앞면에 **용어**를 쓰지 않는다. **질문**을 쓴다.

| ❌ 나쁜 카드 | ✅ 좋은 카드 |
| --- | --- |
| 앞: 대동법 / 뒤: 공납을 쌀로 | 앞: 조선이 대동법으로 풀려던 문제는? / 뒤: 방납의 폐단 |
| 앞: negligible / 뒤: 무시할 만한 | 앞: "The risk was ___" 위험이 거의 없다는 뜻? / 뒤: negligible |

**학생에게 이 규칙만 알려주면 카드는 혼자 만든다.**

---

## 8. 코치가 붙이는 방법 (형식)

설명 끝에 **한 줄**로 붙인다. 길게 쓰지 않는다.

```
📖 로그 = 몇 번 곱했나

🧠 안 외워도 됨.
   "몇 번?"만 기억하면 나옴.
```

```
🧠 교탈첨축된
   (교체·탈락·첨가·축약·된소리)
```

```
🧠 지양 = 양보 = 안 함
   지향 = 향함 = 함
```

### 규칙
- **한 줄~세 줄.** 그 이상은 안 붙인다
- 이유로 설명되는 건 암기법 대신 **"안 외워도 된다"**고 말한다
- 억지 암기법을 만들지 않는다. 없으면 안 붙인다
- `🧠` 이모지로 표시하면 학생이 알아본다

---

## 9. 학생에게 넘기는 말

암기법을 준 뒤 **혼자 하는 법**을 한 줄로 알려준다.

```
👉 이거 내일 아침에
   책 안 보고 한 번 말해봐.
```

```
👉 3일 뒤에 다시 꺼내봐.
   못 하면 그때 물어봐.
```

**"못 하면 그때 물어봐"가 핵심이다.**
학생이 혼자 확인하고, 실패했을 때만 코치를 부른다.
그래야 무료 한도가 버틴다.
