# 암기 — 효과 순서대로

이 학생은 단순 반복 암기가 약하다. 그래서 **효과 있는 방법만** 쓴다.

## 효과 순위

학습 연구에서 반복 검증된 순서다. 위에서부터 쓴다.

| 순위 | 방법 | 왜 강한가 |
| --- | --- | --- |
| 1 | **인출 연습** (꺼내보기) | 꺼내는 행위 자체가 기억을 만든다 |
| 2 | **간격 두고 반복** | 잊을 만할 때 꺼내면 더 단단해진다 |
| 3 | **자기 설명** | 왜 그런지 말하면 구조로 저장된다 |
| 4 | **섞어 풀기** | 구분하는 힘이 생긴다 |
| 5 | 구체적 사례 + 그림 | 추상적인 걸 붙잡을 손잡이 |
| 6 | 두문자·소리연상 | **효과 낮음.** 아래 조건에서만 |

**1~3번이 나머지를 다 합친 것보다 강하다.**

---

## ⛔ 효과 없는데 열심히 한 것처럼 느껴지는 것

학생이 시간을 가장 많이 낭비하는 지점이다. **발견하면 바로 말해준다.**

| 하지 마라 | 왜 |
| --- | --- |
| 다시 읽기 | 눈에 익을 뿐, 꺼낼 수 없다 |
| 밑줄·형광펜 | 칠하는 동안 생각을 안 한다 |
| 필기 옮겨 쓰기 | 손만 움직인다 |
| 요약본 반복해 보기 | 위와 같다 |
| 몰아서 하루에 다 | 다음 날 사라진다 |

```
"아는 것 같은데 못 쓰겠어"
 → 다시 읽기만 한 것

"봤을 땐 알겠는데
 시험지에선 안 나와"
 → 꺼내본 적이 없는 것
```

**"익숙함"과 "아는 것"은 다르다.** 학생은 이 둘을 구분하지 못한다.

---

## 1위. 인출 연습 — 가장 강하고 비용 0

책을 덮고 **꺼낸다.** 이게 전부다.

```
읽기 → 덮기 → 백지에 쓰기 → 확인 → 빠진 것만 다시
```

### 코치가 시키는 방법

```
👉 지금 폰 내리고,
   방금 배운 거 소리 내서 말해봐.
   막히는 데가 진짜 모르는 곳이야.
```

**"막히는 데가 진짜 모르는 곳"** — 이 말이 핵심이다.
학생은 막히는 걸 실패로 느끼는데, 실은 **진단 성공**이다.

### 왜 강한가

```
읽기    = 정보를 넣는다  → 약함
꺼내기  = 길을 만든다    → 강함

시험장에서 하는 건 '꺼내기'다.
연습도 꺼내기로 해야 한다.
```

### 실제 형태

| 상황 | 시키는 말 |
| --- | --- |
| 개념 배운 직후 | "안 보고 한 문장으로 말해봐" |
| 자습 중 | "한 단원 끝나면 백지에 다 써봐" |
| 영어 단어 | "뜻 가리고 단어만 보기" |
| 한국사 | "연표 안 보고 순서 말하기" |
| 문법 | "규칙을 예시로 설명하기" |

---

## 2위. 간격 두고 반복

같은 시간을 써도 **나눠 쓰면 훨씬 오래 남는다.**

```
❌ 하루에 3시간 몰아서
✅ 20분씩 여러 날에 나눠서

시간은 같은데 결과가 다르다
```

### 간격

```
당일 → 1일 → 3일 → 7일 → 14일 → 45일
```

**잊을 만할 때 꺼내는 게 핵심**이다. 너무 자주 보면 효과가 떨어진다.
"아직 기억나는데?" 싶을 때가 오히려 이른 것이다.

### 코치가 하는 일

날짜만 알려주면 된다. 그다음은 학생이 혼자 한다.

```
👉 이거 3일 뒤에 다시 꺼내봐.
   못 하면 그때 물어봐.
```

**"못 하면 그때"가 중요하다.** 매번 코치를 부르지 않게 만든다.

---

## 3위. 자기 설명 — 이 학생에게 특히 유효

암기가 약한 학생일수록 **이해로 대체**하는 게 유리하다.
이해한 건 잊어도 다시 만들 수 있다.

### 세 가지 질문

```
① 왜 그런데?
② 이거 없으면 어떻게 돼?
③ 이거랑 저거 뭐가 달라?
```

이 셋을 학생이 스스로 묻게 만든다.

### 예 — 외울 것을 없애버린다

```
❌ (a+b)² = a²+2ab+b² 외우기

✅ 왜 2ab인지 보면 안 외워도 됨

   ┌───┬───┐
   │ a²│ab │
   ├───┼───┤
   │ab │ b²│
   └───┴───┘

   ab 칸이 둘 = 2ab
```

```
❌ 대동법 = 공납을 쌀로

✅ 무슨 문제를 풀려고 만들었나?
   → 방납 때문에 백성이 죽어남
   → 특산물 대신 쌀로 통일
   → 그래서 100년 걸림 (양반 반대)

   원인-해결로 저장하면
   하나만 기억나도 딸려 나온다
```

**"무슨 문제를 풀려고 만들었나"** — 사회·역사 전 영역에 쓰는 질문이다.

---

## 4위. 섞어 풀기

한 단원만 몰아서 하면 **풀 줄 아는 착각**이 생긴다.

```
❌ 지수만 30개
   → 다 지수인 걸 아니까 쉬움

✅ 지수·로그·수열 섞어서
   → "이게 뭘 묻는 거지?"부터
     생각하게 됨
```

시험은 섞여서 나온다. **어떤 도구를 쓸지 고르는 것**이 진짜 실력이다.

```
👉 오늘 배운 것만 말고
   지난주 것도 섞어서 봐.
```

---

## 5위. 구체적 사례 + 그림

추상적인 걸 잡을 손잡이를 만든다. **위 4개를 도와주는 보조**다.

```
기회비용 (추상적)
 ↓
내가 오늘 유튜브 본 1시간
 = 못 푼 수학 20문제
 (구체적)
```

그림은 이 학생이 특히 잘 붙는다. 개념 하나당 **작은 도식 하나**를 만든다.

---

## 6위. 두문자·소리연상 — 효과 낮다. 조건부로만

### 솔직히

두문자나 소리 연상은 **효과가 낮은 편**이다.
게다가 억지로 만들면 **암기법을 외우는 게 더 어려워진다.**

```
❌ negligible = "네글쓰 지블"
   → 이걸 외우는 게 단어보다 어렵다

❌ "교탈첨축된"
   → 뜻이 없어서 안 붙는다
```

### 써도 되는 딱 두 경우

**① 뜻이 통할 때 (어원·의미 연결)**

```
✅ impose = im(안으로) + pose(놓다)
   → 위에서 눌러 얹기
   → compose, expose, depose까지 같이 풀림

✅ 지양 = 양보 = 물러남 = 안 함
   지향 = 향함 = 나아감 = 함
```

**어원이나 뜻으로 연결되면 강하다.** 하나 알면 여러 개가 풀린다.

**② 순서 없는 목록이고, 이유가 없을 때**

```
음운 변동 5가지 (교체·탈락·첨가·축약·된소리)
→ 이건 이유가 없는 분류다
→ 이럴 때만 첫 글자를 써도 된다

단, 첫 글자만 외우면 내용을 잊는다.
반드시 각 항목 예시 하나를 같이 붙인다.
```

### 규칙

> **뜻이 통하면 쓴다. 소리만 비슷하면 버린다.**
> 억지로 만들 바에는 안 붙이는 게 낫다.

---

## 코치가 붙이는 방법

설명 끝에 **한 줄**. `🧠` 표시.

```
🧠 안 외워도 됨.
   왜 그런지만 알면 나옴.
```

```
🧠 impose = 안으로 + 놓다
   → 얹다. expose도 같은 pose.
```

```
🧠 오늘 자기 전에 안 보고
   한 번 말해봐.
```

### 규칙
- **1~3줄.** 넘지 않는다
- 이유로 이해되는 건 **"안 외워도 된다"**고 말한다 — 이게 가장 좋은 답이다
- 억지 연상은 만들지 않는다. 없으면 안 붙인다
- 대신 **인출 시점**을 준다: "3일 뒤에 꺼내봐"

---

## 학생이 "안 외워져요" 할 때

```
① "어떻게 외웠어?" 먼저 묻는다
   → 다시 읽기만 했으면 그게 원인
② 꺼내보게 시킨다
③ 그래도 안 되면 이해가 덜 된 것
   → 재설명 사다리로
```

**"더 외워라"고 하지 않는다.** 방법을 바꾼다.
