# 기억 · 오답 · 복습 엔진

이 학생은 단순 반복 암기가 약하다. 그래서 **암기를 시스템으로 대체한다.**

핵심 원칙 하나:
> 반복해서 **읽는** 것은 공부가 아니다. 반복해서 **꺼내는** 것이 공부다.

---

## 1. 파일 구조

프로젝트 루트에 다음 파일들을 만들어 운영한다.

```
공부 프로젝트/
├── STUDENT_PROFILE.md    학생 상태 (성적, 시간, 약점)
├── ERROR_LOG.md          오답 기록
├── REVIEW_QUEUE.json     복습 큐 (스크립트가 관리)
└── VOCAB.md              어휘 (국어 한자어 + 영어)
```

**세션 시작 시 `STUDENT_PROFILE.md`와 `ERROR_LOG.md`를 읽는다.** 이건 선택이 아니다.

---

## 2. 오답 기록 형식

`ERROR_LOG.md`에 누적한다. 새 항목은 위에 추가한다.

```markdown
## 2026-07-29

### 영어 · 어법 · 관계사
- 문제: `the place which I lived` 의 오류
- 학생 답: 오류 없음
- 정답: which → where
- **오답 코드:** `C` (개념 혼동)
- 진단: 관계대명사/관계부사 구분 미형성. 뒤 문장 완전성 판단을 안 함
- 처방: "뒤 문장 완전 → 부사, 불완전 → 대명사" 규칙 + 판별 10문제
- **누적:** 관계사 4회째 ⚠️
- 복습: 3일 / 14일 / 45일
```

### 오답 코드 (SKILL.md와 동일)

| 코드 | 원인 |
| --- | --- |
| `P` | 선수 개념 부족 |
| `C` | 개념 혼동 |
| `R` | 어휘·문장 해석 실패 |
| `M` | 조건 누락 |
| `L` | 추론 순서 오류 |
| `K` | 암기 미정착 |
| `X` | 계산·표기 실수 |
| `T` | 시간 관리 실패 |

## 3. 누적 경고 규칙

같은 항목이 반복되면 **반드시 학생에게 말한다.** 이게 코치와 답변기의 차이다.

| 누적 | 대응 |
| --- | --- |
| 2회 | 기록만 하고 언급 |
| 3회 | **경고.** "이번 주 최우선 항목으로 올립니다" |
| 4회 이상 | 새 진도를 멈추고 이 항목 집중 세션 |

### 경고 문구 예시
> **관계사, 이번이 4번째입니다.**
> 지난 3번 모두 "뒤 문장이 완전한지"를 확인하지 않았습니다.
> 오늘은 새 진도 안 나갑니다. 이것만 정리하고 갑니다.

**빈 칭찬은 안 하지만, 이런 지적은 반드시 한다.**

## 4. 간격 복습 스케줄

새로 배운 것은 다음 지점에 복습을 예약한다.

```
당일 → 1일 → 3일 → 7일 → 14일 → 45일
```

오답으로 걸린 항목은 더 촘촘하게:
```
당일 → 1일 → 3일 → 7일 → 14일 → 30일 → 60일
```

### 복습 결과에 따른 조정

| 결과 | 다음 간격 |
| --- | --- |
| 바로 답함 | 다음 단계로 (간격 증가) |
| 힌트 후 답함 | 같은 간격 유지 |
| 못 답함 | **1단계로 리셋** + 재학습 |

## 5. 복습 큐 스크립트

날짜 계산은 직접 하지 않는다. 실수한다.

```bash
S=skills/suneung-coach/scripts/review_queue.py

# 추가
python $S add "관계대명사 vs 관계부사" --subject 영어 --level L1 --from-error

# 오늘 복습할 것
python $S due

# 전체 현황
python $S list

# 복습 완료 (ok / hint / fail)
python $S done 7 --result ok

# 통계 (약한 과목·항목)
python $S stats
```

**세션 시작 시 `due`를 확인한다.** 밀린 게 있으면 새 진도보다 먼저 말한다.

> "오늘 복습 3개 밀렸습니다. 15분이면 됩니다. 이거 먼저 하고 새 진도 갑니다."

## 6. 회상 훈련 방법

읽기·밑줄·형광펜은 **효과가 거의 없다.** 대신 이것들을 쓴다.

### ① 백지 회상 (Blank Recall)
```
책을 덮는다 → 백지에 아는 것을 다 쓴다 → 책을 열어 빠진 것을 빨간색으로 채운다
→ 빨간색 부분만 복습 큐에 넣는다
```
가장 강력하다. 주 1회, 단원 단위로.

### ② 질문형 카드
카드 앞면에 **용어**를 쓰지 않는다. **질문**을 쓴다.

| ❌ 나쁜 카드 | ✅ 좋은 카드 |
| --- | --- |
| 앞: 대동법 / 뒤: 공납을 쌀로 | 앞: 조선 정부가 대동법을 만들어 풀려던 문제는? / 뒤: 방납의 폐단 |
| 앞: negligible / 뒤: 무시할 만한 | 앞: "The risk was ___" 에서 위험이 거의 없다는 뜻의 단어? / 뒤: negligible |

### ③ 이중 부호화
그림 + 언어를 함께 저장한다. 이 학생에게 특히 유효하다.
개념 하나당 **작은 도식 하나**를 반드시 만든다.

### ④ 한 문장 설명
"이 개념을 한 문장으로. 전문용어 없이."
말이 막히면 이해가 안 된 것이다.

### ⑤ 비교 쌍
헷갈리는 것은 **항상 짝으로** 저장한다.
```
지양 ↔ 지향 / 자유권 ↔ 사회권 / 정비례 ↔ 반비례 / which ↔ where
```

## 7. 인터리빙 (섞어 풀기)

같은 유형만 몰아서 풀면 **풀 줄 아는 착각**이 생긴다.
한 단원을 마치면 **이전 단원과 섞어서** 낸다.

```
1단원 학습 → 1단원 문제
2단원 학습 → 2단원 문제 + 1단원 문제 섞기
3단원 학습 → 3단원 + (1,2단원 랜덤) 섞기
```

수능은 어차피 섞여서 나온다.

## 8. 장기 기억 점검 (월 1회)

매월 1회, 지난달 학습 항목 중 **랜덤 20개**를 회상 테스트한다.

```bash
python $S stats --month
```

- 회상률 80% 이상 → 정상
- 60~80% → 복습 간격을 좁힌다
- 60% 미만 → 학습 방식 자체를 재검토 (아마 이해 없이 넘어간 것)

## 9. 학생에게 복습을 설득하는 방법

학생은 복습을 싫어한다. 새 진도가 더 재밌다.

❌ "복습이 중요해요"
✅ "지난주에 푼 이 문제, 지금 다시 풀면 몇 % 맞힐 것 같아? ... 해보자."

**직접 잊었다는 걸 겪게 하는 것**이 어떤 설명보다 효과적이다.
한 번 겪으면 그 다음부터는 복습을 스스로 요구한다.
