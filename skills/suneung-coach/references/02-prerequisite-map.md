# 초·중등 선수 개념 역추적 지도

고등 개념이 안 될 때 **어디로 내려가야 하는지**의 지도.
학생은 자기가 중2에서 막혔다는 걸 모른다. 이 표가 그걸 찾아준다.

사용법: 학생이 막힌 고등 개념을 찾고, 그 행의 선수 개념을 **위에서부터** 검증 문제로 확인한다.
최대 3단계까지만 내려간다.

### 수학 결손 3대 병목 (가장 자주 발견됨)

1. **분수 사칙연산** (초5~6) — 유리식, 확률, 미분에서 전부 터진다
2. **문자와 식 / 이항** (중1~2) — 방정식 전 영역
3. **함수의 뜻** (중2) — "x를 넣으면 y가 나온다"는 대응 관계 자체

이 3개는 발견되면 **다른 무엇보다 먼저** 복구한다.

1. **문장 성분 분석** (중1~2) — 문법 전 영역 + 긴 문장 독해
2. **주장/근거 구분** (초6~중1) — 독서 지문의 선지 판단
3. **한자어 어휘** — 사회·과학 지문에서 치명적. 별도 어휘 큐 운영

## 역추적 실행 스크립트

```
1. 학생이 막힌 고등 개념 확인
2. 위 표에서 해당 행을 찾는다
3. 오른쪽(더 낮은 학년)으로 이동하며 검증 문제를 낸다
4. 학생이 맞히는 지점에서 멈춘다 = 여기가 바닥
5. 바닥에서 위로 한 층씩 재구축 (각 층마다 확인 문제 1개)
6. 원래 고등 개념으로 복귀
7. 복구한 층 전부를 복습 큐에 넣는다
```

### 학생에게 말하는 방식

❌ "기초가 너무 부족하네요. 중2부터 다시 해야 해요."
✅ "찾았습니다. 로그가 아니라 **음의 지수**입니다. 이거 하나 메우면 로그 문제 대부분 풀립니다. 20분이면 됩니다."

**결손은 나쁜 소식이 아니라 좌표다.** 그렇게 전달한다.
