# 평가원 말 사전 — 간극을 메우는 다리

이 스킬의 존재 이유가 여기 있다.

```
학생 수준:  초·중등
배울 내용:  수능

이 간극을 메우는 게 코치의 일이다
```

학생은 개념을 이해해도 **시험지 앞에서 막힌다.**
평가원이 쓰는 말이 학생이 아는 말과 다르기 때문이다.

그래서 설명할 때마다 **두 개를 같이 준다.**

```
① 쉬운 말로 이해시킨다
② 평가원은 이 말을 이렇게 쓴다고 알려준다
③ 문제로는 이렇게 나온다고 보여준다
```

②③을 빼면 학생은 **알아도 못 푼다.**

---

## 1. 붙이는 형식

```
📖 시험에선 이렇게 나와
   쉬운 말 → 평가원 말

🎯 문제로는 이렇게
   (실제 발문) = (무슨 뜻)
```

### 예 — 로그

```
✅ 로그 = 몇 번 곱했나

📖 시험 말
   "몇 번 곱했나" → 지수
   "곱해지는 수"  → 밑
   "결과"        → 진수

🎯 문제로는
   "log₂(x-1)의 값이 정의되도록
    하는 x의 범위는?"
   = "진수가 0보다 커야 한다"
     는 걸 아는지 묻는 것
```

**문제 문장을 번역해 주는 게 핵심이다.** 학생은 발문을 못 읽는다.

---

## 2. 발문 번역 — 과목별

### 국어

| 평가원 발문 | 실제로 하라는 것 |
| --- | --- |
| 윗글에 대한 이해로 적절하지 않은 것은? | 지문에 **없는 말**을 찾아라 |
| ㉠의 의미로 가장 적절한 것은? | 앞뒤 문장으로 판단하라 |
| `<보기>`를 바탕으로 감상한 내용으로… | 보기의 관점을 지문에 씌워라 |
| 윗글의 서술 방식으로 적절한 것은? | 무슨 방법으로 썼는지 보라 |
| 문맥상 ⓐ와 바꿔 쓸 수 있는 것은? | 같은 뜻인 다른 말 찾기 |
| 윗글을 읽고 추론한 내용으로… | 지문에 **직접 없지만** 나오는 것 |

**"적절하지 않은"** 이 네 글자를 놓쳐서 틀리는 학생이 매우 많다.
발문에 이게 있으면 **표시하라고** 알려준다.

### 수학

| 평가원 표현 | 뜻 |
| --- | --- |
| 모든 실수 x에 대하여 | 예외 없이 항상 |
| 어떤 실수 x가 존재하여 | 하나라도 있으면 됨 |
| ~를 만족시키는 | 조건에 맞는 |
| ~의 값을 구하시오 | 답이 하나 |
| ~의 개수를 구하시오 | 경우를 다 세라 |
| 최댓값과 최솟값의 합 | 두 개 구해서 더해라 |
| 자연수 n에 대하여 | n은 1,2,3… (0 아님) |
| 서로 다른 두 실근 | 답이 2개, 겹치면 안 됨 |

**"모든"과 "어떤"이 정반대**인데 학생은 구분 못 한다. 매번 짚어준다.

### 영어

| 평가원 발문 | 실제로 하라는 것 |
| --- | --- |
| 다음 글의 요지로 가장 적절한 것은? | 반복되는 개념어를 찾아라 |
| 빈칸에 들어갈 말로 가장 적절한 것은? | 앞뒤 **논리 연결어**를 보라 |
| 다음 글의 순서로 가장 적절한 것은? | 지시어(this, such)를 따라가라 |
| 주어진 문장이 들어갈 위치로… | 그 문장의 지시어가 가리킬 것 찾기 |
| 밑줄 친 부분이 의미하는 바로… | 비유의 실제 뜻 |
| 전체 흐름과 관계 없는 문장은? | 화제가 벗어난 것 |

### 사회 · 과학

| 평가원 표현 | 뜻 |
| --- | --- |
| 자료에 대한 분석으로 옳은 것은? | **자료 안에서만** 판단 |
| 자료를 통해 알 수 있는 것은? | 자료에 없으면 오답 |
| 다른 조건이 같을 때 | 나머지는 고정, 하나만 변함 |
| 옳은 것만을 있는 대로 고른 것은? | ㄱㄴㄷ 다 따져라 |
| A에 해당하는 사례로 적절한 것은? | 개념을 사례에 적용 |
| 밑줄 친 ⊙에 대한 설명으로… | 그 부분만 보라 |

**"자료를 통해 알 수 있는"** = 자료 밖 상식을 쓰면 틀린다.
학생이 가장 자주 하는 실수다.

## 3. 쉬운 말 ↔ 시험 말 대응 (과목별)

설명은 왼쪽으로, 마지막에 오른쪽을 알려준다.

### 국어

| 쉬운 말 | 평가원 말 |
| --- | --- |
| 글쓴이가 하고 싶은 말 | 논지 / 주제 |
| 왜 그런지 대는 것 | 근거 / 논거 |
| 앞뒤가 반대로 | 대조 / 대비 |
| 딴 사람 말 가져옴 | 인용 |
| 예를 듦 | 예시 |
| 말을 그림처럼 | 형상화 |
| 떠올리게 함 | 환기 |
| 두드러지게 | 부각 |

### 수학

| 쉬운 말 | 평가원 말 |
| --- | --- |
| 딱 들어맞는다 | 성립한다 |
| 조건에 맞는다 | 만족시킨다 |
| 아무 수나 | 임의의 실수 |
| 안 변하는 수 | 상수 |
| 짝이 된다 | 대응한다 |
| 점점 가까워진다 | 수렴한다 |
| 몇 개인지 | 개수 |

### 사회

| 쉬운 말 | 평가원 말 |
| --- | --- |
| 나눠 줌 | 배분 / 분배 |
| 비뚤어짐 | 왜곡 |
| 하게 만드는 이유 | 유인 |
| 서로 부딪힘 | 상충 |
| 같이 따라옴 | 수반 |
| 방해함 | 저해 |
| 높임 | 제고 |

### 과학

| 쉬운 말 | 평가원 말 |
| --- | --- |
| 같이 늘어남 | 비례한다 |
| 하나 늘면 하나 줌 | 반비례한다 |
| 안 변하고 유지 | 보존된다 |
| 바뀜 | 전환된다 |
| 나옴 / 생김 | 생성된다 |
| 없어짐 | 소모된다 |

## 4. 문제 양상 알려주기

개념을 설명했으면 **그게 문제로 어떻게 나오는지** 보여준다.
"이 개념 중요해"보다 **"이렇게 나온다"**가 훨씬 강하다.

### 형식

```
🎯 문제로는 이렇게

   (자주 나오는 발문 한 줄)
   → 무엇을 묻는 건지
   → 어디서 틀리는지
```

### 예 — 국어 문법 (음운 변동)

```
🎯 문제로는 이렇게

   "다음 중 음운 변동이
    두 번 일어난 것은?"

   → 한 단어에서 몇 번인지 세라는 것
   → 함정: 두 개가 겹쳐 일어나는 단어
     (예: '맑고' → 자음군단순화 + 된소리)
```

### 예 — 사회 (수요·공급)

```
🎯 문제로는 이렇게

   "그림은 어떤 재화의 수요·공급
    곡선이다. 이에 대한 분석으로
    옳은 것은?"

   → 선이 움직였나, 점이 움직였나
   → 함정: 가격 때문이면 점,
     다른 이유면 선
```

### 예 — 수학 (로그부등식)

```
🎯 문제로는 이렇게

   "log₂(x-1) < 3을 만족시키는
    정수 x의 개수는?"

   → 진수 조건(x>1) 먼저
   → 함정: 그거 빼먹고 세면 하나 더 나옴
```

**함정을 미리 알려주는 게 이 항목의 핵심이다.**

## 5. 기출 언급 규칙

| 해도 되는 것 | 하면 안 되는 것 |
| --- | --- |
| "이런 형태로 자주 나온다" | "○○년 ○월 ○번 문제" (기억 부정확) |
| "이 유형은 진수 조건을 묻는다" | 기출 지문·선지를 지어내기 |
| "함정은 대개 여기다" | 확실하지 않은 출제 연도 단정 |

**연도·회차를 정확히 모르면 말하지 않는다.**
"자주 나오는 형태"로만 말한다. 틀린 기출 정보는 학생 시간을 버린다.

확실하지 않으면 `[확인 필요]`를 붙이고, EBS·평가원 자료로 확인하라고 안내한다.

---

## 6. 이 모듈을 언제 쓰나

**개념 설명할 때마다.** 이건 선택이 아니다.

```
설명 (쉬운 말)
  ↓
📖 시험에선 이 말을 쓴다
  ↓
🎯 문제로는 이렇게 나온다
```

이 세 층이 있어야 **초·중등 수준에서 수능까지 다리가 놓인다.**

②③이 없으면 학생은 "이해했는데 시험만 보면 안 돼요"가 된다.
그게 지금 이 학생의 상태다.
