# 수학

이 학생의 **유일한 예외 과목**이다. 목표는 1등급이 아니다.
하지만 서울대 인문계열도 수학을 반영하므로 **방치하면 안 된다.**

2028 개편 기준 수학 출제 범위는 **대수 / 미적분Ⅰ / 확률과 통계** `[확인 필요 — 평가원 최종 시행계획]`
심화수학(미적분Ⅱ·기하)은 미출제로 결정되었다 `[사실 — 2023.12 교육부 발표]`

---

## 1. 전략: 확실한 구간을 만든다

수학 4등급 학생에게 "전 범위 고득점"은 비현실적이다. 대신:

```
① 초·중등 결손 복구
   ← 없으면 아무것도 안 쌓임
② 각 단원의 기본~중급 완전 정복
③ 최고난도 문항은 후순위, 시간 남으면
```

**3점 문항 + 쉬운 4점 문항을 다 맞히는 것**이 현실적 1차 목표다.
그것만으로도 4등급 → 3등급 → 2등급 구간이 열린다.

이 전략을 학생에게 숨기지 않고 명시적으로 말한다.

---

## 2. 설명 순서 (고정)

이 학생은 식보다 그림이 먼저다.

```
그림 / 쉬운 수로 실험
    ↓
규칙 발견
    ↓
식으로 표현
    ↓
공식의 의미 ("이 공식이 말하는 게 뭐냐")
    ↓
기본 문제
    ↓
조건 결합
```

### 예: 이차함수 최댓값

❌ "y = a(x-p)² + q 에서 a>0이면 x=p에서 최솟값 q를 갖는다."

✅
```
y = x²
 → U자, 바닥 (0,0)

y = (x-2)²
 → 오른쪽 2칸, 바닥 (2,0)

y = (x-2)² + 3
 → 위로 3칸, 바닥 (2,3)

규칙: 괄호 안 부호는 반대로, 밖의 수는 그대로.
왜? x-2가 0이 되려면 x=2여야 하니까.
```

**"왜"를 붙이면 공식을 안 외워도 된다.** 이 학생에게는 이게 훨씬 유리하다.

## 4. 계산력 — 별도 관리

수학 4등급 학생의 실점 중 상당 부분은 개념이 아니라 **계산 실수**다.
이걸 "조심해"로 넘기지 않는다.

### 실수 로그
```markdown
| 날짜 | 실수 유형 | 내용 |
| --- | --- | --- |
| 7/29 | 부호 | 이항할 때 부호 안 바꿈 |
| 7/29 | 분수 | 통분 안 하고 분자끼리 더함 |
| 7/30 | 부호 | (반복) |
```

같은 유형 3회 → **그 유형 전용 계산 훈련 20문제**를 강제 삽입한다.

### 검산 습관
- 답이 나오면 **원식에 대입**한다
- 그래프 문제는 **개형을 그려서** 답이 말이 되는지 본다
- 확률 답이 1을 넘거나 음수면 즉시 오답

## 5. 문제 풀이 절차 (강제)

```
① 무엇을 구하라는 건가 (한 문장으로 다시 쓴다)
② 주어진 조건에 번호를 매긴다 ①②③
③ 조건마다 "이게 뭘 뜻하지?"를 번역한다
④ 구하려는 것과 조건을 잇는 도구(공식·정리)를 찾는다
⑤ 계산
⑥ 검산
⑦ 안 쓴 조건이 있나 확인 ← 남은 조건이 있으면 대개 틀렸다
```

②와 ⑦이 핵심이다. **조건 누락(M)이 이 학생의 최대 실점 원인일 가능성이 높다.**

## 6. 수학에서의 "왜?" 질문 예시

서울대 사고력은 수학에서도 통한다.

- 왜 판별식이 b²-4ac인가?
- 왜 로그의 밑은 1이 아니어야 하는가?
- 왜 미분계수가 접선의 기울기인가?
- 왜 등비수열의 합에 (r-1)이 분모로 오는가?
- 확률에서 왜 '경우의 수'를 세는 게 정당한가? (모든 경우가 같은 확률일 때만)

이 질문들은 답을 강요하지 않는다. **한 번 생각하게 만드는 것이 목적**이다.

## 7. 수학 시간 배분 원칙

이 학생은 수학이 1등급 목표가 아니다. 그러나 **시간을 안 쓰면 4등급도 못 지킨다.**

권장: 전체 학습 시간의 **20~25%**. 그 이상은 국어·탐구에 쓴다.
단, 초·중등 결손 복구 기간(초기 2~3개월)에는 **일시적으로 35%까지** 올린다.
바닥을 안 메우면 나중에 더 비싸다.

이 배분은 프로필의 실제 성적이 들어오면 재조정한다.
