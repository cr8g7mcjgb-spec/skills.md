# 사회 · 역사 (통합사회 / 한국사)

2028 개편에서 탐구는 **통합사회 + 통합과학**을 모두 응시한다 `[사실 — 2023.12 교육부 발표]`
한국사는 필수다.

인문계 지망생에게 통합사회는 **국어 다음으로 중요하다.**

---

## 1. 설명 구조 (고정)

```
배경  →  원인  →  과정  →  결과  →  쟁점(왜 논쟁이 되는가)
```

마지막 '쟁점'을 빼면 암기 과목이 되고, 넣으면 사고력 과목이 된다.
**항상 넣는다.**

---

## 2. 사실 / 해석 / 관점 구분

역사와 사회는 **사실과 해석이 섞여 있다.** 이걸 구분해서 가르치지 않으면
학생은 해석을 사실로 외우고, 다른 관점이 나온 선지에서 틀린다.

```markdown
[사실]  1894년 갑오개혁이 시행되었다.
[해석A] 근대적 개혁의 출발점이었다. (근대화론)
[해석B] 일본의 영향력 아래 이루어진 타율적 개혁이었다. (타율성 비판)
[쟁점]  주체성과 근대성 중 무엇을 기준으로 평가할 것인가
```

**수능은 [사실]을 직접 묻고, 고난도 문제는 [쟁점]을 선지로 만든다.** 둘 다 본다.

---

## 3. 통합사회 — 영역별 핵심

| 영역 | 핵심 개념 | 자주 나오는 함정 |
| --- | --- | --- |
| 인간·사회·환경 | 통합적 관점(시간·공간·사회·윤리) | 4가지 관점 구분 |
| 행복 | 질 높은 정주환경, 경제적 안정, 민주주의, 도덕적 실천 | 조건 간 우선순위 없음 |
| 자연환경 | 기후·지형과 생활, 자연관 | 환경결정론 vs 가능론 |
| 생활공간 | 도시화, 산업화, 교통 발달 | 변화의 인과 방향 |
| 인권 | 인권의 확장, 헌법적 보장 | 자유권/평등권/사회권 구분 |
| 시장 | 수요·공급, 시장실패, 정부 개입 | 그래프 이동 방향 |
| 정의 | 분배 기준(업적/능력/필요), 자유주의 vs 공동체주의 | 각 입장이 지지할 정책 |
| 문화 | 문화 상대주의, 다문화 | 상대주의의 한계(보편윤리) |
| 세계화 | 국제 분업, 공정무역 | 이익과 비용의 주체 구분 |
| 지속가능 | 인구, 자원, 기후변화 | 세대 간 형평성 |

### 자료 해석형이 핵심

통합사회는 **그래프·표·지도·사진 해석 비중이 크다.**

```
① 축이 뭔지 읽는다 (단위 포함)
② 전체 경향 한 줄
③ 예외·역전 지점
④ 자료가 말하지 않는 것 ← 오답 선지가 여기서 나온다
```

④가 중요하다. **"자료에서 인과를 추론"하는 선지는 대개 오답이다.**
상관관계를 인과로 바꾼 선지를 항상 의심한다.

## 4. 한국사

### 시간 감각이 전부다

사건 순서가 안 잡히면 무슨 공부를 해도 무너진다. **타임라인을 반드시 그린다.**

```
고조선 ─ 삼국 ─ 남북국 ─ 고려 ─ 조선전기 ─ [임진왜란] ─ 조선후기 ─ [개항] ─ 대한제국 ─ [강점] ─ 광복 ─ 현대
                                            1592              1876            1910    1945
```

**굵은 사건(전쟁·개항·강점·광복)을 기둥으로 삼고 나머지를 그 사이에 배치한다.**

### 주제별 종단 정리

시대순만 하면 안 된다. 같은 주제를 시대 관통해서 본다.

| 주제 | 추적 |
| --- | --- |
| 토지제도 | 전시과 → 과전법 → 직전법 → 관수관급제 → 폐지 |
| 조세제도 | 조용조 → 대동법 → 균역법 |
| 신분제 | 골품제 → 문벌귀족 → 양반 → 신분제 동요 → 갑오개혁 폐지 |
| 교육·과거 | 국자감 → 성균관 → 과거제 → 근대 학교 |
| 대외관계 | 사대교린 → 개항 → 식민 → 분단 |

**이 종단 정리가 수능 사료 문제와 서술형에서 결정적이다.**

### 사료 읽기

한국사는 **사료(원문)**가 나온다. 절차:
```
① 등장하는 고유명사·제도명에 표시
② 시대를 추정할 단서 찾기 (인물, 관직명, 제도, 사건)
③ 시대 확정
④ 그 시대의 배경 지식과 연결
```

## 5. 사회에서의 "왜?" 질문 예시

이 과목은 "왜"가 잘 나온다. 단, **질문은 응답당 1개까지다.**
확인 질문을 이미 냈으면 "왜"는 생략한다.

- 왜 조선은 대동법을 시행하는 데 100년이 걸렸나? (누가 반대했나)
- 왜 시장실패가 있어도 정부 개입이 항상 정답은 아닌가?
- 왜 문화 상대주의를 무제한 적용하면 안 되는가?
- 왜 갑오개혁은 근대적이면서 동시에 비판받는가?
- 왜 인권의 범위는 계속 확장되어 왔는가?

**수능 고난도 추론 문제가 이런 사고를 요구한다.**

---

## 6. 암기 방식

이 학생은 단순 반복 암기가 약하다. 사회·역사에서는 다음을 쓴다.

| 금지 | 대체 |
| --- | --- |
| 연도 나열 암기 | 타임라인에 배치 + 앞뒤 사건과 인과로 연결 |
| 용어 정의 반복 읽기 | 그 용어가 **아닌 것**과 비교 (예: 자유권 ≠ 사회권) |
| 제도 이름 외우기 | "이 제도는 어떤 문제를 풀려고 만들었나" |
| 인물 나열 | 인물 관계도 |

**모든 제도·사건은 "무슨 문제를 해결하려 했는가"로 저장한다.**
문제-해결 구조로 저장하면 잊어도 재구성할 수 있다.
