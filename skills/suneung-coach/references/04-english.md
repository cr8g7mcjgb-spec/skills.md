# 영어

2028 대입개편 기준 영어는 **절대평가**다. 1등급 = 원점수 90점 이상.
상대평가가 아니므로 **경쟁이 아니라 기준선 통과** 문제다. 이 학생 전략에서 중요한 함의:

> 영어는 투자 대비 회수가 가장 확실한 과목이다. 90점 넘기면 그 이상은 불필요하다.
> 남는 시간을 국어와 탐구로 돌린다.

단, 서울대는 영어 등급을 감점 방식으로 반영하는 경우가 있다 `[확인 필요]` — 실제 반영 방식은 서울대 모집요강 원문 확인 후 답한다.

---

## 1. 영어 독해의 유일한 뼈대

```
주어 찾기 → 동사 찾기 → 나머지는 전부 수식
```

수능 영어를 못 읽는 학생의 99%는 **문장의 주어와 동사를 못 찾는다.**
어휘를 아무리 외워도 이게 안 되면 안 읽힌다.

### 훈련 절차

```
① 동사부터 찾는다 (시제 표시가 있는 것)
② 그 동사 앞에서 주어를 찾는다
③ 나머지 덩어리에 괄호를 친다
④ 뼈대만 읽는다
⑤ 그 다음 괄호 안을 붙인다
```

예:
```
The researchers (who had been studying the phenomenon for decades)
finally concluded (that the effect was negligible).

뼈대: The researchers concluded that the effect was negligible.
→ 연구자들이 결론 내렸다: 효과가 미미하다고.
```

**이 훈련을 매일 3문장씩.** 지문 전체를 해석하는 것보다 이게 먼저다.

---

## 2. 유형별 공략

| 유형 | 핵심 | 근거 위치 |
| --- | --- | --- |
| 주제·요지 | 반복되는 개념어 | 첫 문단 + 마지막 문단 |
| 빈칸 추론 | 빈칸 앞뒤의 논리 연결어 | 빈칸 직전/직후 문장 |
| 순서 배열 | 지시어(this, such, the+명사), 연결어 | 각 단락 첫 문장 |
| 문장 삽입 | 삽입 문장의 지시어가 가리킬 대상 | 빈칸 앞 문장 |
| 무관한 문장 | 글의 흐름에서 벗어난 화제 | 주제문과 대조 |
| 어법 | 수일치 / 시제 / 태 / 병렬 / 관계사 | 밑줄 주변 구조 |
| 어휘 | 문맥상 반대 의미가 들어간 것 | 앞뒤 논리 방향 |
| 함의 추론 | 비유 표현의 실제 뜻 | 앞뒤 맥락 |

### 빈칸 추론 — 가장 배점 높고 가장 자주 틀린다

```
① 빈칸이 있는 문장을 먼저 읽는다 (전체를 먼저 읽지 않는다)
② 빈칸이 글의 어느 위치인가 확인
   - 첫 문장 → 주제 제시
   - 중간 → 앞 내용의 부연 또는 전환
   - 마지막 → 결론
③ 빈칸 앞뒤 연결어를 확인
   - however / but → 앞과 반대
   - therefore / thus → 앞의 결과
   - for example → 앞의 구체화
   - in other words → 앞의 재진술
④ 글의 주제를 한 단어로 압축
⑤ 선지 중 그 압축과 방향이 같은 것
```

**함정:** 지문의 단어를 그대로 쓴 선지. 어휘가 같다고 논리가 같지 않다.

## 3. 어법 — 5개만 잡으면 대부분 해결

| 순위 | 항목 | 확인 질문 |
| --- | --- | --- |
| 1 | 수일치 | 진짜 주어가 뭐지? (수식어에 속지 마라) |
| 2 | 동사 vs 준동사 | 이 문장에 동사가 이미 있나? |
| 3 | 능동 vs 수동 | 주어가 하는 건가, 당하는 건가? |
| 4 | 관계사 | 뒤 문장에 빠진 성분이 있나? (있으면 관계대명사, 없으면 관계부사) |
| 5 | 병렬 | and/or 앞뒤 형태가 같은가? |

### 관계사 — 이 학생이 반복해서 틀릴 가능성이 높은 항목

```
관계대명사: 뒤 문장에 주어나 목적어가 비어 있다
  the book [which I read ___]   ← 목적어 없음 → which

관계부사: 뒤 문장이 완전하다
  the place [where I lived]     ← 완전한 문장 → where
```

**판단법 한 줄: 뒤 문장이 완전하면 부사, 불완전하면 대명사.**

## 4. 어휘 — 별도 트랙

### 원칙
- 단어장 순서대로 외우지 않는다. **지문에서 만난 단어를 쌓는다**
- 뜻 하나만 외우지 않는다. **이미지 + 짧은 예문 + 유의어와의 차이**
- 반복 읽기 금지. **회상 테스트**로만 복습

```markdown
| 단어 | 이미지 | 예문 | 헷갈리는 말 |
| --- | --- | --- | --- |
| negligible | 먼지 한 톨 | The risk was negligible. | negligent(태만한) — 전혀 다름 |
| impose | 위에서 눌러 얹기 | impose a tax | expose(드러내다) |
```

### 목표량
공부 시간이 충분한 학생이므로 **하루 30~50개 신규 + 복습 큐**가 가능하다.
단, 첫 2주는 20개로 시작해 정착률을 확인한 뒤 늘린다.

## 5. 듣기

절대평가 90점 목표에서 듣기 17문항은 **거의 전부 맞혀야 하는 구간**이다.
- 매일 1회분, 같은 시간대에
- 틀린 문항은 **스크립트를 보지 말고 다시 듣는다** → 그래도 안 들리면 스크립트 확인
- 안 들린 이유를 분류: 어휘 / 연음 / 속도 / 집중

## 6. 영어 학습 로드맵

| 단계 | 목표 |
| --- | --- |
| 1 | 주어·동사 찾기 (매일 3문장) |
| 2 | 중등 문법 5개 복구 (수일치, 준동사, 태, 관계사, 병렬) |
| 3 | 어휘 큐 가동 |
| 4 | 유형별 풀이 절차 체화 |
| 5 | 시간 제한 훈련 |
| 6 | 90점 안정화 → 시간 재배분 |

**6단계에 도달하면 영어 학습 시간을 줄이고 국어·탐구로 옮긴다.** 이걸 명시적으로 알려준다.
