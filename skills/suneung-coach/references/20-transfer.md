# 응용력 — 처음 보는 문제에 옮겨 쓰는 힘

수능은 배운 그대로 안 나온다. 4등급과 1등급을 가르는 건 지식량이 아니라 **옮겨 쓰는 힘**이다.

## 응용이 안 되는 진짜 이유

학생은 문제를 **겉모습**으로 기억한다.

```
"기차가 시속 60으로 간다" 문제를 품
  ↓
"물탱크에 물이 찬다" 문제가 나옴
  ↓
못 품

겉모습이 달라서.
속은 똑같은 '일정 비율로 변하는 것'인데.
```

**응용력 = 겉모습을 걷어내고 구조를 보는 힘.**

그래서 훈련도 "여러 문제를 풀기"가 아니라
**"이 문제가 어떤 구조인지 말하기"**다.

---

## 1위. 구조 이름 붙이기 — 가장 효과적

문제를 풀기 전에 **"이건 어떤 종류지?"**를 한마디로 말하게 한다.

```
문제를 본다
  ↓
"이건 ○○ 문제야"   ← 여기가 훈련
  ↓
그 도구를 꺼낸다
```

### 예 — 수학

```
"소금물 200g에 소금 30g"
"할인 20% 후 다시 10%"
"인구가 매년 3%씩 증가"

겉모습: 소금 / 할인 / 인구
구조:   전부 '비율' 문제

→ 같은 도구를 쓴다
```

### 예 — 국어

```
"이 지문 어떤 구조야?"

· 개념 설명형
· 과정 설명형
· 견해 대립형
· 원리+응용형
· 통시적 변화형

구조를 맞히면 어디가 출제될지도 보인다
```

### 코치가 시키는 말

```
👉 풀지 말고, 이게 무슨
   종류 문제인지만 말해봐.
```

**푸는 것보다 분류하는 게 응용력을 더 키운다.**
답을 못 내도 구조를 맞히면 성공이다.

---

## 2위. 두 문제 비교하기

한 문제를 깊게 보는 것보다 **두 개를 나란히 놓는 게** 강하다.

```
문제 A와 B를 나란히
  ↓
"뭐가 같고 뭐가 달라?"
  ↓
같은 것 = 구조
다른 것 = 겉모습
```

### 예

```
A: log₂(x-1) < 3
B: log₂(x-1) < 3, x는 정수

같은 것: 로그부등식, 진수 조건
다른 것: B는 정수만 세야 함

→ "정수" 한 단어가 문제를 바꾼다
```

**차이를 말할 수 있으면 다음에 안 틀린다.**

### 코치가 시키는 말

```
👉 아까 틀린 문제랑
   이 문제, 뭐가 달라?
```

---

## 3위. 자기 말로 원리 말하기

구체적인 문제에서 **원리만 뽑아내는** 훈련이다.

```
문제를 풀었다
  ↓
"숫자 빼고, 이 문제가
 알려주는 게 뭐야?"
  ↓
그게 다음 문제에 쓰인다
```

### 예

```
문제: 판별식 D<0이라 실근이 없다

원리만 뽑으면?
→ "그래프가 x축에 안 닿으면
   답이 없다"

이러면 다른 문제에서도 보인다
```

---

## 4위. 조건 하나 바꿔보기

**직접 비틀어 보는 것**이 이해를 확인하는 가장 빠른 길이다.

| 바꾸기 | 질문 |
| --- | --- |
| 숫자 | "다른 수면?" |
| 방향 | "거꾸로 물으면?" |
| 조건 | "이 조건 빼면?" |
| 크기 | "0이면? 엄청 크면?" |

### 왜 효과가 있나

```
숫자만 바꿔도 못 푼다
 → 겉모습만 외운 것 (진단됨)

바꿔도 풀린다
 → 구조를 아는 것
```

**이건 훈련이자 자가 진단이다.** 학생이 혼자 할 수 있다.

### 예

```
배운 것: log₂8 = 3

혼자:
  log₃9 = ?
  log₅125 = ?
  log₂1 = ?   ← 여기서 막히면 발견!
```

---

## 5위. 다른 데서 찾기 — 창의성이 나오는 곳

같은 원리가 **다른 과목·일상**에 있는지 찾는다.

```
로그를 배웠다
 ↓
어디에 또 있나?
 · 소리 크기 (데시벨)
 · 지진 규모 (리히터)
 · 산성도 (pH)

전부 "몇 배씩 커지는 것"을
다루려고 로그를 쓴다
```

```
기회비용을 배웠다
 ↓
오늘 유튜브 본 1시간의
기회비용은?
```

**수능 `<보기>` 적용 문제가 정확히 이걸 묻는다.**
그리고 돈도 시간도 안 든다.

### 과목별

| 과목 | 시키는 말 |
| --- | --- |
| 국어 | "이 논리가 다른 데도 되나?" |
| 영어 | "이 구조로 내 얘기 한 문장" |
| 수학 | "이 공식 안 통하는 경우는?" |
| 사회 | "오늘 뉴스에서 이 개념 찾기" |
| 과학 | "집에서 보이는 예 찾기" |

---

## ⛔ 효과가 낮은 것

| 하지 마라 | 왜 |
| --- | --- |
| 비슷한 문제 많이 풀기 | 겉모습만 익는다 |
| 유형별로 몰아서 풀기 | 어떤 도구 쓸지 안 고르게 된다 |
| 풀이 과정 베껴 쓰기 | 손만 움직인다 |
| "창의적으로 생각해봐" | 틀 없이는 아무것도 안 나온다 |

**많이 푸는 게 응용력을 만들지 않는다.**
같은 문제를 **다르게 보는 것**이 만든다.

---

## 학생이 물어봤을 때만 답한다

> ⚠️ **먼저 붙이지 않는다.** 학생이 "응용이 안 돼"라고
> 물었을 때만 이 파일을 쓴다.

물어보면 **한 줄**. `🔄` 표시.

```
🔄 이거 무슨 종류 문제인지
   한마디로 말해봐.
```

```
🔄 숫자만 바꿔서 하나
   혼자 해봐. 되면 넘어가자.
```

```
🔄 이 원리 다른 데 어디
   있는지 하나만 찾아봐.
```

### 규칙
- **학생이 물어봤을 때만.** 설명에 얹지 않는다
- **한 줄.** 답을 요구하지 않는다
- 확인 질문과 겹치면 **하나만** 쓴다 (§7 질문 1개 규칙)
- 학생이 개념을 아직 못 잡았으면 **붙이지 않는다**

---

## 순서를 지킨다

```
이해  →  암기  →  응용
```

응용이 안 되는 건 **개념이 덜 잡힌 것**이다. 응용을 더 시키지 않는다.

```
숫자만 바꿔도 못 함
 ↓
응용 문제가 아니라 개념 문제
 ↓
재설명 사다리로 (00-response-protocol §4)
```

**이해 없이 응용을 시키면 학생이 무너진다.**
